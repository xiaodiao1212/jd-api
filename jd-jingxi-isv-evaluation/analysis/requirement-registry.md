## 编制口径

- 来源：`inputs\京东京喜-ISV-需求清单.md`；原文行号以该文件为准。
- `招标方 CLI Skill` 只按需求清单“是否已有”列记录：是=原文明确；否=原文明确不存在；未说明=原文没有该列值（经营自动化模块）。这不表示我方已有实现，也不表示已有 API 或生产级自动执行能力。
- 其他行为字段采用 `[明确]`（原文直接写出）、`[解释]`（从产品名称/概述抽取的行为）、`[待确认]`（需要招标方或京东确认）；空行为写“无”。本表只做需求分解，不做最终技术可行性或等级判断。
- `修改京东状态` 指需求语义上可能写入/改变京东侧业务对象；是否有开放接口、权限及实际状态边界留待后续评估。
- 现有能力基线：已有成熟 SaaS 基座、Sico AI 生图侠、Sico AI 巡检侠及招标方 CLI Skill 流程，但不可据此推断具体 API、权限、内部数据或自动化实现（参见 `inputs\existing-capabilities.md` 第 17-33、37-69、73-107、111-131 行）。

本文档为电商开放平台的商品管理模块对接指南，旨在帮助商家通过一系列接口实现商品运营中多项进阶场景功能的管理。

本文档为电商开放平台的商品管理模块对接指南，旨在帮助商家通过一系列接口实现商品运营中多项进阶场景功能的管理。本文档涵盖的功能范围包括 **区域销售限制**、 **数量限购**、 **电子说明书**、 **商品系列品** 与 **商品预订** 五大核心模块

- **区域销售限制管理**：支持区域限制模板的发布、修改、删除及绑定商品，便于商家根据不同地区政策或运营需求设置商品销售范围；
- **数量限购策略管理**：包括数量限购策略的发布、查询、绑定与解绑商品，通过策略设置限制同一收货手机号、同一账号PIN、同一下单IP在有效时间范围内的购买件数，帮助商家预防黄牛/扫货行为攻击
- **电子说明书管理**：支持创建、编辑、查询电子说明书，并可将其与商品关联，提升商品信息完整性与用户体验；
- **商品系列品管理**：支持商品系列的创建、删除、修改及查询，便于商家对关联商品进行统一管理与展示；
- **商品预订管理**：支持批量创建与查询商品预订

**适用业务：** POP、自营 （不同场景分别标注）

**适用对象：** 自研商家，软件服务商。

## 一、基础概念

## 1.1 名词解释

| **名词** | **解释说明** |
| --- | --- |
| 区域限购 | 商家可根据商品或者店铺维度设置一个限售模板，模板关联商品即可生效，前台展现为“当前地区无货”，不允许消费者下单 |
| 数量限购 | 数量限购，也可以称之为限售，是指京东商家可以设置消费者购买商品的数量，包括“起购”“限购”；譬如 “最多购买5件” “至少购买2件”；消费者购买商品时会有购买商品数量的限制；主要是为了帮助商家预防黄牛/扫货行为攻击 |
| 电子说明书 | 解决客户在商品选购以及收货后，对商品安装、使用、清洁、保养等关于 商品如何正确使用 的问题，助力售前转化，降低售后咨询，提升消费者服务体验 |
| 商品系列品 | 可以将同类目下不同类型、不同系列的的商品绑定在一起，方便用户在选择特定商品属性系列后可以快速定位到相同系列下的其他产品，减少用户选择链路，达成连带营销等销售效果 |
| 商品预订 | 预订（一种负卖模式）：先售后发。优点：灵活性高，可随时开启关闭。适合有一定制作周期、短时间缺货的场景使用。 |

## 二、业务规则

## 2.1 区域限购

### 2.1.1 需要设置区域限购的场景

商家设置有多种原因，常见场景如下：

1. 部分地区物流成本太高（例偏远地区新疆、西藏等），商家无法承担运输成本；
2. 因物流快递在部分地区政策管控（例疫情洪水等不可抗力，两会、阅兵等重大活动），物流无法运输导致；
3. 因品牌授权要求，只能在部分地区售卖等；
4. 因春节等假期物流快递停运等；

## 2.2 数量限购

### 2.2.1 京麦端如何设置数量限购

1. 第一步：打开京麦后台->商品->商品工具->商品工具箱->商品数量限购

| **入口展示** | **介绍说明** |
| --- | --- |
| ![](https://joscms.jd.com/doc/img/0000Dx0RXhgRiT9073EXnVlfoEYL8EdR96I8E9UWTzD3QZSUsA338ZYNRuDDjrEEHQpcvbI95ILUC1pcJprxay1MUcLfvZF) | 原限购工具，为POP商家开放提供的商品限购工具，支持商品SKU／SPU维度设置限购，通过策略设置限制同一收货手机号、同一账号PIN、同一下单IP在有效时间范围内的购买件数，帮助商家预防黄牛/扫货行为攻击； |

1. 第二步：点击【创建策略】

![](https://joscms.jd.com/doc/img/00005z2jfJv71bWyQXCf9Yqux1LpRdpNFhx08yMM0B38QirHE8nJWNn4g89lHAPmSX5mdIp8pjvHg6a04WqRB9Ik9A9BYMZ)

1. 第三步：填写“策略名称”，选择“限购维度” “限购类型” “限购内容”，填写限购规则； 选择策略生效的“开始时间” “结束时间”
- **商品池限购** 是指同一SPU下， **所有SKU数量累计** 生效； **商品限购** 是指同一SPU下， **每个SKU数量累计** 生效；
- 限购内容：仅勾选需要的限购内容即可， **至少选择一项不是必须都要勾选**； **N件起购至少填写2-9999的数字，不填写就是默认1件起购**
- 开始时间必须大于当前时间(包括时分秒)；生效时间至少1天，最长可设置三年；策略在设置时间段内生效，过期策略失效。
- 使用快捷绑定时，限购维度是SPU时，请粘贴SPU编码，限购维度是SKU时，请粘贴SKU编码，否则会提示：商品因不属于该商家而绑定失败；每次最多绑定500个商品，如您配置的商品较多（400个－500个），系统可能会出现“loading”加载提醒，请您耐心等待即可，最长等待1分钟

## 3.1 区域限购

区域限购功能， **自营仅针对厂直商家** 开放、 **POP针对所有商家** 开放

### 3.1.1 业务流程图

![](https://img11.360buyimg.com/img/jfs/t1/433136/30/15639/685548/6a0bcb50Ffeae72ae/00c3f1efe112c1d1.jpg)

### 3.1.2 操作步骤

1\. 发布区域限制模板

本步骤使用的接口： [POST sp-product/v0/area-restriction-templates](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100513&apiName=postAreaRestrictionTemplate&gwType=1)

- 发布商品区域限制模板，用于设置商品销售区域限制

> 如何获取areaid？  
> 1.jingdong.areas.province.get获取省级地址列表，使用场景，能够获取全国所有省级地址信息，使用限制，只能获取省一级的地址信息，无法获取市县镇的信息  
> 2.jingdong.areas.city.get根据省份id获取市级信息列表，使用场景，已知省份id，获取省份下级地址信息，例如北京市下所有区县地址信息，根据北京id1去获取，使用限制，一次只能传一个省份id，不支持批量查询  
> 3.jingdong.areas.county.get获取区县级信息列表，使用场景，根据市级地址id获取该市下县级地址信息，使用限制，每次只能传一个市级地址，不能批量获取  
> 4.jingdong.areas.town.get获取乡镇级信息列表，使用场景，根据县级地址，获取乡镇地址信息列表，使用限制，每次只能传一个县级地址，不能批量获取，直辖市的地址只到三级，没用乡镇级地址

2\. 修改区域限购模版

本步骤使用的接口： [PUT sp-product/v0/area-restriction-templates/{templateId}](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100498&apiName=putAreaRestrictionTemplate&gwType=1)

- 修改指定商品的区域限制模板信息

3.删除区域限购模版

本步骤使用的接口： [DELETE sp-product/v0/area-restriction-templates/{templateId}](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100495&apiName=deleteAreaRestrictionTemplate&gwType=1)

- 删除指定商品的区域限制模板信息

4.查询区域限购模版列表

本步骤使用的接口： [GET sp-product/v0/area-restriction-templates](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100502&apiName=listAreaRestrictionTemplates&gwType=1)

- 查询商品区域限制模板列表接口，用于获取所有可用的区域限制模板
- 支持分页查询，可按模版类型、模版名称进行过滤

5.查询区域限购模版详情

本步骤使用的接口： [GET sp-product/v0/area-restriction-templates/{templateId}](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100503&apiName=getAreaRestrictionTemplate&gwType=1)

- 获取商品区域限制模板的详细信息

6.查询模版绑定的商品列表

本步骤使用的接口： [GET sp-product/v0/area-restriction-templates/{templateId}/products](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100515&apiName=listAreaRestrictionTemplateProducts&gwType=1)

- 查询区域限制模板上绑定的商品列表
- 支持分页查询

7.批量绑定店铺或商品到限购模版

本步骤使用的接口： [POST sp-product/v0/area-restriction-templates/{templateId}/products/batch](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100514&apiName=batchPostAreaRestrictionTemplateProduct&gwType=1)

- 店铺或商品批量绑定区域限制模板
- 可通过templateType参数控制绑定至店铺or商品

8.店铺or商品与数量限购模版解绑

本步骤使用的接口： [DELETE sp-product/v0/area-restriction-templates/{templateId}/products/batch](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100511&apiName=deleteAreaRestrictionTemplateProduct&gwType=1)

- 对区域限购模版上绑定的商品进行解绑，或对店铺模版进行解绑

## 3.2 数量限购

数量限购功能目前 **仅对POP商家开放**

### 3.1.1 业务流程图

![](https://img11.360buyimg.com/img/jfs/t1/436163/33/12115/636511/6a0bcb69F9cb2eda3/00c3f1ef19b3dd5d.jpg)

### 3.1.2 操作步骤

1.新增数量限购策略

本步骤使用的接口： [POST sp-product/v0/limit-buy-strategies](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100559&apiName=postLimitBuyStrategy&gwType=1)

- 发布限购策略接口，用于设置商品的数量限购规则
- 起购数量,范围为2-9999；限购总数量,范围为1-9999；单个订单限购数量,范围为1-9999
- 可按spu/sku维度进行限购，如果是spu则限购类型不可以选择按ip或手机号

2.删除数量限购策略

本步骤使用的接口： [DELETE sp-product/v0/limit-buy-strategies/{id}](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100572&apiName=deleteLimitBuyStrategy&gwType=1)

- 删除指定的商品数量限购策略信息

3.查询数量限购策略列表

本步骤使用的接口： [GET sp-product/v0/limit-buy-strategies](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100565&apiName=listLimitBuyStrategies&gwType=1)

- 获取当前商家下所有限购策略的列表信息
- 支持分页查询，支持按创建时间、生效时间、策略名等维度进行过滤

4.查询数量限购策略详情

本步骤使用的接口： [GET sp-product/v0/limit-buy-strategies/{id}](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100626&apiName=getLimitBuyStrategy&gwType=1)

- 支持分页批量查询商家的有效商品信息

5.查询策略绑定的商品列表

本步骤使用的接口： [GET sp-product/v0/limit-buy-strategies/{id}/products](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100591&apiName=listLimitBuyStrategyProducts&gwType=1)

- 查询与指定限购策略关联的商品列表接口
- 接口支持分页查询

6.批量绑定商品到限购策略

本步骤使用的接口： [POST sp-product/v0/limit-buy-strategies/{id}/products/batch](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100574&apiName=batchPostLimitBuyStrategyProduct&gwType=1)

- 批量绑定限购策略中的商品接口，用于商家对某商品进行限购

7.商品与数量限购策略解绑

本步骤使用的接口： [DELETE sp-product/v0/limit-buy-strategies/{id}/products/batch](https://open.jd.com/v2/#/doc/api?apiCateId=100081&apiId=100594&apiName=batchDeleteLimitBuyStrategyProduct&gwType=1)

- 批量把商品与数量限购策略解绑

## 四、常见问题

## 5.1 业务类常见问题

1. wareId、spuId、skuId的区别是什么？

wareId是京东商品Id，spuId是标品Id，skuId是sku的唯一标识。

1个wareId下可以有N个skuId，1个skuId只能属于1个wareId，1个wareId绑定1个spuId

本文档为电商开放平台的商品运营模块对接指南，旨在帮助商家通过一系列接口实现商品的精细化运营与数据化管理。涉及开放的模块有商品的价格星级、健康分、商机、评价等关键场景，是商家提升商品竞争力与转化效率的重要支撑。

本文档涵盖的核心运营能力包括：

- **价格星级**：支持查询商品价格星级、建议价及回传价格变更记录，辅助商家进行科学定价与价格策略调整。
- **信息健康分**：提供商品信息健康分列表与详情查询，帮助商家识别并优化信息不完整的商品，提升信息质量与搜索曝光。
- **商机数据**：支持分页滚动查询平台推荐的商机数据，并允许ISV（服务商）回写根据商机发布的商品信息，助力商家捕捉市场机会。

**适用业务：** POP、自营

**适用对象：** 自研商家，软件服务商。

## 一、基础概念

## 1.1 名词解释

| **名词** | **解释说明** |
| --- | --- |
| 价格星级 | 京东推出，帮助商家更好的监测店铺商品价格水平，通过降价，提升价格竞争力 **，** 获得更多流量和营销资源激励的价格运营工具 |
| 信息健康分 | 是京东平台用于衡量商品信息完整性和质量的综合指标，满分为100分，最低为58分。它通过评估商品素材（如图片、视频、文本等）对商品详情页转化率的影响来计算得分。分数越高，代表商品信息越完整、优质，对商品的流量获取和转化率提升越有帮助 |
| 商机 | 商品商机是指通过分析消费者行为、商品销售数据以及市场供需情况，识别出具有较高销售潜力或市场机会的商品或商品类别。其核心目标是帮助商家发现市场中的高需求商品，从而优化选品、备货和运营策略，提升商品曝光率和成交机会。 |

## 二、业务规则

## 2.1 价格星级

### 2.1.1 “价格星级”是什么？

由京东推出，帮助商家更好的监测店铺商品价格水平，通过降价，提升价格竞争力 **，获得更多流量和营销资源激励** 的价格运营工具。“价格星级”会对比自身商品与同款商品的实时到手价、历史到手价，结合行业合理价格水平，综合计算得出（由低到高，1星到5星，越高越好）。

| **价格星级** | **价格竞争力级别** | **赋星标准** |
| --- | --- | --- |
| 五星 | 优 | 实时及历史比价均全网最优 |
| 四星 | 良 | 实时或历史比价全网最优 |
| 三星 | 中 | 该商品近期日常销售价 |
| 二星 | 差 | 当前价格处于历史高价 |
| 一星 | 极差 | 当前价格严重偏离行业合理水平 |

### 2.1.2“价格星级”能为商家带来什么好处？

**1、流量提升：** 高星（四星、五星）商品能获得更多搜索、推荐流量；

**2、营销活动机会**：参与秒杀、排行榜等营销活动机会；

**3、可感知的权益：** 消费者可见的【价格标签】，促进转化；

## 2.3 商机

### 2.3.1 商家相关指标解释

| **指标名称** | **分类** | **数据口径** |
| --- | --- | --- |
| 市场热度 | 需求 | 相关商品在市场的累计销量，数据仅供参考（月粒度更新） |
| 需供比 | 竞争 | 搜索用户数/平台在售商品数量。需供比越高，代表消费者需求强供给少，竞争越小，更易成交 |
| 曝光商品量 | 供给 | 近7天在搜索结果有曝光的商品数，SKU维度去重统计 |
| 曝光商家量 | 供给 | 近7天在搜索结果有曝光商品的商家，商家去重统计 |

### 2.3.2 商机核心价值

1. **供需平衡优化**：发现供给不足或竞争过热的细分市场，调整商品策略，优化平台商品结构。
2. **市场趋势预判**：通过市场数据分析，识别高潜力品类及爆品趋势，辅助制定采购与库存策略。
3. **商家运营指导**：基于商机洞察，主动向商家推荐潜力商品方向，提升商家发品效率与平台商品竞争力。
4. **数据驱动决策**：提供多维数据分析（如需供比、热度、建议价等），支持策略制定与复盘。

### 3.3.2 操作步骤

1\. 商品价格星级数据查询

本步骤使用的接口： [jingdong.grow.ware.price.star.query](https://open.jd.com/v2/#/doc/api?apiCateId=48&apiId=10743&apiName=jingdong.grow.ware.price.star.query)

- 获取商品当前的价格星级及竞争力

![](https://joscms.jd.com/doc/img/000000EkmLn5tubFp5xqm5finYxK1J6jTI1HDN5pnuleLurMyXNiZ2Oi8J73iBzzHgRUfPeqNTtYZsvIIIK7ndslUEhzy54)

2\. 商品建议价查询

本步骤使用的接口： [jingdong.grow.ware.price.suggest.query](https://open.jd.com/v2/#/doc/api?apiCateId=48&apiId=10733&apiName=jingdong.grow.ware.price.suggest.query)

- 查询商品的星级建议价（下一个目标星级的建议价）、标签建议价（降价幅度最小可获得标签的建议价）、搜索建议价（提升销量或流量降幅最小的搜索建议价）

本步骤使用的接口： [PATCH sp-product/v0/product-applies/{applyId}](https://open.jd.com/v2/#/doc/api?apiCateId=200375&apiId=100583&apiName=patchProductApply&gwType=1)

- 使用商品原子更新接口可支持编辑商品京东价

4\. 价格变更记录数据回传

本步骤使用的接口： [jingdong.grow.ware.price.change.record.create](https://open.jd.com/v2/#/doc/api?apiCateId=48&apiId=10744&apiName=jingdong.grow.ware.price.change.record.create)

- 改价记录需按格式回传京东平台，用于监测和统计各服务商的改价信息，官方平台会每周看信息回传的完整度和量级，针对回传不完整或不回传的会逐步限制接口调用和下线

## 四、常见问题

## 5.1 业务类常见问题

1. wareId、spuId、skuId的区别是什么？

wareId是京东商品Id，spuId是标品Id，skuId是sku的唯一标识。

1个wareId下可以有N个skuId，1个skuId只能属于1个wareId，1个wareId绑定1个spuId

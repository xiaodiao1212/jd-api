# jd-product-spec-check

先确认商品品类和需要校验的字段，只读取对应品类标准。字符计数按京东规则：汉字计 2，英文/数字/符号计 1；要求性、建议性与优化项分别报告。品类标准优先于通用汇总，无法确认或过期的规则标明待核实。

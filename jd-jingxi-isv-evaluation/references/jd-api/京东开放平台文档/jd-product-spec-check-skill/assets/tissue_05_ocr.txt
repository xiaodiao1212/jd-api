04 { 短标题 } SPECIFICATION

总结：短标题结构化展示、精简重要信息

结构建议：
【品牌】+【核心功能功效/卖点】+【产品词】（抽纸/卷纸等）+【核心规格】
例如：某某品牌超韧山茶花抽纸4层90抽20包

字符范围：
16-30个字符（一个汉字等于2个字符，数字、符号、英文算作1个字符）

不同类目短标题规则如下（黑色为必填，灰色为非必填）：

05 { 通用卖点 } SPECIFICATION

总结：
避免技术化和工业化的用语，使用用户理解的语言。

转化示例：
卖点表述"加厚"→ 换成用户关心"湿水不易破""湿水不烂絮"。

示例：
柔韧不掉屑、湿水不易破、吸水强、无荧光剂、柔软亲肤、强韧耐用、抑菌

{ 整体规范综述 }

商品信息围绕用户选购需求基础上，通过优化商品主图、标题、开通主图小图优化SPU系列化绑定、商详基础内容，提升流量转化效率。

● 主图：结构化，核心决策信息聚焦于首屏主图位置，从而提升选购效率

● SPU绑定：标准化，制定不同品类绑定规则，模糊信息标准化、简单清晰可识别

● 标题：规范化，长标题是商品编辑/发布页维护的标题，用于展示、召回和排序；短标题仅用于用户展示，务必清晰便于用户记忆识别

● 详情页：模块化，选购指引加速建立信任，促成转化

01 主图规范：结构化

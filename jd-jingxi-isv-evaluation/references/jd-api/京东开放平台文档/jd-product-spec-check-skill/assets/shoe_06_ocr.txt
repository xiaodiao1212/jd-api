03 { 开箱测评/主图画廊 } UNBOXING EVALUATION

开箱测评和主图画廊是对主图静态图片的补充功能，可以具象化呈现卖点。用户通过点击开箱测评或主图，展开两屏级优质内容（图文和视频）瀑布式排列，带来「翻阅感」和视觉沉浸感，比起传统主图，提升了内容多样性，丰富该屏信息，提升订单转化。

优质规范：
封面：直击痛点／共鸣；
内容：具备看点／突出卖点；
音画：快节奏／高情绪／强连续。

04 { 图文详情 } DETAILS OF PICTURES AND TEXTS

整体视觉质量要求：

● 【产品信息-清晰】：展示材质、耐磨系数、防滑系数等核心参数，可验证且与检测报告一致。
● 【尺码信息-多维】：结合脚长、脚宽、楦型、制作测量图示，避免尺码不合导致退货，与描述一致。
● 【配色展示-标准】：色差零容忍，以色卡模式完整展示所有颜色，标注色名，确保与描述一致。
● 【模特展示-真实】：真人模特多角度（正／侧／背）上脚，直观展示穿着效果与适配人群。
● 【亮点细节-突出】：特写防滑纹路、缝线、认证标识，鞋垫结构。
● 【场景展示-生活】：通过运动、户外、居家、雨天等场景图，激发联想，强化适用性。
● 【实拍展示-真实】：自然光或暖色调实拍，不过度修图，真实反映色差、质感与做工。
● 【贴心内容-实用】：提供防磨脚小贴士、材质知识、保养须知，降低售后咨询。
● 【品牌背景-信赖】：渗透品牌理念，精品展示装饰及物流包装，打消顾虑。

第2屏 参数、配色与尺码：建立信任。详尽展示产品参数（材质、耐磨系数、防滑系数等）、配色展示（色卡+全名）、尺码信息（脚长／脚宽对应表+测量图示）、模特上脚图（多角度）、亮点细节（纹路和缝线、电绣工艺、鞋垫结构），帮助用户合理决策从而降低退货率。

05 { 标题 } COMMODITY TITLE

短标题（列表页吸引用户点击，搜索点击量提升 ↑） AI

● 字数范围：含品牌，16-50个字符（一个汉字等于2个字符，数字、符号、英文算作1个字符）
● 结构：【品牌】+【产品词】+【适用场景】/【功能卖点】/【材质特征】/【风格趋势】
● 组合规则：从「适用场景、功能卖点、材质特征、风格款式」中精选1-2个关键词，严禁堆砌
● 可选词库参考：
　适用场景：居家、通勤、户外工地、跑步、沙滩、办公室
　功能卖点：防滑、静音、防穿刺、抗静电、保暖、透气、防水（低／中／高帮）
　材质特征：EVA、真皮、网布、橡胶、帆布
　风格款式：厚底、高帮、低帮、复古、运动、商务
● 品类适配参考：
　拖鞋侧重【材质特征】+【适用场景】，如「EVA室内居家」
　功能鞋侧重【适用场景】+【功能卖点】，如「工地防穿刺」
　休闲鞋侧重【材质特征】+【适用场景】，如「网布夏季通勤」
　鞋类侧重【风格款式】+【功能卖点】，如「中筒复古」〔末条「鞋类侧重」配图小字若有出入：字迹不清〕

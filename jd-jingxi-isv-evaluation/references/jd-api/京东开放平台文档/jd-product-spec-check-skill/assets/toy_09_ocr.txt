04
{ 短标题 }
SPECIFICATION

■ 效果数据：搜索点击率 ↑

■ 总结：短标题结构化：品牌+IP/外观造型+产品名+规格+营销词

■ 字数：16-30个字符（1个英文字母、数字、符号代表1个字符；1个中文字代表2个字符）；特别关注品牌名占用字符数，展示优先级：中文名称>英文名称缩写。

注意：规避营销词不良引导（如买一送一、TOP1）。

■ 建议：

卖点选词优先级：
● 用户语言表达，对比标题的工业化表达，卖点词更注重商品特色和“解说性”。

建议方向：
● 每个商品的卖点数量至少满足2个，同时每个卖点字数在4-8字（1个中文、1个英文字母、1个数字都算作1个字）。

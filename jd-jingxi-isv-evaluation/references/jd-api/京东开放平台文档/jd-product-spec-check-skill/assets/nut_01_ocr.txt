{ 整体规范综述 } INTRODUCTION

商品信息围绕用户选购需求，通过优化产品主图、主图视频、标题、卖点、属性、品质标签等10项基础内容，优化用户体验，提升转化率。

● 【主图】：
主图首张包含主图信息要素：商品名、商品展示、规格、品牌、卖点和价促。主图前五张：第1-2张商品核心卖点+第3-4张聚焦商品品质细节和食用场景+第5张商品相关背书图（如证书/商品尺寸等）。丰富主图类型：在素材中心补充卖点图、场景图、白底图、透明图，满足商品在不同场域的呈现形式。

● 【主图视频】：
拍摄风格建议以种草向/商品展示/工艺或产地介绍，时长控制在40秒以内。

● 【长标题】：
结构化：品牌+品名+形容词+规格。规格表达以“（单件净含量*数量）或（总净含量+含数量）”为准，标明克重。

● 【短标题】：
结构化：品牌+品名+形容词+规格；精简表达，形容词由2-3个词组构成。

● 【卖点】：
对比标题的工业化表达，卖点词更佳注重“趣味性”和“解说性”；优先选择长标中存在但短标字数受限无法展示的关键形容词，避免与短标信息重复。

● 【属性】：
①属性需要与长短标题、卖点、已选弹层、主图等商详外露信息保持一致，避免引起客诉和不必要用户流失；②增加用户高搜的通用属性覆盖率。

● 【尺码绑定】：
结构化命名：核心卖点+简短品名+（单件净含量*数量）或（总净含量+含数量）+包装形式。关注：不同末级避免捆绑在同一SPU下。

● 【系列品】：
同店内建议以经营多细分类目且垂类品牌店铺搭配组合；以“类别/规格/包装/口味/品质/成分/是否有壳有核/价促”为主题划分。

● 【主推标签】：
主推标签是对主推商品配置打标的工具，商家完成配置后，在京东APP上会有对应的“主推”标识，用户在浏览商品详情时，能直观的看到主推商品标志，主要提升商品的加购转化。

● 【品质标签】：
基于行业制定更高质检标准，建议以产地、工艺和配料或关键成分为主。

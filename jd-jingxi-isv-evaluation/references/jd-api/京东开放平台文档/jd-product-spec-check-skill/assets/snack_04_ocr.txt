02 { 主图视频(建议方向) } MAIN PICTURE VIDEO

建议：
拍摄风格以种草向/商品展示/场景消费向介绍，视频建议15-30秒。
视频确保高清、明亮、稳定，有助于用户了解产品。
视频需要搭配字幕、有助于用户在无声环境观看；BGM以轻松纯音乐为主，可搭配口播卖点更佳。
时长：视频建议15-30秒。

视频结构：
种草向：核心卖点（口味/酥脆/原料/轻负担）+工艺展示（安全健康）+真人互动展示商品（手抓/咬开）+附加场景（追剧/下午茶/分享）+口感表达（咔擦/酥脆）。

视频类型｜内容要求｜时长

种草向｜核心卖点+工艺展示+真人互动展示商品+附加场景+口感表达｜15-30秒

商品展示｜商品展示+卖点表达（酥脆/原料），镜头——聚焦商品本身，突出膨化体积感、产品形态、倒落/堆叠等视觉效果｜20-30秒

场景消费类｜商品+消费场景（追剧/聚会/办公零食），突出解馋与分享属性｜15-30秒

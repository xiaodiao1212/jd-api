{ 整体规范综述 } INTRODUCTION

整体文字排版规整有序，不同层级信息在字体大小、颜色、粗细等方面需明显区分；色彩搭配符合品牌形象与产品特点，保证色调协调统一；图片需保证高分辨率、无模糊失真，提升整体宣传效果与用户体验。

● 【主图】主图首张：
主图规范采用模块化布局，将画面划分为6个模块，帮助用户在短时间内捕捉关键信息，提升点击意愿与信息吸收效率。

● 【主图视频】：
拍摄风格主要是实物展示与产品实际使用，种草和商品展示视频建议5-10秒；产品实际使用或实验对比5-10秒。

● 【长标题】：
长标题结构化：品牌+[类别/类型]（悬挂式/无芯）+产品词+核心规格+适用场景/范围+核心功能功效/卖点（原料成分/工艺/品质/包装形式）+[资质]。核心规格表达以"层数*抽数/卷数*包数"为准，卷纸标明克重。

● 【短标题】：
短标题结构化：品牌+核心功能功效/卖点+产品词+核心规格；精简表达，确保信息层级清晰且前后一致，快速抓取用户核心关注点。

● 【卖点】：
卖点词更加偏向用户语言，严禁夸大或虚假宣传功效信息。

● 【参数楼层&属性】：
将用户关注的参数信息从商详最下方的属性模块上提至参数楼层，故①属性需要与长短标题、卖点、已选弹层、主图等商详外露信息保持一致，避免引起客诉和不必要用户流失；②增加用户高搜的通用属性覆盖率（如原料成分、是否压花、是否独立包装、功能）。

● 【系列品】：
同店内建议以经营多细分类目且垂类品牌店铺作搭配组合；以"类别/系列/联名/原料成分/包装形式/尺寸"为主题划分。

● 【主推标签】：
主推标签是对主推商品配置打标的工具，商家完成配置后，在京东APP上会有对应的"主推"标识，用户在浏览商品详情时，能直观的看到主推商品标志，主要提升商品的加购转化。

● 【一诺千金】：
"一诺千金"是京东超市联合生活用纸品牌推出的品质保障活动，商家完成配置后，会有对应的"品质保真"标签，承诺商品抽数符合国家标准。

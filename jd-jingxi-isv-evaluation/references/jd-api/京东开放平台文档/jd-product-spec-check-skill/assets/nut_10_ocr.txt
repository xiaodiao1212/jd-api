08 { 尺码绑定 } SIZE BINDING

规则
● SKU的末级类目、品牌、SPU一致化属性等信息需要保持一致。

作用
● 共用权重、评价等，避免用户在相似商品间反复对比，减少流失；便于流量集中；减少重复操作，提升运营效率。

建议
● 结构化命名：核心卖点+品名（简短美观品名为主）+（单件净含量*数量）或（总净含量+含“数量”）+包装形式（礼盒装需特别强调）。

案例
● 优秀案例：〔图示：SKU列表〕示例文案方向：〔三只松鼠_开口松子〕160g*3袋 休闲零食〔引线：核心卖点+品名｜规格信息｜包装形式〕
● 待改进：〔图示：规格选择区红框〕旁注：子类目规格建议一致-sku?

09 { 主推标签 } MAIN PUSH LABEL

● 主推标签是对主推商品配置打标的工具，商家完成配置后，在京东APP上会有对应的“主推”标识，用户在浏览商品详情时，能直观的看到主推商品〔字迹不清〕，主推提升商品的加购转化。

展现样式
● 〔图示：商详/选规格/楼层等三屏，含「主推」「主推款」等样式〕

10 { 品质标签 } QUALITY LABEL

建议
● 基于行业制定更高质检标准，建议以产地（地理标志产品）、工艺（中华老字号、药食同源）和配料或关键成分（高蛋白、高钙、0脂、配料干净）为主。安心品质目前为京东特有品质楼层，同品竞对没有特殊露出。

展现样式
● 搜索页面｜商详页面｜证书页面〔三屏示意图〕

标签名与标签要求

标签名：配料干净
标签要求：本产品通过《京东自营商品配料干净品质认证标准》要求，京东倡导食品配料简单干净，在满足食品工艺基础上确保不使用“非必要”的食品添加剂、“非必要”的食用香精香料以及可能存在的健康风险配料，让广大消费者享受更加天然、纯粹的美味食品。

标签名：药食同源
标签要求：传统作为食品，且列入《中华人民共和国药典》的物质。由国家卫生健康委会同市场监管总局制定发布《按照传统既是食品又是中药材的物质目录管理规定》，根据传统食用历史证明、食用安全性评价资料等及时审查、更新食物物质目录。目前已公布纳入食物物质目录的物质106种。

标签名：中国有机
标签要求：指在生产过程中不使用农药、化肥、生长调节剂、抗生素、转基因技术，经过中国有机认证机构认证的食品。

标签名：地理标志产品
标签要求：是指产自特定地域，所具有的质量、声誉或其他特性本质上取决于该产地的自然因素和人文因素，经审核批准以地理名称进行命名的产品。

主图优化基础要求
● 整体文字排版有序，不同层级信息在字体大小、颜色、粗细等方面层级区分清晰。
● 色彩搭配需符合品牌形象与商品特征，保证和谐统一。
● 图片需保证高分辨率、无模糊失真，提升宣传效果与用户体验。
● 建议营销文字占比不超过图片面积的35%。

主图首张核心要求
● 信息要素：商品名、商品展示、规格、品牌、卖点。
● 品牌：以醒目字体与色彩展示品牌名与广告语，强化品牌认知与信任。
● 产品与核心卖点：品名清晰，便于用户识别品类；展示1-3个核心差异化卖点。
● 产品展示：商品主体（展示产品形态）+产品细节展示（质感/口味的直观感受）+场景（凸显原料及消费场景）。
● 信任背书：简洁传达关键信任信息以增强用户信心。〔落款/认证小字以对图核对为准〕
● 价格促销/商品名：位于画面下部，可使用撞色设计以增强吸引力；可含到手价、限时补贴、赠品等促销信息。

主图前五张建议方向
1. 第1张（卖点）：主体+核心卖点+促销（产地/工艺/场景/口味/口感/健康原料/品质/包装形态）。
2. 第2张（卖点）：强化核心差异化卖点。
3. 第3张（卖点）：口味卖点、产品细节、口感可视化呈现（激发食欲）。
4. 第4张（卖点）：品质（品类介绍+原料是否进口等）。
5. 第5张（场景）：产品消费场景（聚会/早餐/分享/童年回味等）。
● 差异化补充：检测报告、品牌背书、配料表/营养成分表——物理呈现（①简表直观；②产品成分明细表）。
● 丰富素材类型并可于素材中心补充：场景图、透明图、白底图、卖点图。（路径：京麦-商品-素材管理-商品素材）

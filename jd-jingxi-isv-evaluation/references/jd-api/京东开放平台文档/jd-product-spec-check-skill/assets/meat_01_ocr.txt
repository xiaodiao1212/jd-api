{ 整体规范综述 } INTRODUCTION

围绕用户选购需求和决策关注点，通过优化商品主图、主图视频、标题、卖点、属性、品质标签等10项基础内容，优化用户体验，提升转化率。

【主图】：
主图首张：包含信息要素商品名、商品展示、品牌、核心&营销卖点、价促。
主图前5张：第1张卖点图 + 第2-3张产品明细图（成分表&产品信息图、细节特写、制作工艺） + 第4-5张补充图（包装细节、搭配场景、烹饪方法、品牌资质、送礼场景）。
丰富素材圈类型：在素材中心补充卖点图、场景图、白底图、透明图，满足商品在不同场域的呈现形式。

【主图视频】：
拍摄方向可参考种草开箱、工艺展示、品质特写、场景/烹饪方法（烹饪画面控制在5~8s内，聚焦“简单易操作”），多种方向可进行组合。建议时长控制在60s内。

【长标题】：
长标题结构化：品牌+品名+形容词（地域/工艺/场景/口味/口感/健康成分/品质/包装）+规格。
规格表达以“（单件净含量*数量）或（总净含量+含数量）”为准，标明克重。

【短标题】：
短标题结构化：品牌+品名+形容词+规格；字符不超过30。

【卖点】：
对比标题的工业化表达，卖点词需要以用户语言表达，通俗易懂、快速辅助决策。优先选择长标中存在但短标字数受限无法展示的关键形容词，避免与短标信息重复。方向可参考“产地&特产、工艺、适用场景、口感风味、健康成分、品质特征、包装形式、食用方式”。

【属性】：
①属性需要与长短标题、卖点、已选弹层、主图等商详外露信息保持一致，避免引起客诉和不必要用户流失；②完善用户关注的属性。

【系列品】：
店内建议以经营多细分类目且垂类品牌作为组合搭配，为用户提供高关联商品，缩短用户购买链路和决策时效。
可尝试以“类别/包装/口味/品质/成分/礼盒/适用场景”为划分主题。

【尺码绑定】：
结构化命名：核心卖点+简短品名+口味+规格（“单件净含量*数量”或“总净含量+含数量”）。避免不同末级类目商品捆绑在同一SPU下。

【主推标签】：
商家可选择对各SPU下的主推荐SKU进行打标，配置完成后APP端会展示“主推标识”，帮助用户缩短决策时效、提升商品加购转化。

【品质标签】：
对有资质认证的商品进行打标，强化品质表达、增加用户信任，打标成功后会在搜索和商详展示。建议以产地（地理标志产品）、工艺（中华老字号）和配料/关键成分（高蛋白、高钙、0脂、配料干净）为主。

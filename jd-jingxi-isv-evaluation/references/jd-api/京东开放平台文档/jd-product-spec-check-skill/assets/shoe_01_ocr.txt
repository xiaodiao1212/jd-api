更新日期：2026年4月16日

{ 整体规范综述 }
INTRODUCTION

商品信息优化应紧密围绕用户选购决策路径，通过系统化提升主图、视频、开箱测评/主图画廊、图文详情、标题、卖点、属性、尺码助手、安心品质、主推标签、规格图和系列品十二个模块的信息质量，实现流量转化效率的最大化。

● 主图规范：信息逻辑精简聚焦，营销区域面积占比建议在35%以内，主图集内容建议包括整体呈现、材质与卖点、多角度细节、颜色及尺码建议四部分。
● 主图视频：建议视频时长不低于15秒，结构化建议包括快速识别产品、卖点集中展示、穿搭场景展示、强化信任引导购买四部分，垂类视频内容包括产品展示类和卖点讲解类。
● 开箱测评/主图画廊：作为主图静态图片的补充内容，可提供高颜值优质内容，增强用户决策信心。
● 图文详情：首屏抓住注意力，展示产品海报与基础信息；2-4屏诠释尺码适配、品质认证与多角度细节；5-8屏详细介绍材质工艺、穿着体验、场景实拍与服务保障。
● 标题：结构化建议明确，不同品类差异化参考。短标：【品牌】+【产品词】+【适用场景】/【功能卖点】/【材质特征】/【风格款式】；长标：【品牌】+【性别】+【产品词】+【上市时间】+【适用人群】+【适用场景】+【功能/特色卖点】+【鞋面材质】+【鞋底材质】+【适用季节】+【颜色】+【尺码】。
● 卖点：将参数转化为消费者可感知的语言，突出鞋类材质优势、功能特色与技术理念，凸显品质感、舒适感与性价比。
● 属性：属性值须真实、可验证，与标题、卖点逻辑一致，禁止矛盾、夸大或虚假描述，避免客诉。
● 尺码助手：为消费者精准推荐适配尺码，降低尺码原因退换货率，提高商详订单转化率。
● 安心品质：上传检测报告，如耐磨、抗菌性能等，在商品详情页清晰透传权威背书抢占用户“耐穿、舒适、安全”的心智，降低咨询并提升转化。
● 主推标签：配置主推商品标识，用户浏览下单时可见，提升爆品订单转化率。
● 规格图：展示商品细节，优化用户体验，提升加购率，降低退换货率。
● 系列品：提升连带销售，推荐高关联商品，促进跨品类连带销售。

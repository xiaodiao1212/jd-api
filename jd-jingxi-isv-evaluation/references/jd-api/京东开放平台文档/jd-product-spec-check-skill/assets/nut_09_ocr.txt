05 { 通用卖点 } SELLING POINT OF GOODS

建议
● 卖点选词优先级：
● 长标题中存在但短标题字数受限无法展示的关键形容词，避免与短标题信息重复。
● 用户语言表达，对比标题工业化表达，卖点词更佳注重“趣味性”和“解说性”。
● 建议方向：产地、工艺、场景、口感、成分、品质、包装形式、丰富度。
● 卖点数量满足3个/SKU，同时每个卖点字数在4-8字符（1个中文、数字都算作2个字符）。

示例展示
● 口感风味：酸甜可口，奶香浓郁
● 品质特征：颗粒饱满，皮薄肉厚
● 工艺：无核，免剥即食，低温烘焙
● 产地特色：韩国特产，果圆色深，内蒙〔字迹不清〕源
● 适用场景：送礼佳品，出游零嘴
● 成分：5种果干组合，坚果含量55%

06 { 属性 } COMMODITY ATTRIBUTES

建议
● 额外加成：积极补充4种以上属性信息，在商详页会有额外楼层露出，有助于提升用户转化。
● 信息丰富度：通用属性提升覆盖率（口味、包装形式、类别、总净含量、产地）；差异化属性建议如下针对性补充。
● 坚果炒货：是否去壳；蜜饯果干：是否有核、工艺；奶制品零食：国产/进口、产地。
● 填写规范：属性需要与长短标题、卖点、已选规格、主图等商详外露信息保持一致，避免引起客诉和不必要用户流失。

信息不一致案例
● 〔图示：商详截图红框〕特性：无核；是否有核：有核〔冲突示例〕
● 截图其他可见小字：2025.12 生产日期｜二等 等级｜店铺｜客服｜购物车｜加入购物车｜到手价 立即购买〔以原图为准〕

07 { 系列品 } SERIES PRODUCTS

规则
● 同店铺、同品牌、同三级类目可绑定（三级类目可以跨类目绑定）。可展示2-6个SPU；单店铺内最大绑定2000个系列品组。

说明
● 通过为用户推荐高关联商品，来缩短跳转和决策路径，提升消费者的购物体验和商家的销售转化率。

建议
● 同店内，本次建议以经营多细分类目且垂类品牌店铺（如三只松鼠、沃隆等）作为初次搭配测试建议；以【类别/规格/包装/口味/品质/成分/是否有壳有核/价促】为主题划分。

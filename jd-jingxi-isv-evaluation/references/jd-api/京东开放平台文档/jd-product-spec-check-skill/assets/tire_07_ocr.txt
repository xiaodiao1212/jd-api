■ 短标题结构规范：[品牌] + [产品词] + [轮胎规格] + (可选信息)
■ 可选信息：轮胎花纹 / 适用车型 / 花纹性能（三选一或组合，用空格分隔）
■ 字数要求：整个标题控制在8-15个汉字（30个字符内），1个英文字母/数字/符号 = 1字符
■ 产品词选项（选择其一）：汽车轮胎、静音棉轮胎、防爆轮胎、自修补轮胎、雪地轮胎
■ 可选信息填写建议：
  • 轮胎花纹：根据产品匹配（如米其林Primacy系列）
  • 适用车型：优先热门车型（如大众途观 / 宝马X5）
  • 花纹性能：如舒适静音、防滑耐磨等

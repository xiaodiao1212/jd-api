4. 丰富素材图类型
上传路径：京麦-商品-素材管理-商品素材

素材图类型	内容要求	示例

白底图	纯白底无营销内容 1:1方图	〔示例：罐装鹰嘴豆、袋装花生白底〕

卖点图	含卖点文字信息的 1:1方图	〔示例：南瓜籽配高钾高镁高蛋白等卖点字｜花生配传统工艺等字〕

场景图	带背景无营销内容 1:1方图	〔示例：亲子食用场景｜苹果干泡水场景〕

透明图	透明背景无营销内容 1:1方图	〔示例：核桃仁、芒果干透明底〕

02 { 主图视频 } MAIN PICTURE VIDEO

建议
● 拍摄风格以种草向/商品展示/工艺或产地介绍；种草和商品展示视频建议15-30秒；工艺和产地介绍建议30-40秒。
● 视频确保高清、明亮、稳定，有助于用户了解产品。
● 视频需要搭配字幕，有助于用户在无声环境观看；BGM以轻松纯音乐为主，可搭配口播卖点更佳。

视频结构
● 种草向：核心卖点（各类成分/易食）+真人互动展示商品（亲自剥开/撕开）+附加场景（泡酒/泡茶等）+工艺/功效。
● 工艺或产地介绍向：工艺或产地介绍（场景再现）+商品原料和加工品呈现（体现品质）+附加场景（泡酒/泡茶等）+工艺/功效。

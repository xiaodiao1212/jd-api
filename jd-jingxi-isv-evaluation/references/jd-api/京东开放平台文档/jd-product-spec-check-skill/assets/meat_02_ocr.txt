主图优化基础要求

● 排版：文字排版整齐有序，不同层级信息在字体大小、颜色、粗细等方面区分清晰，字体尽可能保持一致；
● 配色：色彩搭配需符合品牌形象与商品特性，协调统一；
● 画质：图片须保证高分辨率、无模糊失真，提升整体宣传效果与用户体验。

首张主图-核心要素
（品牌、商品名、商品展示、核心卖点、规格、价促）

● 品牌：使用醒目的字体与颜色展示品牌名称及传达核心价值观的 slogan，强化品牌识别与信任；
● 产品词及核心卖点：清晰写明商品品名以便快速识别，展示 1～3 个核心差异化卖点；
● 商品展示：包含商品主体（呈现形态）、商品细节展示（可视化味觉/风味感知）、场景（突出原料与食用场景）；
● 信任背书：简明传达关键信任信息，善用对比呈现以增强用户信任；
● 价格促销：位于图片底部，采用撞色设计增强视觉吸引力，包含活动到手价、限时补贴、赠品等促销信息。

主图结构化-前五张（建议方向）

● 第1张：主推商品 + 核心卖点 + 价促（产地 / 工艺 / 场景 / 口味 / 口感 / 健康成分 / 品质 / 包装形式）；
● 第2张：激发食欲（肉类特写画面，风味与口感可视化）；
● 第3张：加深用户理解（配料表 & 产品信息图 & 配料清单、制作过程介绍、肉源产地）；
● 第4张：匹配需求（包装细节展示、多适用场景展示、多种烹饪/食用方式展示、品牌资质）；
● 第5张：品牌资质相关，建立信任（品牌介绍、资质认证说明、质检报告等）。

丰富素材图类型

为获取更多流量，建议除前五张主图外，在京麦素材中心补充：白底图、透明图、场景图、卖点图。

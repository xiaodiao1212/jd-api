02 { 标题：结构化 } PRODUCT TITLE

短标题：
字符范围：16-30个字符
结构建议：品牌+型号+品类
示例：石头A30CE洗地机大吸力0缠绕

长标题：
字符范围：90个字符
结构建议：品牌名+系列名（如有）+型号+品类+通用卖点（2-4个）+趋势词
说明：通用卖点指用户关注的功能点，如0缠绕等

趋势词（示例）：
超薄、0缠绕、大户型、嵌入式、长续航等

03 { 卖点：差异化 } SELLING POINTS

消费者关注：
吸力、清洁效果/效率、续航、口碑、性价比等；卖点优先级按消费者高频咨询问题排列

基础卖点：
吸力、真空度、平躺角度、拍打频率、滚刷转速、最低噪音、水箱容量、吸头数量等

产品性能：
助力方式、平躺角度、平躺高度、特色功能、集尘容量等

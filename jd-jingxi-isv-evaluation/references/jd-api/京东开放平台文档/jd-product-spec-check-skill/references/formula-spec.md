# 奶粉商品信息运营规范

> **来源：** 京东商品运营中心「官方建议」  **文档入口：** 麦头条 / JoySpace 等官方专题（内嵌原图以公示为准）  **规范原图更新日期：** 2024 年 4 月 21 日（见 OCR 首图）  **整理归档：** 2026 年 4 月 22 日  **提取方式：** OCR 识别原图内容  
> **说明：** 官方对「官方建议」的诠释为经验与方法参考，**并非强制性平台规则**；下文仍按原文区分文档中的要求表述与运营建议，便于自检时区分轻重。

## 一、整体规范综述（八大模块）

商品信息优化运营围绕用户意向决策路径，通过系统化提升以下**八大模块**的信息质量，实现流量转化效率最大化【官方综述】：

| 模块              | 核心表述（摘取自 OCR）                                       | 类型   |
| ----------------- | ------------------------------------------------------------ | ------ |
| **主图**          | 首图视觉区功能区域明确，信息层级清晰，动线流畅；营销贴片过多时需优化样式；赠品不多时首图可介绍主要营销活动与成分/效果 | 建议性 |
| **标题**          | 「品牌 + 核心要素」的结构；突出系列、产品词、规格、成分特点、营销词；信息层级清晰且前后一致 | 要求性 |
| **卖点**          | 覆盖主要成分信息、认证信息、冲调方式、健康引导、使用感受、奶源地、包装形式等；语言精准，**严禁夸大或虚假宣传诱导消费** | 要求性 |
| **属性&参数楼层** | 属性准确全面，提升搜索/筛选等场景；参数楼层展示关键属性，减少咨询与退货，提升转化率 | 要求性 |
| **安心品质**      | 上传权威认证报告类素材，在商详页安心品质楼层展示，建立「安全心智」与品质信任 | 建议性 |
| **主推标签**      | 商详/加购等环节露出主推标识，助力加购转化                    | 建议性 |
| **SPU 尺码绑定**  | SKU 规格命名按规范、展示顺序有逻辑，便于选购                 | 建议性 |
| **商品使用指南**  | 结合高频咨询配置说明书，促售前转化、降售后咨询               | 建议性 |

## 二、主图规范

### 2.1 效果数据（原文）

- 方图商详转化 **+5.48%**；长图商详转化 **+12.99%** ↑【效果数据】

### 2.2 主图基础要求

| 项目           | 规范要求                                               | 类型   |
| -------------- | ------------------------------------------------------ | ------ |
| **文字与层次** | 排版规整有序；不同层级信息在字号、颜色、粗细上区分清晰 | 建议性 |
| **色彩**       | 背景与主体、文字搭配协调                               | 建议性 |
| **画质**       | 高分辨率、无模糊失真                                   | 要求性 |

### 2.3 首图模块化布局

| 区域          | 要求                                                      | 类型   |
| ------------- | --------------------------------------------------------- | ------ |
| **品牌 Logo** | 左上角，清晰可见                                          | 建议性 |
| **产品展示**  | 商品正面；背景可选纯色或商品包装接近或贴合的色彩          | 要求性 |
| **卖点提炼**  | 一句话概括主要营销点 + **2–4 个**核心卖点，精炼、直击痛点 | 建议性 |
| **赠品贴片**  | 左下侧，清晰整洁，能描述、突出赠品且让用户直观看到        | 建议性 |
| **促销贴片**  | 下方展示单件到手价及活动信息，便于比价与了解时效          | 建议性 |

### 2.4 主图第 2～5 张（长图建议）

| 张序          | 内容                                                         | 类型   |
| ------------- | ------------------------------------------------------------ | ------ |
| **第 2 张**   | 赠品多：补充福利，用「省钱攻略/享好礼」等字样吸引；赠品少：可增引导文案，写使用后益处 | 建议性 |
| **第 3–5 张** | 详细描述核心成分或作用（用户语义），展示产品升级/专利技术/产线迭代等 | 建议性 |

首图权重高，需在「黄金 5 秒」内强化成分与核心卖点【原文表述】。

### 2.5 优质主图结构化示例（长图 / 方图）

**长图结构要点：** 品牌名 → 商品卖点(核心营销词+主要卖点信息） → 商品正面展示图  → 赠品贴片信息  →  促销贴片信息(单件到手价及活动时间)

**方图结构要点：** 品牌名 → 商品正面展示图 → 商品卖点(核心营销词+主要卖点信息）→ 赠品贴片信息 →  促销贴片信息(单件到手价及活动时间)

### 2.6 赠品场景对比表（第 2 张、第 3～5 张）

| 赠品场景       | 赠品较多时                                                 | 赠品较少时                                                 |

## 三、长标题规范（商详场域）

### 3.1 效果数据

- 商详转化 **+0.2%** ↗【效果数据】

### 3.2 字数与品牌位

- **60 个字符以内**（汉字/全角符号=2个字符；字母/半角符号/数字=1个字符）【要求性】  
- **品牌信息系统自动关联，无需单独填写且不占用字符数**【要求性】

### 3.3 成分特点 / 营销词示例

## 五、通用卖点规范

### 5.1 效果与数量

- 搜索点击率 **+0.76pp** ↗【效果数据】  
- 每个 SKU可维护 **3 个**卖点；每个卖点 **4–16 字符**（汉字/全角符号=2个字符；字母/半角符号/数字=1个字符）【要求性】

### 5.2 核心规则

- 参数转化为消费者可感知语言，突出特点；**勿夸大或虚假宣传**【要求性】

### 5.3 填写维度建议（需与长/短标题差异化表述）

将包装特点&送礼属性（小包装方便携带）、认证信息（欧盟认证）、健康引导（三重防护力）、使用感受（清淡口感）、奶源地（新西兰奶源）、科学配方（添加乳铁蛋白）、送礼属性（送爸妈健康）等维度进行用户语义转述，突出商品特点的可理解性，并与长/短标题做差异化信息表述。

## 六、属性与参数楼层

### 6.1 效果数据

- 参数楼层商详转化 **+3.87%～6.45%**（不同类目有差异）↗【效果数据】

### 6.2 填写规范

- 提升准确率与挂靠率；与**长/短标题、卖点、已选弹层、主图**等保持一致，利于搜索与筛选，减少客诉与用户流失【要求性】

### 6.3 参数楼层

- 将用户关注参数从商详底部属性**上提**至参数楼层；自营商品支持**外露生产日期**【建议性】

### 6.4 一致性反面示例（原文摘意）

- **信息不一致：** 标题段位与已选规格段位冲突（示例截图标注）【要求性】  
- **前台效果：** 参数行展示生产日期、保质期、国产/进口、成分特点等信息【建议性】

## 九、SPU 尺码绑定（规格命名）

- SKU 规格名称建议**结构化**：产品简称/系列（非必填）、**段位**（婴幼儿奶粉必填，其他类目可非必填）、单件净含量*包装规格、卖点/营销词（非必填）；注意**顺序与易读性**【要求性】

## 十、商品使用说明

- 结合高频售前/售后咨询，配置**商品使用说明书**：卖点信息（如优质奶源地）、使用方法、注意事项、常见问题答疑等【建议性】  
- FAQ 示例主题含：奶源产地、结块现象、黑色/黄色小颗粒、颜色差异、绿便、上火等（原文为示意，以实际审核与合规为准）【建议性】

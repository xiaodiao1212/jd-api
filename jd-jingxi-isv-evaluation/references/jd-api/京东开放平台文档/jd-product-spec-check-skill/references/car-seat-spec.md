## 一、整体规范综述

商品信息优化应紧密围绕用户选购决策路径，通过系统化提升主图、标题、卖点、属性、安心品质、主推标签和图文详情七大模块的信息质量，实现流量转化效率的最大化。

### 1.1 七大模块核心要求

| 模块         | 核心要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **主图**     | 主图第一张需划分明确的功能区域，确保信息层级清晰；构建流畅的视觉动线，引导用户快速获取核心信息，降低认知成本 | 建议性 |
| **标题**     | 结构遵循「品牌 + 核心要素」；内容需突出适用年龄、权威资质认证（如 3C/i-Size）及关键功能（如 360 度旋转、通风加热）；确保信息层级清晰且前后一致 | 建议性 |
| **卖点**     | 将技术参数转化为用户可感知的利益与场景，按「安全认证与核心保护 → 舒适度 → 安装便捷性」的优先级排序；使用家长关心的安全体验语言进行描述，严禁夸大或虚假宣传认证信息 | 要求性 |
| **属性**     | 信息必须准确，且与标题、卖点内容严格对应；适用年龄需按标准分组填写；明确填写人体固定方式、调节方式及安装接口类型 | 要求性 |
| **安心品质** | 上传 i-Size、ADAC 等权威认证证书；在商品详情页清晰透传权威背书，抢占用户「安全心智」，建立消费者对平台安全座椅品类的品质信任感，提升购买信心 | 建议性 |
| **主推标签** | 用户在浏览商品详情时，能直观看到主推商品标志，助于提升商品的加购转化 | 建议性 |
| **图文详情** | 首屏抓注意力，展示核心卖点、服务与促销；2-4 屏诠释尺寸适配、品牌安全认证；5-8 屏详细介绍材质骨架等差异化优势 | 建议性 |

## 二、主图规范

### 2.1 主图基础要求

| 项目         | 规范要求                                                     | 类型   |

## 三、标题规范

### 3.1 短标题（搜索场域）

- 搜索点击率 ↑5.9%

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **字数范围** | 16-30 个字符（一个汉字等于 2 个字符，数字、符号、英文算作 1 个字符） | 要求性 |
| **标题结构** | 【品牌】+【产品类型】+【适用年龄】/【资质认证】/【关键功能】/【颜色或款式】 | 建议性 |
| **组合规则** | 在「适用年龄、资质认证、关键功能、颜色款式」中，精选 1-2 个吸睛的词语填入，避免堆砌 | 建议性 |

#### 可选词库参考

| 类别         | 参考词                                                       |
| ------------ | ------------------------------------------------------------ |
| **适用年龄** | 0-15 个月、0-4 岁、0-7 岁、0-12 岁、3-12 岁                  |
| **资质认证** | 3C 认证、ECE 认证、i-Size 认证、ADAC 测试认证                |
| **关键功能** | 通风加热、冷暖双控、物理通风、智能通风、360 度旋转、侧撞保护、双向安装、一键折叠 |

#### 短标题结构示例

```
【某某品牌】安全座椅0-12岁i-Size认证
```

### 3.2 长标题（商详场域）

| 项目                 | 规范要求                                                     | 类型   |
| -------------------- | ------------------------------------------------------------ | ------ |
| **字数范围**         | 60 个字符以内，1 个汉字/全角（中文）符号 = 2 个字符，1 个英文字母/半角（英文）符号/数字 = 1 个字符 | 要求性 |
| **标题结构**         | 【品牌名】+【产品系列/型号】+【产品类型】+【适用年龄】+【核心功能】+【认证标准】+【固定方式】+【颜色/款式】 | 建议性 |
| **核心功能词库示例** | 360 度旋转、通风加热、智能通风、坐躺调节、便携折叠           | 示例性 |

#### 长标题结构示例

```
【某某品牌】儿童安全座椅 0-12岁 360度旋转智能循风 i-Size 棋盘格绿
```

## 五、属性规范

### 5.1 填写原则

属性填写时，请确保信息准确，并与长标题、短标题、商品卖点保持一致，避免出现前后矛盾或虚假描述。属性值须与标题、卖点中宣传的功能完全对应，不得夸大或遗漏。准确、一致的属性可减少咨询与退货，提升转化。

### 5.2 关键属性说明

| 属性             | 填写要求                                                    | 类型   |
| ---------------- | ----------------------------------------------------------- | ------ |
| **适用年龄**     | 按标准分组填写，如「0-4 岁」「0-12 岁」「15 个月-12 岁」    | 要求性 |
| **检测标准**     | 必须包含「中国 3C 认证」；如有国际认证（如 i-Size）一并列出 | 要求性 |
| **人体固定方式** | 明确三点式安全带、五点式安全带和前置护体等                  | 要求性 |
| **调节方式**     | 明确角度调节、360 度旋转、可旋转、可折叠和可侧拉            | 要求性 |
| **安装方式**     | 说明接口类型（ISOFIX/安全带等）及固定方式（如支撑腿）       | 要求性 |

## 六、安心品质

### 6.1 目的与效果

- 商详转化率 ↑14%
- 为提升消费者对平台安全座椅的品质信任感，帮助优质商品脱颖而出。
- I-Size、ADAC 是行业公认的品质认证，建议上传对应证书，在商详页透传权威背书，抢占用户「安全心智」。

### 6.2 核心认证说明

| 认证            | 说明                             | 类型   |
| --------------- | -------------------------------- | ------ |
| **I-Size 认证** | 欧盟儿童安全座椅标准（ECE R129） | 建议性 |
| **ADAC 认证**   | 德国汽车俱乐部测试（第三方测试） | 建议性 |

### 6.3 证书展示说明

证书图、报告图在APP/PC 端呈现方式，用于说明「安心品质」在商详或商品详情中的透传形态，不上升为所有商品必须使用的固定版式。

## 七、主推标签

### 7.1 作用

主推标签是对主推商品配置打标的工具，商家完成对商品主推配置后，在京东 APP 上会有对应的「主推」标识，用户在浏览商品详情时，能直观看到主推商品标志，有助于提升商品的加购转化。

### 7.2 展示说明

APP 商详商品卡、SKU 选择弹层的「主推」角标展示示例，仅用于说明主推标签可能出现的位置与形态，不作为通用版式规则。

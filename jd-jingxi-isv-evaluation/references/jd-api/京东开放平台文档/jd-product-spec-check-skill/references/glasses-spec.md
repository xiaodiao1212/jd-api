眼镜类目优质主图规范升级

## 一、整体规范综述

为加强眼镜品类在推荐、搜索、商详等场域的规范要求，进一步提升主图视觉体验，商品图片需围绕主体大小、营销区域面积、留白面积、商品呈现方式、背景等优质标准优化；OCR 正文重点说明**核心卖点清晰突出**与**设计特性匹配目标客群**两类优化方向。

### 核心模块要求

| 模块             | 核心方向                                                     | 类型   |
| ---------------- | ------------------------------------------------------------ | ------ |
| **卖点表达**     | 卖点传递需清晰可读、具象可信、节奏舒适，让商品主图在海量信息中快速抓住用户 | 建议性 |
| **设计特性**     | 针对不同目标客群的偏好与需求，用匹配的设计语言进行沟通，引起共鸣并提升传达效率 | 建议性 |
| **主图问题治理** | 重点解决核心卖点模糊、设计特性不足两类问题                   | 建议性 |

## 二、主图规范

### 2.1 常见问题

| 问题             | 说明                                               | 类型   |
| ---------------- | -------------------------------------------------- | ------ |
| **核心卖点模糊** | 卖点呈现平铺直叙，无法让消费者准确快速感知商品亮点 | 建议性 |
| **设计特性不足** | 整体设计氛围倾向不明显，无法为商品调性传达加分     | 建议性 |

### 2.2 信息可阅读性

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **字体选择** | 在复杂背景上，推荐使用粗实的非衬线字体，避免使用衬线体或笔画过细的字体 | 建议性 |
| **文字描边** | 当粗体字仍不够清晰时，可通过为文字添加描边强化视觉对比       | 建议性 |
| **背景处理** | 文字底部可增加半透明蒙层，以创建视觉缓冲层并隔离背景干扰     | 建议性 |

### 2.3 卖点具象化

| 方向         | 规范要求                                               | 示例                                                        | 类型   |
| ------------ | ------------------------------------------------------ | ----------------------------------------------------------- | ------ |
| **理性判断** | 将模糊功能展示为精确、可衡量的指标，增强专业度和可信度 | 将「阻隔炫光」数字化、放大化与色彩强调为「阻隔炫光 99.99%」 | 建议性 |
| **感性认知** | 通过公认视觉符号传递信息，把抽象优势转化为可感知画面   | 以漂浮羽毛和镜片悬浮姿态暗示「超轻」                        | 建议性 |

### 2.4 阅读节奏优化

| 项目               | 规范要求                                                     | 类型   |
| ------------------ | ------------------------------------------------------------ | ------ |
| **信息载体多样化** | 在信息呈现上适当穿插多样性表达，避免大片文字造成沉闷感和信息丢失 | 建议性 |
| **卖点视觉分层**   | 运用字体大小与色彩对比突出核心卖点，建立清晰视觉层次         | 建议性 |
| **信任信息符号化** | 将「国家专利」等信任信息转化为符号化标识，增强专业性与信任度 | 建议性 |
| **布局合理变化**   | 当卖点文案与图片内容紧密契合时，可调整位置增强呼应，形成视觉锚点和阅读强拍 | 建议性 |

## 三、客群设计规范

### 3.1 模特展示图表达策略

| 目标客群       | 设计特性                                                     | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **潮流驱动型** | 追逐流行款式，易被 KOL 和社交媒体种草；可营造「戴上就变好看」的氛围，参考主流社媒视觉元素（小线条、花字、贴纸等），整体更年轻化 | 建议性 |
| **品牌驱动型** | 注重品牌价值、明星背书、品质感和身份认同；品牌 Logo 清晰显眼，与明星共同构建视觉中心，构图稳重居中，色彩偏低饱和 | 建议性 |
| **场景应用型** | 有明确使用场景（如户外运动、驾驶等），追求亲近自然及速度感；呈现真实语境，色彩多用蓝色、绿色，文字可适当变形增强速度感 | 建议性 |

### 3.2 功能特性视觉表现

| 商品类型   | 客群关注点               | 设计特性                                                     | 类型   |
| ---------- | ------------------------ | ------------------------------------------------------------ | ------ |
| **老花镜** | 阅读舒适度、耐用性和品牌 | 平稳构图，文字区域和产品区域清晰分隔，秩序感强，易于扫读；主色用黑、蓝、白等冷静色，营造专业健康感 | 建议性 |
| **骑行镜** | 性能与个性，偏科技认知   | 动感构图，暗示速度与突破；色彩强调渐变鲜明、科技感强、高明暗反差，营造未来感 | 建议性 |

### 3.3 不同客群卖点设计技巧

| 客群           | 关注点                             | 设计特性                                                     | 类型   |
| -------------- | ---------------------------------- | ------------------------------------------------------------ | ------ |
| **价格敏感型** | 关注得到什么、能省多少，怕错过便宜 | 应用高饱和渐变色，放大核心利益点，增加闪电等限时秒杀视觉符号，营造紧迫感 | 建议性 |
| **品质敏感型** | 追求品牌价值、精湛工艺和高级质感   | 依循「少即是多」原则，通过去高饱和色与极简设计构建品质感     | 建议性 |

## 四、优化效果参考

### 4.1 效果数据（原图）

- 商详转化率提升 **↑7.15%**

### 4.2 优化方向示例

| 优化项           | 优化前问题               | 优化后方向                               | 类型   |
| ---------------- | ------------------------ | ---------------------------------------- | ------ |
| **核心卖点强调** | 卖点表达泛化             | 数字化、放大化呈现核心指标               | 建议性 |
| **信息层级**     | 信息视觉密度高且缺乏层次 | 字号、色彩、符号分层                     | 建议性 |
| **图文呼应**     | 卖点集中在固定区域       | 根据商品位置调整卖点文案，增强理解路径   | 建议性 |
| **客群调性**     | 风格不匹配商品人群       | 按潮流、品牌、场景、价格、品质等客群设计 | 建议性 |

## 五、校验清单

### 5.1 上架前自检清单

```
## 主图卖点检查（建议性）
- [ ] 核心卖点清晰突出，未平铺直叙
- [ ] 复杂背景上的文字使用粗实字体、描边或半透明蒙层保证可读
- [ ] 抽象功能已转化为可感知、可理解的信息
- [ ] 可量化功能尽量用明确指标表达
- [ ] 信息层级通过字号、颜色、符号建立清晰阅读顺序
- [ ] 卖点文案位置与图片内容有呼应

## 主图设计特性检查（建议性）
- [ ] 已根据目标客群选择对应设计语言
- [ ] 潮流驱动型商品体现年轻化社媒视觉元素
- [ ] 品牌驱动型商品突出 Logo 与品质感
- [ ] 场景应用型商品呈现真实使用语境
- [ ] 老花镜类商品保持专业、健康、易扫读
- [ ] 骑行镜类商品体现速度感、科技感和动感
- [ ] 价促类信息放大核心利益点但不遮挡商品理解
- [ ] 品质类信息避免高饱和堆叠，保持极简质感
```

### 5.2 常见问题

| 问题         | 原因                         | 解决方案                                         |
| ------------ | ---------------------------- | ------------------------------------------------ |
| 卖点看不清   | 背景复杂、字体过细或缺少对比 | 使用粗实非衬线字体、文字描边或半透明蒙层         |
| 卖点不可信   | 只写抽象形容词               | 将功能转为量化指标或可感知视觉符号               |
| 阅读负担重   | 文字密集且缺少层级           | 用字号、颜色、图标、标识建立信息分层             |
| 商品调性不足 | 未按目标客群设计视觉语言     | 按潮流、品牌、场景、价格、品质等客群匹配设计特性 |

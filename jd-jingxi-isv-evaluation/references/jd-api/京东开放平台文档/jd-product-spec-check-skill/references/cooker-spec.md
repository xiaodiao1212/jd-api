## 一、整体规范综述

### 1.1 文档性质说明

「官方建议」诠释：**本规范是京东平台通过洞察—梳理—验证—总结后提炼出的、有助于提升商品信息点击率与转化率的经验与方法**，为商家提供参考与指导，**并非强制性平台规则**。【建议性 / 运营指引】

### 1.2 优化目标与六大方向（综述图）

商品信息围绕用户选购需求，通过优化下列内容提升流量转化效率：

| 方向                            | 要点（摘录）                                                 | 类型   |
| ------------------------------- | ------------------------------------------------------------ | ------ |
| **主图**                        | **结构化** — 核心决策信息聚焦于首屏主图及第二帧位置，提升选购效率 | 建议性 |
| **标题**                        | **结构化** — 长标题精准呈现核心信息，简明准确详尽，利于检索与信任；短标题提炼核心卖点，仅前端展示，助力快速决策 | 建议性 |
| **系列品工具（不同 SPU 绑定）** | **标准化** — 制定绑定规则，模糊信息标准化、简单清晰可识别    | 建议性 |
| **规格图**                      | **结构统一化** — 减少多余价促切片，只保留商品主体 + 关键卖点信息 | 建议性 |
| **销售属性**                    | **简洁化** — 只保留容量 + 该商品在同系列中的差别点           | 建议性 |
| **卖点**                        | **差异化** — 针对不同价格区间消费者关注的核心信息，精准匹配卖点 | 建议性 |

## 三、标题规范

### 3.1 短标题（搜索场域）

| 项目     | 要求                                                  | 类型   |
| -------- | ----------------------------------------------------- | ------ |
| **字数** | **16–30 个字符**                                      | 建议性 |
| **结构** | **品牌 +（主推卖点/系列名）+ 品类 + 适用人数 + 容量** | 建议性 |
| **示例** | 美的纯钛 0 涂层电饭煲 4–5 人 5L                       | 建议性 |

### 3.2 长标题（商详场域）

| 项目           | 要求                                                         | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **字符数**     | **90 个字符**                                                | 建议性 |
| **结构**       | **品牌词 + 品类词 + 系列词（如有）+ 核心卖点 + 颜色 + 容量 + 适用人数 + 型号** | 建议性 |
| **趋势词**     | 钛内胆、瓷内胆、316L 不锈钢内胆、IH 加热等；建议结合消费者对 **健康、无化学有害物质析出** 等关注点运营 | 建议性 |
| **「母婴级」** | **工艺合规 + 材质安全** 的 **316L 不锈钢内胆、钛内胆**，可加注「母婴级」关键词 | 建议性 |

## 四、系列品绑定规范（同一 SPU）

### 4.1 SKU 绑定原则

| 条款       | 内容                                                  | 类型   |
| ---------- | ----------------------------------------------------- | ------ |
| **模具**   | **同模具**支持绑定；**不同模具**需分开                | 建议性 |
| **可变体** | 同款不同色 / 不同配件 / 产品某个配件升级等 **可绑定** | 建议性 |

### 4.2 三层规则（优先级）

1. **有出厂系列**的优先按出厂系列划分（示例：【松下饭光光系列】【苏泊尔旋焰釜系列】）。  
2. 若不满足上条：可结合 **内胆材质 + 加热方式** 绑定（示例：【基础款高性价比系列】【升级款 IH 加热系列】【升级款 0 涂层系列】）。  
3. **同模具**：外形与功能无差别，仅 **颜色或容量** 区别者可绑定。

### 4.3 排序与容量标注

在同一 SPU 下：**按容量从小到大排序**，且 **容量放到最前面**。【建议性】

## 五、系列品规范（不同 SPU 绑成系列）

### 5.1 划分原则

系列品须在 **同品牌 ID** 下，有明确 **场景划分**，便于用户感知：

- 按 **价格带 / 材质场景**、**迭代升级场景** 划分；  
- 示例命名：【基础 0 涂层系列】【升级 0 涂层系列】【IH 加热 0 涂层系列】【旗舰款 0 涂层系列】；或【经济款】【品质款】【高端款】 / 【品质款】【高端款】【顶奢款】。

[系列品操作手册 ](https://joyspace.jd.com/pages/so6Pke5zJ4geDUOtBgp0)

## 六、规格图规范（结构统一化）

### 6.1 总体原则

| 条款     | 内容                                                         | 类型   |
| -------- | ------------------------------------------------------------ | ------ |
| **切片** | 规格小图减少多余价促切片；保留 **产品图 + 关键卖点信息 + 容量 + 适用人数** | 建议性 |

### 6.2 布局三条

1. **左侧**：品牌、型号、**三个主推卖点**、赠品配件依次排列；**右侧**：商品本体并标注尺寸（不加干扰背景）；**下方**：容量 + 适用人数。  
2. **同一 SPU** 下色调保持统一；**A3 及以上新品**，SKU 新品期间 **可换色调** 以增加转化。  
3. 各品牌可选用符合调性的背景色。

### 6.3 模板要素（占位示意）

Logo → 型号 → 产品短标题 → 多行卖点 → 配件清单 → 产品 PNG + 尺寸标注 → **容量 ≈ X 碗米饭、适用人数**。

文中美的示例给出尺寸数字「3L ≈ 8 碗米饭 适用 2–3 人」等，仅供结构参考。

## 七、销售属性规范（简洁化）

| 条款         | 内容                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **命名**     | **极简**                                                     | 建议性 |
| **排序**     | **容量从小到大排最前**                                       | 建议性 |
| **命名格式** | **容量 + 卖点**（例：3L 纯钛 IH、4L 纯钛 IH）；点明同系列下差异，**不必赘述系列名** | 建议性 |

文中附松下 / 小米 / 半球等容量与卖点组合示意，落地时须与 SKU 实际一致。

## 八、卖点规范（差异化）

运营侧宜按下列维度区分不同价位用户关切：

| 维度         | 选项（摘录）                                                 | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **加热方式** | 普通底盘 / IH 电磁 / 远红外 / 蒸汽加热                       | 建议性 |
| **内胆材质** | 普通涂层内胆；305 普通 0 涂层；316L 母婴级 0 涂层；陶瓷内胆；土锅内胆；钛涂层内胆；纯钛内胆等 | 建议性 |
| **特色功能** | 开盖煮、联网预约、低糖饭、滤油釜、饭菜一锅出等               | 建议性 |

> **真实性：** 卖点须与实物与检测报告一致；**不得**夸大材质或认证。涉及「母婴级」等表述须满足文中 **工艺合规 + 材质安全** 前提（见 3.2）。

## 一、整体规范综述（五大模块）

商品信息围绕用户选购需求，通过优化产品**主图**、**标题**、**卖点**、**系列品**、**规格图**五项基础内容，提升流量转化效率。

| 模块                            | 核心方向                                                     | 类型   |
| ------------------------------- | ------------------------------------------------------------ | ------ |
| **主图**                        | 结构化，核心决策信息聚焦于首屏主图位置，从而提升选购效率     | 建议性 |
| **标题**                        | 结构化，长标题用于精准呈现商品核心信息，表述简明、准确且详尽；短标题聚焦提炼商品核心卖点，仅用于前端用户展示 | 建议性 |
| **卖点**                        | 差异化，针对不同价格区间消费者所关注的核心信息，精准匹配对应产品卖点 | 建议性 |
| **系列品工具**（不同 SPU 绑定） | 标准化，制定不同品类绑定规则，模糊信息标准化、简单清晰可识别 | 建议性 |
| **规格图**                      | 简洁化，减少多余价促切片，保留场景图和关键卖点               | 建议性 |

## 二、主图规范

### 2.1 产品主图（第一张）核心要求

### 3.2 短标题

## 四、卖点规范

### 4.1 消费者关注方向

吸力、清洁效果/效率、电池续航、口碑、性价比等；**卖点优先级按消费者高频咨询问题排列**。

### 4.2 基础卖点（参考词库）

| 维度         | 推荐词示例                                                   | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **基础卖点** | 吸力、真空度、平躺角度、拍打频率、滚刷转速、最低噪音、水箱容量、吸头数量等 | 建议性 |
| **产品性能** | 助力方式、平躺角度、平躺高度、特色功能、集尘容量等           | 建议性 |

## 六、规格图规范

### 6.1 基本原则

- **规格小图减少多余价促切片**，保留场景图和关键卖点。【建议性】
- 建议配置为【**简洁版本**】、【**卖点版本**】两种图片类型，**二选一即可**。【建议性】
- 要求**同一 SPU 下色调保持统一**；其中 **A3 及以上新品**，此 SKU 可换色调。【建议性】

### 6.2 模版信息结构（卖点版本）

模版一般包含：**品牌 + 型号**、**slogan 主卖点**、**核心参数条**、**随箱配件**、**产品场景图**等区域（布局以原图模板为准）。

### 6.3 各品类需呈现要素与示例文案

#### 6.3.1 吸尘器-有线推杆

- **需呈现：** 吸功 AW、真空度 Kpa、操作直径 + 随箱配件
- **示例文案（示意）：**
  - 有线推杆-C3
  - 轻量低噪 小身材大吸力
  - 170AW 吸入功率
  - 18kPa 真空度
  - 10m 操作直径
  - 随箱配件

#### 6.3.2 吸尘器-无线推杆、自集尘

- **需呈现：** 吸功 AW、真空度 Kpa、续航 + 随箱配件
- **示例文案（示意）：**
  - 自集尘-C36MAX-SL
  - 自集尘 + 除螨 专业不卡毛不缠毛
  - 215AW 吸入功率
  - 33kPa 真空度
  - 15–60min 续航时间

#### 6.3.3 吸尘器-卧吸、桶吸

- **需呈现：** 吸功 AW、真空度 Kpa、操作直径 + 随箱配件
- **示例文案 1（桶吸示意）：**
  - 标准款桶吸-70A
  - 干湿吹三用 带温控器和泄压阀
  - 130AW 吸入功率
  - 19kPa 真空度
  - 15m 操作直径
- **示例文案 2（卧吸示意）：**
  - 标准款卧吸-37A
  - 轻音低噪 无极调节吸力
  - 170AW 吸入功率
  - 22kPa 真空度
  - 14m 操作直径

### 6.4 温馨提示

- 注意对仗工整，如【有线】对【无线】，【新品】对【老品】。【建议性】
- 桶吸卧吸，颜色尺码中建议标注容量、功率。【建议性】

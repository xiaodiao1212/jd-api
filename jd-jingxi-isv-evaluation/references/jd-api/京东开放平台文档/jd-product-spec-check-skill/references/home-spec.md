## 一、升级背景与适用范围

### 1.1 升级目的

为提升家居类目在**搜索推荐场域**的流量承接效率，平台对素材规范升级：**优先展示长图素材（宽高比约 3:4）**。数据表明优质长图对点击率、转化率及 GMV 有正向作用，建议商家积极上传优质长图。

### 1.2 覆盖范围

| 维度                         | 说明                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| **商家类型**                 | 自营、POP                                                    |
| **类目（常见问题答复一致）** | **厨具**、**床上用品**、**家居饰品**、**灯饰照明**（四个一级类目） |
| **新建字段**                 | 商品发布环节中可选字段 **「搜索推荐图」**（宽高比 **3:4**）  |

### 1.3 平台 AIGC 生成说明（重点关注）

为降低商家操作成本，平台**可能**对部分商品使用 AIGC 生产并投放优质长图。**商家上传优先级大于平台生成**；若不满意，可自行删除或重新上传。

## 二、等级总览（优质 / 一般 / 低质）

搜推主图分为 **优质**、**一般**、**低质**三档。**优质**与**一般**须满足各自层级下**全部**细则；若出现任意一种 **低质** 情形，则判为低质主图。

### 2.1 规则因子总表

| 规则因子                | ●优质                                            | ●一般  | ●低质  |
| ----------------------- | ------------------------------------------------ | ------ | ------ |
| **商品主体面积占比**    | ≥30%                                             | ≥30%   | ＜30%  |
| **营销区域面积占比**    | ≤35%                                             | ≤50%   | ＞50%  |
| **主图留白面积占比**    | ≤10%                                             | ≤30%   | ＞30%  |
| **营销卖点 / 商品背景** | 须满足：场景实拍图 **或** 卖点图 **或** 非白底图 | 不考核 | 不考核 |
| **主图尺寸**            | **3:4 长图**                                     | 不考核 | 不考核 |

### 2.2 备注（与 README / OCR 一致）

1. **适用范围：** 床上用品、厨具、家居饰品、灯饰照明。对外素材标题或作「家居」「家电家居」，**类目与规则以本表及 README 第二节总表为准**。  
2. **推荐场域：无腰带 / 贴片**，可有 **Logo** 和 **卖点**。  
3. **细长商品：** 部分细长商品若商品主体**高度或宽度**占主图整体高度或宽度的 **80% 以上**，也可满足优质与一般条件（与主体面积阈值配套使用，详见下文）。

## 三、规则释义

### 3.1 商品主体面积占比

- **定义：** 商品主体清晰可辨，商品主体面积占整图比例 **不小于 30%**。  
- **特殊商品（细长型）：** 如「筷子」「擀面杖」等，**主体面积占比难以 ≥30%** 时，仅需商品主体 **高度或宽度** 占整图对应边的 **80% 以上**，亦可与总表「商品主体 ≥30%」**配套**判为**优质与一般**（**并非**另一套「40%」面积门槛，亦不要求普通商品同时满足面积≥30%与边长≥80%）。

### 3.2 营销区域面积占比

- **定义：** 除商品主体外，图中文字、促销信息、Logo、水印等均计入 **营销区域**。  
- **示意图提示：** 官方提供方图（1:1）与长图（3:4）网格示意；绿色格子仅为示意，**不表示**营销内容必须固定在某一几何区域。

### 3.3 主图留白面积占比

- **定义：** 主图四周留白占整图面积的比例。  
- **优质：** 留白 **≤10%**（示意中以「非优质」对照留白过大）。

### 3.4 场景实拍图或卖点图或非白底图（优质必填）

图片须至少满足其一：

- 商品实拍且 **场景化** 呈现；或  
- 展示 **营销卖点**；或  
- 背景 **非纯白底**。  

**白底、无场景、无卖点** 的展示易被判为 **非优质**（参见案例图）。

## 四、案例层级摘要（与 OCR 封面一致）

### 4.1 优质案例（3:4 长图）

**1-1 搜索场域优质示例要点**

- 商品主体面积 **≥30%**  
- 营销区域面积占比 **≤35%**；主图留白面积 **≤10%**  
- 场景实拍 / 卖点图 / 非白底（其一）  
- 主图尺寸 **3:4**

**1-2 推荐场域优质示例要点**

- 商品主体面积 **≥30%**；主图留白 **≤10%**  
- 场景实拍 / 卖点图 / 非白底（其一）；主图尺寸 **3:4**  
- **无贴片和腰带**，可保留 **Logo** 与 **卖点**

### 4.2 一般案例

- 商品主体面积 **≥30%**（细长品若在面积维度难以达标，改以主体 **高度或宽度** 占整图对应边的 **≥80%** 视为满足本条；与封面备注、案例页表述一致）。  
- **搜索与推荐场域：** 营销区域面积占比 **≤50%**；主图留白 **≤30%**；主图尺寸 **1:1**  
- **重点（推荐）：无贴片和腰带**，可保留 Logo 与卖点  

### 4.3 低质情形（任一即低质）

- 商品主体面积占比 **＜30%**  
- 营销区域面积占比 **＞50%**  
- 主图留白面积 **＞30%**

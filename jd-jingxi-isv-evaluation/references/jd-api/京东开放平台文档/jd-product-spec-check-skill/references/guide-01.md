# 京东商品规范校验技能

## 技能概述

本技能用于校验京东平台商品信息发布是否符合官方运营规范，帮助商家避免因信息不规范导致的下架、降权等风险。

技能内容来源于京东商品运营中心官方发布的运营规范文档，通过 OCR 识别提取完整内容，包含**要求性规范**（必须遵守）和**建议性规范**（推荐遵守）。

## 使用场景

- 新品上架前规范自检
- 存量商品规范批量检查
- 商品优化建议生成
- 规范合规性报告输出
- 运营培训与学习

## 核心功能

### 1. 图片+视频底线规则（通用）

| 类型 | 规则 | 要求类型 |
|------|------|----------|
| **方主图** | 宽高比 1:1，宽高均 >480px，推荐 1440×1440，<3M，jpg/jpeg/png | 要求性 |
| **长主图** | 宽高比 3:4，宽高均 >480px，推荐 1440×1920，<3M，jpg/jpeg/png | 要求性 |
| **规格图** | 同方主图/长主图逻辑 | 要求性 |
| **搜索主图** | ≥480×640px，比例 3:4，jpg/jpeg/png | 要求性 |
| **视频** | 时长 ≥5s，分辨率 ≥720P，比例 1:1/3:4/9:16/16:9，mp4 等 | 要求性 |
| **素材（白底）** | 1:1，>480×480px，jpg/jpeg，<3M；纯白背景、无牛皮癣、主体完整不变形、清晰不偏色、尽量铺满画布、单主体（套装除外） | 要求性 |
| **素材（透底）** | 1:1，>480×480px，**png**，<3M；透明背景、无牛皮癣、主体完整不变形 | 要求性 |
| **素材（场景图）** | 1:1，>480×480px，jpg/jpeg，<3M；带背景、无牛皮癣、不留白边、单主体 | 要求性 |
| **素材（卖点图）** | 1:1，>480×480px，jpg/jpeg，<3M；含卖点文字且不违反广告法、主体完整不变形 | 要求性 |

### 2. 标题规范校验

| 校验项 | 要求类型 | 规范要求 |
|--------|----------|----------|
| 长标题字数 | 建议性 | ≤60 字符（部分品类 ≤90），京东计数规则：汉字=2，英文/数字=1 |
| 短标题字数 | 建议性 | 16–30 字符（鞋靴 16–50） |
| 品牌名 | 要求性 | 必须包含品牌名 |
| 禁用词 | 要求性 | 不得含"最""第一""顶级""销量第一""全网最低"等违禁词 |
| 结构化 | 建议性 | 品牌 + 产品词 + 核心卖点 + 规格/口味/适用场景 |

### 3. 卖点规范校验

| 校验项 | 要求类型 | 规范要求 |
|--------|----------|----------|
| 条数 | 建议性 | 每 SKU 3 条（部分品类 ≥2 条） |
| 字数 | 建议性 | 每条 2–8 字符（京东计数规则） |
| 去重 | 建议性 | 不得与短标题重复 |
| 真实性 | 要求性 | 不可夸大或虚假宣传 |

### 4. 属性规范校验

| 校验项 | 要求类型 | 规范要求 |
|--------|----------|----------|
| 必填属性 | 要求性 | 各品类有独立必填属性列表（详见各 spec） |
| 一致性 | 要求性 | 属性须与标题、卖点、主图、已选弹层信息一致 |
| 信息外露 | 建议性 | 属性 ≥4 条可获得额外搜索曝光加成 |

### 5. 主图构图指标（部分品类）

| 品类 | 商品主体面积 | 营销区域面积 | 留白面积 | 要求类型 |
|------|-------------|-------------|---------|----------|
| 家居 | ≥30% | 优质≤35% / 一般≤50% | 优质≤10% / 一般≤30% | 要求性 |
| 服饰 | ≥40% | 推荐<5% / 搜索≤35% | <10% | 要求性 |

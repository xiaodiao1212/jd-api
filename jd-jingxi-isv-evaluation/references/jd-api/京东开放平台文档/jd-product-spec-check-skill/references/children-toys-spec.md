   ## 一、整体规范综述

   ### 1.1 文档性质说明

   「官方建议」诠释：**本规范是京东平台通过洞察—梳理—验证—总结后提炼出的、有助于提升商品信息点击率与转化率的经验与方法**，为商家提供参考与指导，**并非强制性平台规则**。【建议性 / 运营指引】

   ### 1.2 优化目标与九大基础模块

   商品信息应围绕用户选购需求，通过优化下列基础内容改善体验、提升转化率：

   | 模块             | 核心指向                                                     | 类型   |
   | ---------------- | ------------------------------------------------------------ | ------ |
   | **主图**         | 给出清晰方向，帮助用户在短时间内捕捉关键信息，提升点击意愿与信息吸收效率 | 建议性 |
   | **主图视频**     | 拍摄风格建议种草向 / 功能向 / 痛点引入向；**时长控制在 20–30 秒以内** | 建议性 |
   | **长标题**       | 采用「模块化 + 顺序化」原则将产品信息拆解为品类、IP/系列、适用年龄、材质、卖点、适用场景等模块，避免重复与散乱 | 建议性 |
   | **短标题**       | 模块化结构，集中展示品牌、产品类型及核心属性，提升点击率与决策效率 | 建议性 |
   | **通用卖点**     | 避免技术术语，使用用户语言、直观与体验导向表达（如「可高温消毒、防误吞」） | 建议性 |
   | **安心品质**     | 上传含硼量合格、甲醛未检出等权威检测报告；在商详安心品质楼层透传背书 | 建议性 |
   | **主推标签**     | 配置后主推高亮，用户浏览商详时能直观看到主推标识，有助加购转化 | 建议性 |
   | **系列品**       | 推荐高关联商品，缩短跳转与决策路径                           | 建议性 |
   | **商品使用说明** | 针对高频咨询配置说明书，助力售前转化、降低售后咨询           | 建议性 |

   ### 2.4 首张主图三类优化方向（文中示例）

   #### （1）互动类玩具：加入互动场景，强化使用想象

   - **要点：** 优化后可加入人物互动、强化使用场景；明确差异化卖点（如「超大风筝」）；保留商品特有赠品信息（如线轮、连接线等）。
   - **类型：** 建议性

   #### （2）卖点表达：标签式卖点，降低用户理解门槛

   - **要点：** 突出可动部分（如箭头指示增加动感）；卖点组合示例维度含工业风、可动、独特玩法；利益点可与店铺活动、赠品分区呈现。
   - **类型：** 建议性

   #### （3）场景设置：构建产品使用语境，增强游戏代入感

   - **要点：** 背景与卖点匹配；突出遥控方式；高亮差异化卖点（示例：八轮八驱、水陆两栖、遥控灵敏等）。
   - **类型：** 建议性

   ## 三、主图视频规范

   ### 3.1 总体建议

   | 条款             | 内容                                                 | 类型   |
   | ---------------- | ---------------------------------------------------- | ------ |
   | **拍摄取向**     | 以功能 / 玩法 / 使用场景 / 差异化卖点介绍为主        | 建议性 |
   | **前 5 秒**      | 突出材质、玩法等核心卖点，并通过**真实互动**展示     | 建议性 |
   | **视听风格**     | 风格与音乐符合儿童喜好，活泼有趣                     | 建议性 |
   | **技术合规**     | 确保时长、尺寸、无黑边等**符合平台技术规范**         | 要求性 |
   | **禁止拼接糊弄** | **避免使用图片拼接生成视频**，需展示商品**动态效果** | 建议性 |

   ### 3.2 三类视频风格

   | 类型           | 内容要求                                                     | 类型   |
   | -------------- | ------------------------------------------------------------ | ------ |
   | **种草型**     | 核心卖点 + 真人互动展示；商品 + 语音解说；解说词精炼有吸引力，与画面同步 | 建议性 |
   | **功能型**     | 玩法展示 + 真人互动；实际操作、遥控、多玩法等关键镜头，沉浸式吸引客户停留 | 建议性 |
   | **痛点引入型** | 痛点话术引入 + 产品功能介绍 + 真人演示；先停留再展开亮点     | 建议性 |

   ### 4.2 字数与结构

   | 项目         | 规范要求                                                     | 类型               |
   | ------------ | ------------------------------------------------------------ | ------------------ |
   | **字符数**   | **60 个字符**（1 个英文字母、数字、符号 = 1 字符；**1 个中文字 = 2 字符**） | 建议性             |
   | **结构化**   | **品牌 + IP/系列 + 产品名 + 营销词（功能 / 玩法 / 卖点）**   | 建议性             |
   | **风控提示** | 规避营销词不良引导（如**买一送一、TOP1**）                   | 要求性（合规导向） |

   ### 4.3 分品类句式与示例

   - **积木拼插：**  `【品牌】+【IP/系列】+【产品名】+【材质/工艺】+【规格/片数】+【适用年龄/阶数】+【营销词】`  示例：若客 魔鬼鱼塑料机械拼装模型 14 岁以上益智玩具男孩礼物立体拼图摆件
   - **益智玩具：**  `【品牌】+【IP/系列】+【产品名】+【规格/片数】+【适用年龄/阶段】+【营销词】`  示例：GAN 三阶魔方 7 岁以上磁力可调益智早教生日礼物
   - **绘画 / DIY / 户外 / 娃娃 / 过家家：**  `【品牌】+【IP/系列】+【产品名】+【规格/片数】+【适用年龄】+【营销词】`  示例：卡乐优 36 色超轻粘土套装 3–14 岁儿童无毒彩泥手工课学生幼儿园透明箱
   - **婴幼童玩具：**  `【品牌】+【材质】+【IP/系列】+【产品名】+【规格/片数】+【适用年龄】+【营销词】`  示例：迪士尼 硅胶婴儿摇铃礼盒 5–18 个月新生儿生日礼物
   - **遥控模型 / 玩具枪：**  `【品牌】+【比例】+【IP/系列】+【产品名】+【材质/工艺】+【适用年龄】+【功能热点】+【营销词】`  示例：比美高 1:24 法拉利 SF23 勒克莱尔 16 号 F1 赛车精装版合金汽车模型男孩礼物
   - **户外玩具 / 游乐设施：**  `【品牌】+【IP/系列】+【产品名】+【规格/片数】+【适用年龄】+【营销词】`  示例：爸爸妈妈 飞机玩具 6 个月以上泡沫弹射户外发射儿童玩具男孩户外玩具

   ### 4.4 优化思路示例（木质与年龄门槛）

   | 维度         | 说明                                                         | 类型   |
   | ------------ | ------------------------------------------------------------ | ------ |
   | **信息补全** | 利用多余字符空间补充材质（如木质）、难度门槛（如 14+），传达「我是谁」「谁能玩」 | 建议性 |

   文中「优化前 / 优化后」示例（咖啡工厂积木）：在长标题中明确「木质拼装」「14 岁以上」等产品与人群锚点。

   ## 十、商品使用说明规范

   ### 10.1 目的与内容范围

   结合用户高频售前与售后咨询，配置商品使用说明书，覆盖：主要卖点、使用方法、注意事项、使用后常见问题答疑等。【建议性】

   ### 10.2 优秀示例（文中结构）

   - **商详「使用说明」入口**：与详情切片、卖点图标（材质、年龄等）并列呈现。  
   - **视频演示**：示例含「AI 玩具网络制式」等**硬性提示文案**（如仅支持 4G LTE/3G/2G、不支持 5G）——具体文案须与实物一致。【要求性（真实性）】  
   - **电子说明书**：含功能介绍（按键、指示灯）、扫码联网步骤等。

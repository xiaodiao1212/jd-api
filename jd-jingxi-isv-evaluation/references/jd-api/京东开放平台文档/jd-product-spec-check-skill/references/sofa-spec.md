1. 家具-功能沙发 商品信息运营规范

   > **来源：** 京东商品运营中心官方建议  **文档链接：**https://mtt.jd.com/serviceno/servicenoHomePage/378  **最后更新：** 2026 年 4 月 29 日  **提取方式：** OCR 识别原图内容

   ## 一、整体规范综述

   商品信息围绕用户选购需求，通过优化**产品主图、标题、卖点、系列品、商品详情页**，提升流量转化效率。

   ### 核心模块要求

   | 模块           | 核心要求                                                     | 类型   |
   | -------------- | ------------------------------------------------------------ | ------ |
   | **主图**       | 核心决策信息聚焦于首屏主图位置，采用结构化展示，提升选购效率 | 建议性 |
   | **标题**       | 长标题用于精准呈现商品核心信息；短标题聚焦提炼商品核心卖点，仅用于前端用户展示 | 建议性 |
   | **卖点**       | 根据不同价格段消费者关注的核心因素，匹配不同产品卖点         | 建议性 |
   | **系列品工具** | 同系列不同 SPU 绑定，模糊信息标准化，简单清晰可识别          | 建议性 |
   | **详情页**     | 通过选购指引加速建立信任，促成转化                           | 建议性 |

   ## 二、主图规范

   ### 2.1 产品主图基础要求

   | 项目                   | 规范要求                                                     | 类型   |
   | ---------------------- | ------------------------------------------------------------ | ------ |
   | **高端产品首图**       | 突出高端、品质和品牌调性，头图（第 1 帧）换场景图，减少利益点、权益等信息 | 建议性 |
   | **中端及低端产品首图** | 保持现有策略，保持简洁，减少贴片数量，确保产品清晰完整       | 建议性 |
   | **营销信息位置**       | 第 1 张产品主图中，营销贴片、价格、权益、服务等置于下方，不允许遮挡商品 | 要求性 |
   | **主图视频覆盖**       | 提高主图视频覆盖率，包含品宣视频、产品介绍视频、采销推荐视频 | 建议性 |

   ### 2.2 主图视频要求

   | 项目         | 规范要求                             | 类型   |
   | ------------ | ------------------------------------ | ------ |
   | **视频类型** | 品宣视频、产品介绍视频、采销推荐视频 | 建议性 |
   | **内容聚焦** | 聚焦产品功能讲解、场景展现           | 建议性 |

   ### 2.3 主图 1-10 张结构化要求

   | 序号          | 内容要求    | 说明                                                         | 类型   |
   | ------------- | ----------- | ------------------------------------------------------------ | ------ |
   | **第 1 张**   | 产品主图    | 核心展现产品外观，露出利益点，吸引用户点击；可按产品特性配置个性化、场景化主图 | 建议性 |
   | **第 2 张**   | 尺寸 + 功能 | 标注产品尺寸和核心功能                                       | 建议性 |
   | **第 3 张**   | 卖点总览    | 一张图展示核心卖点、材质、功能等                             | 建议性 |
   | **第 4-8 张** | 卖点展开    | 以用户语言阐释具体卖点、功能                                 | 建议性 |
   | **第 9 张**   | 颜色对比    | 展示不同颜色规格                                             | 建议性 |
   | **第 10 张**  | 服务 / 权益 | 展现京东家具和品牌服务利益点，如送装一体、以旧换新、免费试坐等 | 建议性 |

   ### 2.4 主图内容示例

   | 序号                      | 示例内容                                                     | 类型   |
   | ------------------------- | ------------------------------------------------------------ | ------ |
   | **第 2 张：尺寸 + 功能**  | 可展示三人位、双电动、0 靠墙、头层牛皮、尺寸标注、隐藏式头枕、可进扫地机、合金架质保等 | 建议性 |
   | **第 3 张：卖点总览**     | 可展示可坐可躺、电动一键躺平、复合坐感结构、人体工学靠包、专利合金架等 | 建议性 |
   | **第 4-8 张：卖点展开**   | 可围绕头颈区、肩背区、腰椎区、臀部区、大腿区进行人体工学设计说明 | 建议性 |
   | **第 9 张：颜色对比**     | 可展示可可棕、午夜黑、棉白色等颜色规格                       | 建议性 |
   | **第 10 张：服务 / 权益** | 可展示免费送装、免费仓储、免费试睡、价保、无理由退货、质保、绿色环保、破损包售后等 | 建议性 |

   ## 三、标题规范

   ### 3.1 短标题

   | 项目         | 要求                                 | 类型   |
   | ------------ | ------------------------------------ | ------ |
   | **字数范围** | 16-30 个字符                         | 要求性 |
   | **标题结构** | 品牌 + 型号 + 材质 + 功能 + 产品类型 | 建议性 |
   | **品牌写法** | 规格中品牌仅使用中文简称             | 建议性 |

   **示例：**

   ```
   芝华仕白月光半青皮电动沙发
   ```

   ### 3.2 长标题

   | 项目         | 要求                                                         | 类型   |
   | ------------ | ------------------------------------------------------------ | ------ |
   | **字数范围** | 60 个字符                                                    | 要求性 |
   | **标题结构** | 品牌 + 型号 + 材质 + 功能 + 产品类型 + 颜色 + 尺寸 + 卖点词 / 趋势词 | 建议性 |

   **示例：**

   ```
   芝华仕(CHEERS)头等舱贵族白月光半青皮零靠墙电动沙发白2.86米三座双电
   ```

   ## 四、卖点规范

   ### 4.1 卖点结构

   | 项目         | 规范要求                                   | 类型   |
   | ------------ | ------------------------------------------ | ------ |
   | **通用结构** | 核心功能 + 产品卖点 + 核心服务             | 建议性 |
   | **重复控制** | 卖点信息不可与短标题信息重复，弱化工业卖点 | 建议性 |

   ### 4.2 卖点方向

   | 卖点维度                 | 示例                                                         | 类型   |
   | ------------------------ | ------------------------------------------------------------ | ------ |
   | **中高端溢价类功能卖点** | 0 重力、按摩功能、语音互联、头枕电动可调等                   | 建议性 |
   | **核心功能**             | 可坐可躺、零靠墙、可进扫地机、带翻倒几等                     | 建议性 |
   | **适用人群**             | 小户型适用、大平层适用等                                     | 建议性 |
   | **材质类别和等级**       | 1 号顶级真皮、2 号轻奢真皮、3 号优享真皮、4 号入门真皮、合成皮、人造皮、布艺 | 建议性 |
   | **填充物**               | 羽绒填充、高回弹海绵、赛羽绒等                               | 建议性 |
   | **风格**                 | 中古风、奶油风、轻奢风、意式极简等                           | 建议性 |

   ## 五、系列品工具规范

   ### 5.1 绑定 / 展示原则

   | 项目           | 规范要求                         | 类型   |
   | -------------- | -------------------------------- | ------ |
   | **绑定范围**   | 同系列产品可进行绑定             | 建议性 |
   | **排序方式**   | 绑定后进行低中高端排序，辅助选购 | 建议性 |
   | **前置词要求** | 规格短标题前置词需精简、可区分   | 建议性 |

   ### 5.2 价格带与前台语言

   | 建议方向       | 前台语言 | 核心决策点                                                   | 核心参数 / 卖点                                              | 类型   |
   | -------------- | -------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------ |
   | **5000 以下**  | 经济款   | 是否真皮、是否有功能位、小户型尺寸是否合适                   | 真皮、头层皮；单 / 双电动位；双人位 2.1m、小三人位 2.3m      | 建议性 |
   | **5000-8000**  | 品质款   | 选择大品牌、是否进口头层牛皮、功能升级                       | 头层牛皮、进口头层牛皮；零靠墙设计、可进扫地机、翻到几       | 建议性 |
   | **8000-15000** | 高端款   | 材质升级、功能增加、产品外观风格设计                         | 半青皮、全青皮；气囊按摩、语音控制、零重力、头枕可调节；现代简约、意式极简、轻奢风、新中式 | 建议性 |
   | **15000 以上** | 顶奢款   | 顶级材质、服务、个性化设计、进口、原创类、功能齐全、线下 IP 款 | 加厚牛皮、全皮沙发；免费上门真皮保养；进口品牌、影音沙发、游戏沙发；头枕电动调节、全电动位 | 建议性 |

   ## 七、详情页规范

   ### 7.1 置顶模块：服务 / 权益

   | 项目             | 规范要求                                                     | 类型   |
   | ---------------- | ------------------------------------------------------------ | ------ |
   | **自营模块**     | 自营使用「京东自营家具 HomeCare+」                           | 建议性 |
   | **固定内容**     | 「什么是京东自营家具」内容不可变更；服务项可根据商家实际情况展示 | 要求性 |
   | **服务权益示例** | 免费送装、免费退换、100 天免费试睡、100 天价保、100 天无理由退货、5 年质保、绿色环保、破损包退换、家具现货 | 建议性 |

   ### 7.2 置顶模块：材质怎么挑

   | 皮质等级         | 皮质       | 特点                                     | 常见工艺               | 类型   |
   | ---------------- | ---------- | ---------------------------------------- | ---------------------- | ------ |
   | **1 号顶级真皮** | 全粒面牛皮 | 天然稀有、几乎无瑕疵、头层全真皮         | 摔纹、纳帕、油蜡、磨砂 | 建议性 |
   | **2 号轻奢真皮** | 半粒面牛皮 | 瑕疵很少、涂层薄、头层半真皮             | 摔纹、纳帕、油蜡、磨砂 | 建议性 |
   | **3 号优享真皮** | 修面牛皮   | 表面瑕疵经过修磨，辅以涂层饰面、头层牛皮 | 摔纹、压纹、油蜡、磨砂 | 建议性 |
   | **4 号入门真皮** | 剖层牛皮   | 瑕疵修磨较多、较厚涂层饰面、二层牛皮     | 压纹                   | 建议性 |

   ### 7.3 材质说明注意事项

   | 项目             | 规范要求                                       | 类型   |
   | ---------------- | ---------------------------------------------- | ------ |
   | **皮质选购指南** | 内容不可变更，根据产品实际情况选择对应皮号     | 要求性 |
   | **虚假宣传**     | 请勿虚假宣传，因此导致的客诉等问题商家全责承担 | 要求性 |
   | **展示图说明**   | 皮质展示图仅供参考，具体以实际商品为准         | 要求性 |

   ### 7.4 置顶模块：系列产品卖点对比

   | 项目         | 规范要求                                                   | 类型   |
   | ------------ | ---------------------------------------------------------- | ------ |
   | **对比目的** | 突出系列产品内不同型号的关键差异点，尤其是高配版本的升级点 | 建议性 |
   | **对比维度** | 材质、尺寸、容纳人数、核心功能、填充物、颜色               | 建议性 |

   ## 八、校验清单

   ### 8.1 上架前自检清单

   ```
   ## 主图检查（要求性）
   - [ ] 第 1 张主图中的营销贴片、价格、权益、服务等置于下方，未遮挡商品
   
   ## 主图检查（建议性）
   - [ ] 主图视频覆盖品宣/产品介绍/采销推荐等类型，并聚焦功能讲解和场景展现
   - [ ] 第 1 张清晰展示产品外观与利益点
   - [ ] 第 2 张包含尺寸和核心功能
   - [ ] 第 3 张包含卖点总览
   - [ ] 第 4-8 张以用户语言展开卖点和功能
   - [ ] 第 9 张展示颜色对比
   - [ ] 第 10 张展示服务/权益
   
   ## 标题检查（要求性）
   - [ ] 短标题 16-30 个字符
   - [ ] 长标题 60 个字符
   
   ## 标题检查（建议性）
   - [ ] 短标题结构符合品牌+型号+材质+功能+产品类型
   - [ ] 长标题结构包含品牌、型号、材质、功能、产品类型、颜色、尺寸、卖点词/趋势词
   
   ## 卖点检查（建议性）
   - [ ] 卖点按核心功能+产品卖点+核心服务组织
   - [ ] 卖点信息未与短标题重复
   - [ ] 已按价格段匹配材质、功能、服务等重点
   
   ## 销售属性检查（建议性）
   - [ ] 款式命名符合面料材质-真皮工艺-颜色-功能
   - [ ] 尺寸命名符合产品人数规格+长度+电动位数量
   
   ## 详情页检查（要求性）
   - [ ] 「什么是京东自营家具」内容不可变更
   - [ ] 皮质选购指南内容不可变更
   - [ ] 材质与服务描述不存在虚假宣传
   
   ## 详情页检查（建议性）
   - [ ] 置顶模块包含服务/权益
   - [ ] 置顶模块包含材质怎么挑
   - [ ] 系列产品卖点对比覆盖材质、尺寸、客坐人数、核心功能、填充物、颜色
   ```

   ### 8.2 常见问题

   | 问题                 | 原因                           | 解决方案                                       |
   | -------------------- | ------------------------------ | ---------------------------------------------- |
   | 主图信息影响商品展示 | 贴片、价格、权益或服务遮挡商品 | 将营销信息置于下方，确保商品清晰完整           |
   | 卖点理解成本高       | 卖点与短标题重复或偏工业术语   | 按用户语言展开核心功能、产品卖点和核心服务     |
   | 系列品区分不清       | 前置词不精简或价格带排序不明确 | 按经济款、品质款、高端款、顶奢款等前台语言区分 |
   | 材质客诉风险         | 皮质等级或工艺描述与实际不符   | 按实际商品选择对应皮号，避免虚假宣传           |

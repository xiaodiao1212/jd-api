   ## 一、整体规范综述（十大模块）

   商品信息围绕用户选购需求，通过优化以下 **10 项**基础内容，优化用户体验，提升转化率：

   | 模块         | 核心方向                                                     | 类型   |
   | ------------ | ------------------------------------------------------------ | ------ |
   | **主图**     | 首张含 6 大信息要素（商品名、商品展示、规格、品牌、卖点、价促）；前 5 张按产品主体/核心卖点→产品细节/口味卖点→场景递进；补充素材中心多种图类 | 建议性 |
   | **主图视频** | 种草向/商品展示/场景消费向的拍摄风格，15–30 秒，高清稳定配字幕 | 建议性 |
   | **长标题**   | 品牌+品名+形容词+规格，≤60 字符                              | 建议性 |
   | **短标题**   | 品牌+品名+形容词（择 2–3 个）+规格，16–30 字符               | 建议性 |
   | **卖点**     | 聚焦差异化，直击核心购买需求，重"解说性"；3个/SKU，每个4–8 字符（1个中文、数字都算作2个字符） | 建议性 |
   | **属性**     | 与长短标题、卖点、已选弹层、主图等商详外露信息一致；提升通用属性覆盖率 | 建议性 |
   | **系列品**   | 同店内以类别/规格/包装/口味/成分/系列为主题划分，缩短决策路径 | 建议性 |
   | **尺码绑定** | 结构化命名：核心卖点+品名+净含量规格+包装形式，不同末级不能绑在同一SPU下 | 建议性 |
   | **主推标签** | 配置后 APP 显示「主推」标识，提升加购转化                    | 建议性 |
   | **品质标签** | 以工艺/关键成分/配料干净为主，京东特有品质楼层               | 建议性 |

   ## 二、主图规范

   ### 2.1 效果数据（原文）

   - 商详转化率 **+8.42%**；商详提袋率 **+3.33%** ↑

   ### 2.2 主图基础要求

   | 项目             | 规范要求                                                     | 类型   |
   | ---------------- | ------------------------------------------------------------ | ------ |
   | **文字排版**     | 整体有序，不同层级信息在字体大小、颜色、粗细等方面层级区分清晰 | 建议性 |
   | **色彩搭配**     | 符合品牌形象与商品特征，保证和谐统一                         | 建议性 |
   | **图片质量**     | 高分辨率、无模糊失真，提升宣传效果与用户体验                 | 建议性 |
   | **营销文字占比** | 建议不超过图片面积的 **35%**                                 | 建议性 |

   ### 2.3 首张主图核心要求（6 大信息要素）

   | 要素                 | 规范要求                                                     | 类型   |
   | -------------------- | ------------------------------------------------------------ | ------ |
   | **品牌**             | 以醒目字体与色彩展示品牌名与核心价值语，强化品牌认知与信任   | 建议性 |
   | **产品词与核心卖点** | 品名清晰，便于用户识别品类；展示 1–3 个核心差异化卖点        | 建议性 |
   | **产品展示**         | 商品主体（展现商品形式）+ 产品细节展示（口感/口味直观感受）+ 场景（凸显原料及食用场景） | 建议性 |
   | **信任背书**         | 简洁传达关键信任信息以增强用户信心                           | 建议性 |
   | **价格促销/商品名**  | 位于画面下部，可使用撞色设计；可含到手价、限时补贴、赠品等促销信息 | 建议性 |

   ### 2.4 主图前 5 张建议方向

   | 序号    | 内容要求     | 说明                                                         | 类型   |
   | ------- | ------------ | ------------------------------------------------------------ | ------ |
   | 第 1 张 | 核心卖点图   | 主体 + 核心卖点 + 促销（产地/工艺/场景/口味/口感/健康成分/品质/包装形态） | 建议性 |
   | 第 2 张 | 差异化卖点图 | 强化核心差异化卖点                                           | 建议性 |
   | 第 3 张 | 口感细节图   | 口味卖点、产品细节、口感可视化呈现（激发食欲）               | 建议性 |
   | 第 4 张 | 品质图       | 品类介绍 + 原料是否进口等                                    | 建议性 |
   | 第 5 张 | 食用场景图   | 产品食用场景（聚会/早餐/分享/童年回味等）                    | 建议性 |

   ### 2.5 差异化补充图

   - 检测报告、品牌背书
   - 配料表/营养成分表——物理呈现（简表直观 或 产品成分明细表）

   ### 2.6 优质主图结构化方向

   | 方向               | 核心表达                                                     | 适用场景           | 类型   |
   | ------------------ | ------------------------------------------------------------ | ------------------ | ------ |
   | **食欲表达**       | 以特写构图占据主要视觉；通过食物断面/酥脆特写/馅料凸显口感感知 | 威化类、夹心类     | 建议性 |
   | **原料与场景结合** | 以优质原料陈列传递健康与自然感                               | 巧克力饼干类       | 建议性 |
   | **大包装/组合装**  | 强化品种/口味的丰富感，凸显性价比                            | 苏打饼干、量贩装类 | 建议性 |

   ### 2.7 丰富素材图类型

   上传路径：京麦 → 商品 → 素材管理 → 商品素材

   | 素材类型   | 内容要求                       | 类型   |
   | ---------- | ------------------------------ | ------ |
   | **白底图** | 纯白底，无营销内容，1:1 方图   | 建议性 |
   | **卖点图** | 含卖点文字信息的 1:1 方图      | 建议性 |
   | **场景图** | 带背景，无营销内容，1:1 方图   | 建议性 |
   | **透明图** | 透明背景，无营销内容，1:1 方图 | 建议性 |

   ## 三、主图视频规范

   ### 3.1 基础要求

   | 项目         | 规范要求                         | 类型   |
   | ------------ | -------------------------------- | ------ |
   | **拍摄风格** | 种草向/商品展示/场景消费向       | 建议性 |
   | **时长**     | 15–30 秒（商品展示 20–30 秒）    | 建议性 |
   | **画面**     | 高清、明亮、稳定                 | 建议性 |
   | **字幕**     | 必须搭配字幕，便于无声环境观看   | 建议性 |
   | **BGM**      | 以轻松纯音乐为主，可搭配口播卖点 | 建议性 |

   ### 3.2 视频类型与结构

   | 类型           | 内容要求                                                     | 时长     | 类型   |
   | -------------- | ------------------------------------------------------------ | -------- | ------ |
   | **种草向**     | 核心卖点+ 工艺展示+ 真人互动展示商品+ 附加场景+ 口感表达     | 15–30 秒 | 建议性 |
   | **商品展示**   | 商品展示+卖点表达（酥脆/原料），镜头一聚焦商品本身，突出膨化体积感、产品形态、倒落/堆叠等视觉效果 | 20–30 秒 | 建议性 |
   | **场景消费类** | 商品 + 消费场景（追剧/聚会/办公零食），突出解馋与分享属性    | 15–30 秒 | 建议性 |

   ## 四、长标题规范

   ### 4.1 效果数据

   - 商详转化率 **+0.6%**；商详提袋率 **+1.66%** ↑

   ### 4.2 基本要求

   | 项目         | 要求                                                         | 类型   |
   | ------------ | ------------------------------------------------------------ | ------ |
   | **字数**     | ≤60 个字符（1 英文/数字/符号 = 1 字符；1 汉字 = 2 字符；品牌前缀不计入） | 建议性 |
   | **结构**     | 品牌 + 品名 + 形容词 + 规格                                  | 建议性 |
   | **规格表达** | （单件净含量×数量）或（总净含量+数量），标明克数             | 建议性 |
   | **禁止**     | 避免不良营销话术（如「买一送一」「TOP1」等）                 | 建议性 |

   ### 4.3 结构化公式

   **饼干：**

   ```
   【品牌】+【品名】+【核心风味/原料】+【品质/工艺描述】+【场景/属性】+【规格/包装】+【适用场景】
   ```

   示例：碧翠园 燕麦谷物棒坚果味酥脆高蛋白烘焙盒装 20g×25 支代餐饱腹

   **膨化食品：**

   ```
   【品牌】+【品名】+【口味/风味】+【口感/形态】+【规格/包装】+【趣味/场景】
   ```

   示例：热烈 爆米花奶油非油炸微波炉酥脆袋装 100g×10 袋休闲伴侣

   ### 4.4 形容词 8 大类

   产地 / 工艺 / 场景 / 口味 / 口感 / 健康成分 / 品质 / 包装形态

   ### 4.5 优化案例

   - **优化前：** 〔品牌〕零食大礼包 636g 馍片雪饼馍丁办公室零食  
   - **优化后：** 〔品牌〕零食大礼包 多口味 混合装 馍片雪饼馍丁 办公室 解馋零食 636g

   ## 五、短标题规范

   ### 5.1 效果数据

   - 搜索点击率 ↑

   ### 5.2 基本要求

   | 项目           | 要求                               | 类型   |
   | -------------- | ---------------------------------- | ------ |
   | **字数**       | 16–30 个字符（计数规则同长标题）   | 建议性 |
   | **结构**       | 品牌 + 品名 + 形容词 + 规格        | 建议性 |
   | **精简**       | 形容词从 8 大类中择 **2–3 类**组合 | 建议性 |
   | **展示优先级** | 中文名优于英文名缩写               | 建议性 |
   | **品牌字符**   | 需特别注意品牌所占字符数           | 建议性 |
   | **禁止**       | 避免不良营销话术                   | 建议性 |

   ### 5.3 优化案例

   - **优化前：** 美心 多口味鸡蛋卷  
   - **优化后：** 美心 四口味 鸡蛋卷 208g 礼盒装  
   - **策略：** 增补口味类型「四口味」+ 规格「208g」+ 包装属性「礼盒装」

   ## 六、通用卖点规范

   ### 6.1 效果数据

   - 搜索点击率 ↑

   ### 6.2 基本要求

   | 项目           | 要求                                                         | 类型   |
   | -------------- | ------------------------------------------------------------ | ------ |
   | **数量**       | 每 SKU **3 条**卖点                                          | 建议性 |
   | **字数**       | 每条 **4–8 个字**（汉字或数字各计 2 字符）                   | 建议性 |
   | **选词优先级** | 优先取长标题中存在但短标题因字数无法展现的关键形容词，避免与短标题重复 | 建议性 |
   | **定位**       | 聚焦产品差异化，直击用户核心购买需求，重"解说性"             | 建议性 |

   ### 6.3 五大维度推荐词

   | 维度         | 推荐词示例                                | 类型   |
   | ------------ | ----------------------------------------- | ------ |
   | **品质工艺** | 进口原料/进口奶源、传统工艺/手工制作      | 建议性 |
   | **健康功能** | 0 糖/低糖、高膳食纤维、饱腹代餐、养胃配方 | 建议性 |
   | **口感风味** | 酥脆可口、入口即化、层层酥脆、浓郁夹心    | 建议性 |
   | **包装场景** | 独立小包装、锁鲜罐装、大容量分享装        | 建议性 |
   | **情绪价值** | 童年怀旧味、趣味造型、网红爆款            | 建议性 |

   ### 6.4 搭配建议

   建议在三大主轴各选其一搭配：**"品质/健康" + "口感/风味" + "场景/情绪"**

   ### 7.1 效果数据

   - 商详转化率 ↑

   | 项目         | 要求                                                         | 类型   |
   | ------------ | ------------------------------------------------------------ | ------ |
   | **一致性**   | 属性须与长/短标题、卖点、已选弹层、主图等商详外露信息保持一致，避免客诉与用户流失 | 建议性 |

   - 详情写 200g、SKU 写 220g → 属错误示范

   ## 九、尺码绑定规范（SKU 规格命名）

   ### 9.1 绑定规则

   - SKU 的末级类目、品牌、SPU 一致化属性等信息需要保持一致
   - 共用权重、评价等，避免用户在相似商品间反复对比

   ### 9.2 命名结构

   ```
   核心卖点 + 品名（简短类目名为主）+ （单件净含量×数量）或（总净含量+含数量）+ 包装形式（礼盒装需特别强调）
   ```

   ### 9.3 优秀案例

   - 【高膳食纤维】谷物酸奶夹心 220g ¥17.76
   - 【超值组合】燕麦玉米饼干 265g×4 ¥38.86
   - 【西班牙进口】金黄脆饼干 200g ¥8.5
   - 【独立小包】莓果酸奶夹心 220g ¥18.42

   ## 十、主推标签规范

   ### 10.1 效果数据

   - 商详转化率 **+2.95pp** ↗

   ### 10.2 说明

   主推标签是对主推商品配置打标的工具，商家完成配置后，在京东 APP 上会有对应的「主推」标识，用户在浏览商品详情时，能直观看到主推商品标志，有助于提升商品的加购转化。

   ## 十一、品质标签规范

   ### 11.1 效果数据

   - 商详转化率 **+0.19%** ↗

   ### 11.2 说明

   基于行业制定更高质检标准，建议以配料/关键成分（0 脂、配料干净、低 GI、富含膳食纤维）为主。安心品质为京东特有品质楼层，竞品无同等露出。

   ### 11.3 品质标签定义

   | 标签             | 定义                                                         | 类型   |
   | ---------------- | ------------------------------------------------------------ | ------ |
   | **低 GI**        | 含可利用碳水化合物且血糖生成指数（GI）≤ 55 的食品，可减缓消化吸收减少血糖波动 | 建议性 |
   | **中华老字号**   | 历史悠久，拥有世代传承的产品、技艺或服务，具有鲜明中华民族传统文化背景和深厚文化底蕴 | 建议性 |
   | **配料干净**     | 通过《京东自营商品配料干净品质认证标准》，在满足食品工艺基础上确保不使用"非必要"食品添加剂等 | 建议性 |
   | **0 糖、低糖**   | 依据 GB28050《食品安全国家标准-预包装食品营养标签通则》标准进行规定 | 建议性 |
   | **0 反式脂肪酸** | 依据 GB28050《食品安全国家标准-预包装食品营养标签通则》标准进行规定 | 建议性 |
   | **低脂**         | 依据 GB28050《食品安全国家标准-预包装食品营养标签通则》标准进行规定 | 建议性 |
   | **富含膳食纤维** | 依据 GB28050《食品安全国家标准-预包装食品营养标签通则》标准进行规定 | 建议性 |

   ## 十二、校验清单（运营自检）

   ```
   ## 主图（建议性）
   - [ ] 文字排版层级清晰，色彩协调，高分辨率无模糊
   - [ ] 营销文字占比 ≤35%
   - [ ] 首图含 5 大要素：商品名、商品展示、规格、品牌、卖点
   - [ ] 前 5 张覆盖：核心卖点→差异化卖点→口感细节→品质→食用场景
   - [ ] 补充素材中心：白底图 / 卖点图 / 场景图 / 透明图
   
   ## 主图视频（建议性）
   - [ ] 15–30 秒，高清稳定
   - [ ] 搭配字幕，BGM 轻松不挡口播
   - [ ] 内容覆盖核心卖点 + 工艺展示 + 真人互动展示商品 + 附加场景 + 口感表达
   
   ## 长标题（建议性）
   - [ ] ≤60 字符（品牌前缀不计入）
   - [ ] 结构：品牌 + 品名 + 形容词 + 规格
   - [ ] 规格标明克数
   - [ ] 无不良营销话术
   
   ## 短标题（建议性）
   - [ ] 16–30 字符（品牌名计入）
   ```

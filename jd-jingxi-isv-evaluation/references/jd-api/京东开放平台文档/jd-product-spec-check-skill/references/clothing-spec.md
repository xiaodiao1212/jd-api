## 一、整体规范综述

优质主图建议维护长图，适用首页推荐、潮流好货、搜索、商详等流量场域。服饰类目主图核心围绕商品主体面积、营销区域面积、主图留白、商品呈现方式和背景进行判断。

### 场域核心要求

| 模块                 | 核心方向                                                    | 类型   |
| -------------------- | ----------------------------------------------------------- | ------ |
| **商品主体面积占比** | 首页推荐、潮流好货、搜索、商详首帧均需商品主体面积占比 ≥40% | 要求性 |
| **营销区域面积占比** | 首页推荐、潮流好货 <5%；搜索、商详首帧 ≤35%                 | 要求性 |
| **主图留白占比**     | 首页推荐、潮流好货、搜索、商详首帧均需 ≤10%                 | 要求性 |
| **商品呈现方式**     | 各场域均为模特长图                                          | 要求性 |
| **背景**             | 各场域均为场景图（非白底）                                  | 要求性 |
| **LOGO**             | 各场域均可有                                                | 建议性 |
| **腰带 / 贴片**      | 首页推荐、潮流好货无；搜索、商详首帧可有适量信息            | 要求性 |

## 二、主图规范

### 2.1 场域规则总表

| 应用场域             | 首页推荐、潮流好货 | 搜索             | 商详首帧         | 类型   |
| -------------------- | ------------------ | ---------------- | ---------------- | ------ |
| **商品主体面积占比** | ≥40%               | ≥40%             | ≥40%             | 要求性 |
| **营销区域面积占比** | <5%                | ≤35%             | ≤35%             | 要求性 |
| **主图留白占比**     | ≤10%               | ≤10%             | ≤10%             | 要求性 |
| **商品呈现方式**     | 模特长图           | 模特长图         | 模特长图         | 要求性 |
| **背景**             | 场景图（非白底）   | 场景图（非白底） | 场景图（非白底） | 要求性 |
| **LOGO**             | 可有               | 可有             | 可有             | 建议性 |
| **腰带 / 贴片**      | 无                 | 可有适量信息     | 可有适量信息     | 要求性 |

### 2.2 商品主体面积占比

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **定义**     | 商品需明确清晰，商品主体面积占整个主图画面比例 ≥40%          | 要求性 |
| **正确示例** | 商品主体面积占比 ≥40%                                        | 要求性 |
| **错误示例** | 商品主体面积占比 <40%                                        | 要求性 |
| **特殊商品** | 腰带、裤子等形态较细长，商品主体面积无法 ≥40% 时，只需商品主体高度或宽度占主图整体高度或宽度 80% 以上，也可满足优质和一般主图条件 | 要求性 |

### 2.3 营销区域面积占比与尺寸

| 项目             | 规范要求                                                 | 类型   |
| ---------------- | -------------------------------------------------------- | ------ |
| **建议尺寸**     | 方图 1:1 为 800×800px；长图 3:4 为 750×1000px            | 建议性 |
| **营销区域定义** | 主图中除商品主体外的文字卖点&logo&设计元素等称为营销区域 | 要求性 |
| **营销面积占比** | 营销区域面积 / 主图整体面积                              | 要求性 |

### 2.4 营销面积场域阈值

| 场域               | 等级     | 营销区域面积占比 | 类型   |
| ------------------ | -------- | ---------------- | ------ |
| **推荐**           | 优质     | <5%              | 要求性 |
| **推荐**           | 一般     | ≤10%             | 要求性 |
| **搜索、商详首帧** | 优质     | ≤35%             | 要求性 |
| **搜索、商详首帧** | 错误示例 | >35%             | 要求性 |

### 2.5 主图留白面积占比

| 项目         | 规范要求                             | 类型   |
| ------------ | ------------------------------------ | ------ |
| **定义**     | 主图四周留白面积占主图整体面积的占比 | 要求性 |
| **正确示例** | 主图留白面积 ≤10%                    | 要求性 |
| **错误示例** | 主图留白面积 >10%                    | 要求性 |

### 2.6 商品呈现方式

| 项目     | 规范要求                                                 | 类型   |
| -------- | -------------------------------------------------------- | ------ |
| **定义** | 需通过模特穿戴或使用商品的画面清晰呈现商品版型和上身效果 | 要求性 |
| **示例** | 模特图（如真人穿搭）、非模特图（如平铺、挂拍展示）       | 建议性 |

### 2.7 背景

| 项目           | 规范要求                                     | 类型   |
| -------------- | -------------------------------------------- | ------ |
| **背景定义**   | 场景实拍图，背景不是纯白底，背景避免过于杂乱 | 要求性 |
| **合规方向**   | 卖点图、图片有背景非纯白底                   | 建议性 |
| **不建议方向** | 白底图、背景杂乱                             | 建议性 |

### 2.8 低质案例

| 问题                      | 说明 | 类型   |
| ------------------------- | ---- | ------ |
| **商品主体面积占比 <40%** | 低质 | 要求性 |
| **营销区域面积占比 >35%** | 低质 | 要求性 |
| **主图留白面积 >35%**     | 低质 | 要求性 |
| **人物贴片 - 脸部遮挡**   | 低质 | 要求性 |
| **商品主体遮挡 / 残缺**   | 低质 | 要求性 |

## 三、图文布局与其他要求

### 3.1 图文布局方式

| 布局方式     | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **叠放布局** | 模特占据画面主要区域；文字位置：避免遮挡产品或关键细节，确保文字清晰可读 | 建议性 |
| **插空布局** | 适合留白空间大或干净背景；文字位置：如核心卖点、品牌名叠加在画面空白处（顶部、底部、左右侧）利用模特身体形成的空白区（如头部上方、手臂/腿部外侧） | 建议性 |
| **集中布局** | 在单张主图中展示同一商品不同模特（不同体格/风格）或同一模特不同角度/穿着方式；文字位置：集中在画面顶部、底部或一侧的统一区域 | 建议性 |

### 3.2 其他要求

| 项目               | 规范要求                                                     | 类型   |
| ------------------ | ------------------------------------------------------------ | ------ |
| **文件格式及大小** | JPG / PNG，不超过 3MB                                        | 要求性 |
| **品牌一致性传达** | 所有主图在色调、风格、排版上应保持一致的品牌调性，提升专业感和信任度 | 建议性 |
| **画面清晰度**     | 避免模糊、噪点或过曝，确保商品细节（如面料纹理、车线）清晰可见 | 要求性 |
| **模特选择**       | 所符合目标客群特征（如年龄、体型、肤色），避免过度修图导致色差或比例失真 | 建议性 |
| **拍摄角度**       | 平视角度为主（镜头高度与模特腰部齐平）避免俯视/仰视导致比例失真 | 建议性 |
| **图片真实性**     | 图片必须真实反映所售商品，禁止使用与实物严重不符的图片（过度美化/色差） | 要求性 |

### 3.3 色彩与光线管理

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **色彩应用** | 主图色调与品类风格匹配                                       | 建议性 |
| **色彩还原** | 拍摄时使用标准色卡校准，后期避免过度调色导致色差多SKU（颜色）商品需单独拍摄，确保颜色真实（如黑色、深蓝色需区分） | 要求性 |
| **光线要求** | 使用柔光箱或自然光，避免硬光造成反光或阴影多角度布光，确保商品立体感（如侧光突出面料质感） | 建议性 |

**色温示意：**

| 1000K-5000K 主观暖色光源 | 5000K-6000K 客观标准光源 | 6000K-10000K 主观冷色光源 |
| ------------------------ | ------------------------ | ------------------------- |
|                          |                          |                           |

### 3.4 合规与版权要求

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **平台规则** | 建议不要出现拼接图、水印、边框或促销文字                     | 建议性 |
| **素材授权** | 禁止使用侵权素材（如未经授权的IP形象、明星同款设计）         | 要求性 |
| **模特授权** | 确保模特肖像权授权文件完备，避免法律风险                     | 要求性 |
| **知识版权** | 确保图片、字体、设计元素不侵犯他人版权、商标权等知识产权。使用正版字体 | 要求性 |

## 四、校验清单

### 4.1 上架前自检清单

```
## 主图检查（要求性）
- [ ] 商品主体面积占比 ≥40%
- [ ] 推荐场域营销区域面积占比 <5%
- [ ] 搜索、商详首帧场域营销区域面积占比 ≤35%
- [ ] 主图留白面积占比 ≤10%
- [ ] 商品呈现方式为模特长图
- [ ] 背景为场景图（非白底）
- [ ] 首页推荐、潮流好货无腰带/贴片
- [ ] 搜索、商详首帧腰带/贴片可有适量信息
- [ ] 文件格式为 JPG/PNG 且不超过 3MB
- [ ] 图片真实反映所售商品，无过度美化/色差
- [ ] 无未经授权的IP形象、明星同款设计、字体或设计元素
- [ ] 模特肖像权授权文件齐全

## 主图检查（建议性）
- [ ] 优质主图维护长图（3:4）
- [ ] 腰带、裤子等细长商品主体高度或宽度占图 ≥80%
- [ ] 品牌Logo、促销标签等文字清晰可见且不遮挡商品关键细节
- [ ] 多 SKU 颜色单独拍摄且色彩真实
- [ ] 色调、风格、排版保持一致的品牌调性
- [ ] 使用柔光箱或自然光，避免硬光反光和阴影
```

### 4.2 常见问题

| 问题           | 原因                                | 解决方案                              |
| -------------- | ----------------------------------- | ------------------------------------- |
| 主图被判低质   | 商品主体面积 <40% 或留白 >35%       | 调整构图，提高主体占比并减少四周留白  |
| 推荐场域不达标 | 营销区域面积 >10% 或出现腰带 / 贴片 | 压缩营销信息，推荐场域去除腰带 / 贴片 |
| 商品信息遮挡   | 贴片遮挡脸部或商品主体              | 将文字移至空白区，避免遮挡核心细节    |
| 颜色客诉       | 多 SKU 色彩未真实还原               | 单独拍摄颜色 SKU，并使用标准色卡校准  |

# 家用电器 厨卫大电商品信息运营规范

## 一、整体规范综述（四大模块）

商品信息围绕用户选购需求，通过优化以下 **4 项**基础内容，提升流量转化效率：

| 模块         | 核心方向                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **主图**     | 结构化，核心决策信息聚焦于首屏主图位置，提升选购效率；单品第 1–8 张按场景/安装尺寸/选购重点/差异化卖点/风格/套装递进 | 建议性 |
| **标题**     | 规范化，长标题用于展示、召回和排序；短标题仅用于用户展示，须清晰便于记忆识别 | 建议性 |
| **SPU 绑定** | 标准化，按品类制定绑定规则（上下结构 / 左右结构），模糊信息标准化、简单清晰可识别 | 建议性 |
| **详情页**   | 模块化，选购指引加速建立信任，促成转化                       | 建议性 |

## 二、主图规范

### 2.1 单品主图结构（第 1–8 张）

| 主图          | 内容要求                                                     | 类型   |
| ------------- | ------------------------------------------------------------ | ------ |
| **第 1 张**   | 场景图，包含产品权益 + 实测卖点；首图按中高端 / 经济款两类不同设置（见 2.2） | 建议性 |
| **第 2 张**   | 产品安装尺寸（厨卫**强安装品类**为主）                       | 建议性 |
| **第 3 张**   | 采销测评品类选购重点 + 产品差异化卖点汇总（见 2.3 检测标准） | 建议性 |
| **第 4–7 张** | 差异化卖点                                                   | 建议性 |
| **第 8 张**   | 风格/ 套装 选择（视单品情况而定）                            | 建议性 |

### 2.2 首张主图：中高端 vs 经济款

| 类型       | 视觉要求                                                     | 牛皮癣 / 促销                                  | 类型   |
| ---------- | ------------------------------------------------------------ | ---------------------------------------------- | ------ |
| **中高端** | 指定场景、背景色聚焦**黑金白场景 / 非场景**；场景图注意背景中橱柜的品质感 | 减少利益点贴片及促销信息，保持页面干净、质感   | 建议性 |
| **经济款** | **白底图 + 腰带**，类目示例：电热水器、燃气热水器、油烟机、灶具、消毒柜 | 除底部腰带（活动文案）外，无其他贴片及促销信息 | 建议性 |

> 中高端两种版式：**场景长主图**与**无场景长主图**；每种均区分「无贴片版本」与「有贴片版本」。促销腰带常见信息：到手价、下单立减、N 天无忧换、上门安装、N 天价保等。

### 2.3 第 3 张主图选购标准 — 检测标准（按品类）

| 品类           | 标准示例                                                     | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **油烟机**     | 吸烟能力：实测漏烟越少越好；排烟能力：实测风量越大 & 与品牌宣称差值越小越好；噪音大小：实测最大、巡航档位的噪音值，越小越好 | 建议性 |
| **洗碗机**     | 基础洗净 / 重油污洗净 / 加磅洗净 / 暴力测试；不看套数看升数和尺寸 | 建议性 |
| **燃气热水器** | 启停温差（建议 ≤2°C）；多点用水性能；运行噪音（满 / 低功率）；耗气量（越小越节能） | 建议性 |
| **壁挂炉**     | 耗气量；运行噪音（满 / 低功率）；多点用水性能                | 建议性 |

## 三、长标题规范

### 3.1 基本要求

| 项目         | 要求                                                         | 类型               |
| ------------ | ------------------------------------------------------------ | ------------------ |
| **字数**     | 建议控制在 **30 个字（60 个字符）** 以内，搜索商卡可清晰展示双行标题，不折叠 | 建议性             |
| **结构**     | 品牌名称 + 系列名 + 型号（选填）+ 卖点词（至少包含 **2–4 个**）+ 品类词 | 建议性             |
| **简明扼要** | 标题和卖点内容做到简明扼要                                   | 要求性（原文表述） |
| **去重**     | 卖点和短标题中的卖点文字不要重复、指向释义                   | 建议性             |
| **用户语言** | 强调用户语言，避免工业语言（如「AG 玻璃」「7A 恒温」等行业术语不要使用），可改为「抗指纹玻璃」「耐脏污玻璃」等通俗易懂的语言 | 建议性             |

### 3.2 卖点表达 2 种形式

1. 对功能卖点进行**深化描述**（通俗化）；
2. **其他卖点补充**。

### 3.3 优化案例

**热水器**

- 双行：海尔巨能洗JH9 3D速热 超大热水量 0水垢 净肤洗 一级能效电热水器 [京东自营]
- 建议：海尔巨能洗JH9 净肤洗电热水器 [京东自营]

**油烟机**

- 双行：老板风神E1P全自动双腔顶吸30大吸力/1500Pa家用油烟机 [京东自营]
- 建议：老板风神E1P大吸力全自动油烟机 [京东自营]

## 四、SPU 绑定规范

### 4.1 定义与目的

| 项目         | 要点                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **定义规则** | 梳理各个品类不同绑定规则，针对销售属性进行优化，结合系统能力提供规范化梳理，提升前台商家维护的规范性 | 建议性 |
| **目的**     | 清晰合理地罗列商品，符合用户选购逻辑                         | 建议性 |

### 4.2 标准维度

| 维度         | 档位                              | 类型   |
| ------------ | --------------------------------- | ------ |
| **4 个阶梯** | 经济款 / 品质款 / 旗舰款 / 顶配款 | 建议性 |
| **3 个阶梯** | 品质款 / 高端款 / 顶配款          | 建议性 |

### 4.3 运营品类（按 SPU 结构）

| 结构         | 品类清单                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **上下结构** | 电热水器、油烟机、燃气灶、太阳能热水器、灶具、嵌入式微蒸烤   | 建议性 |
| **左右结构** | 燃气热水器、壁挂炉、洗碗机、消毒柜、空气能热水器、集成灶、电热水龙头 | 建议性 |

### 4.4 新版规格命名（改版后）

**上下结构 · 油烟机示例**

| 阶梯   | 命名                |
| ------ | ------------------- |
| 经济款 | 经济款（全能王）    |
| 品质款 | 品质款（大吸力）    |
| 旗舰款 | 旗舰款（变频）      |
| 顶配款 | 顶配款（30 m³/min） |

**左右结构 · 燃气热水器示例**

| 阶梯     | 命名                     |
| -------- | ------------------------ |
| 主流推荐 | 经济款全能王             |
| 品质款   | 【品质款】13 升 一级静音 |
| 旗舰款   | 【旗舰款】16 升 零冷水   |
| 顶配款   | 【顶配款】20 升 全屋恒温 |

## 五、商详页规范

### 5.1 视频端 vs 图文端策略对照

| 屏次                   | 视频端                                                       | 图文端                                                     | 类型   |
| ---------------------- | ------------------------------------------------------------ | ---------------------------------------------------------- | ------ |
| **第一屏（规范要求）** | 品类横测视频（基础知识普及，锚定品牌系列)目的：视频化品类选购指南重点突出主卖点（风量、噪音、风压等数值） | 选购指南、辅助用户选择（采用小红书风格）、用户语言参数图表 | 建议性 |
| **第二屏（规则要求）** | 测评卖点短视频，类似抖音、小红书风格，时长 ≤30S              | —                                                          | 建议性 |

### 5.2 详情模块化核心逻辑

| 模块           | 核心要求                                                     | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **选购指南卡** | (1) 将「非关键参数」从选购页中简化后置，在手机一屏内不需翻屏即可看清差异；(2) 明确三档型号定位，辅助用户精准初步筛选； 核心参数差异化显眼，降低用户决策成本；（3）将技术参数转化为可感知的使用体验；（4）围绕用户真实决策路径重构信息顺序 | 建议性 |
| **导购语**     | (1) 首屏用一句话完成产品定位传达；(2) 明确卖点词，突出关键卖点；(3) 弱化背书元素，提升用户浏览效率；（4）强化型号的展现；（5）用结果语言替代技术说明 | 建议性 |
| **卖点展示**   | (1) 主动挖掘痛点，解决用户最关心的痛点；(2) 卖点表达轻量化，降低理解成本；(3) 视觉明亮轻松，优化手机端浏览习惯；(4) 突出重点，帮助用户快速形成记忆；（5）手机友好型商详转变 | 建议性 |

### 5.3 案例参考（华帝 253 系列热水器）

选购指南对比维度（基础款 253M / 升级进阶款 253X / 高配款 253S）：产品外观、补水增压、恒温稳定性、适用场景、经济节能、静音运行、尺寸大小、质保服务。

**253X 2025 款示例标题：**

```
超一级能效 220%大增压 多点供水 燃气热水器
```

> 案例细节（105% 热效率 / 4609 元可省 / 220% 增压 / 4.0 水伺服 / 36 分贝 / AI+APP 智控 / 智能集水盒 / 4 种安装方式 / 8 年质保）见原图 5、6，仅为商家长图示例，不构成普适规范条款。

## 六、校验清单（运营自检）

```
## 主图（建议性）
- [ ] 单品 8 张结构：场景/安装尺寸/选购+差异化卖点/差异化卖点/套装-风格
- [ ] 首图按中高端（场景，黑金白）/ 经济款（白底+腰带）正确分类
- [ ] 中高端主图减少利益点贴片与促销信息，保持质感
- [ ] 经济款除底部腰带外无其他贴片及促销信息
- [ ] 第 3 张选购重点覆盖品类对应检测标准（油烟机/洗碗机/燃气热水器/壁挂炉）

## 长标题（建议性）
- [ ] ≤30 字 / 60 字符
- [ ] 结构：品牌 + 系列名 + 型号（选填）+ 卖点词（2–4 个）+ 品类词
- [ ] 卖点和短标题中的卖点文字不重复
- [ ] 已去除「AG 玻璃」「7A 级蓝」等工业语言，改用通俗用户语言

## SPU 绑定（建议性）
- [ ] 按 4 阶梯（经济/品质/旗舰/顶配）或 3 阶梯（品质/高端/顶配）划分
- [ ] 上下结构品类（电热水器/油烟机/燃气灶/太阳能热水器/灶具/嵌入式微蒸烤）按规则绑定
- [ ] 左右结构品类（燃气热水器/壁挂炉/洗碗机/消毒柜/空气能热水器/集成灶/电热水龙头）按规则绑定

## 商详页（建议性）
- [ ] 第一屏：视频端凝聚核心参数，图文端含选购指南卡
- [ ] 第二屏：测评 / 功能视频时长 ≤30S
- [ ] 选购指南卡 / 商详首屏 / 卖点展示三模块齐备
- [ ] 核心参数差异化显眼，导购语一句话完成定位
```

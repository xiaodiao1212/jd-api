> **来源：** 京东商品运营中心官方建议  **文档链接：**[京东商品运营中心](https://mtt.jd.com/serviceno/servicenoHomePage/378) · [专题：商品信息促转化](https://mtt.jd.com/index/collection-detail?collectionId=39051)    **提取方式：** OCR 识别原图内容  **说明：** 「官方建议」为平台经验归纳，供商家参考，**非**强制性平台规则。下文「要求性/建议性」依原图表述与项目既有规格文档惯例归纳，自检时须与平台强制规则区分。

\## 一、整体规范综述

商品信息围绕用户选购需求，通过优化产品主图、标题、卖点、系列品、商品详情页，提升流量转化效率。

| 模块                        | 规范方向                                                     |
| --------------------------- | ------------------------------------------------------------ |
| 主图                        | 结构化，核心决策信息聚焦于首屏主图位置，从而提升选购效率     |
| 标题                        | 结构化，长标题用于精准呈现商品核心信息，表述简明、准确且详尽，既可实现精准检索召回，也有助于构建买家信任度；短标题聚焦提炼商品核心卖点，仅用于前端用户展示，通过清晰直观的核心信息，助力用户快速做出购买决策 |
| 卖点                        | 差异化，针对不同价格区间消费者所关注的核心信息，精准匹配对应产品卖点，助力用户高效完成购买决策 |
| 系列品工具（不同 SPU 绑定） | 标准化，制定不同品类绑定规则，模糊信息标准化、简单清晰可识别 |
| 详情页                      | 模块化，选购指引加速建立信任，促成转化                       |

## 二、主图规范

### 2.1 产品主图策略

| 价位段        | 规范要求                                                     |
| ------------- | ------------------------------------------------------------ |
| 超高端        | 突出高端、品质和品牌调性，头图（第 1 帧）换场景图，减少利益点、权益等信息 |
| 中高端 & 低端 | 保持现有策略，保持简洁，减少贴片数量，确保产品清晰、完整     |

### 2.2 结构化展示要求

| 位置                 | 内容要求                                                     |
| -------------------- | ------------------------------------------------------------ |
| 主图视频             | 提高主图视频覆盖率，包含品宣视频、产品介绍视频、采销推荐视频，需要突出产品功能、场景适用性 |
| 第 1 张：产品主图    | 核心展现产品外观，露出核心卖点/体验点。第一张主图确保产品完整清晰，不允许任何遮挡。底部可放价格、权益、服务等。可选：个性化、场景化主图，根据产品特性配置相应风格 |
| 第 2 张：尺寸        | 标注产品安装尺寸，扫地机上下水版本需注明购前咨询             |
| 第 3 张：服务/权益   | 如送装一体、购机权益等                                       |
| 第 4 张：卖点总览    | 一张图展示商品核心卖点/功能点，不超过 8 个                   |
| 第 5-10 张：卖点展开 | 用户语言阐释具体的卖点、功能                                 |

## 三、标题规范

### 3.1 短标题

| 项目   | 规范要求               |
| ------ | ---------------------- |
| 字符数 | 16-30 字符             |
| 格式   | 品牌 + 型号 + 产品类型 |

**示例：**

```
科沃斯T80S扫地机器人水箱版
```

### 3.2 长标题

| 项目   | 规范要求                                                     |
| ------ | ------------------------------------------------------------ |
| 字符数 | 90 字符                                                      |
| 结构   | 品牌 + 型号 + 产品类型 + 普适化卖点（2-4 个）+ 营销词 + 趋势词普适化卖点指用户普遍关心的功能点，如扫拖一体。 |

**趋势词：** 超薄、租房、大户型、嵌入式、长续航等。

**示例：**

```
科沃斯T80S扫地机器人水箱版扫拖一体自动清洗大户型
```

## 四、卖点规范

### 4.1 消费者关注

消费者关注清洁效果与效率、电池续航、口碑和性价比。结合消费者咨询高频问题，可将卖点拆分。

### 4.2 卖点优先级

| 层级     | 维度       | 说明                              |
| -------- | ---------- | --------------------------------- |
| 基础卖点 | 类型       | 单机/扫拖一体/自动清洗/自动集尘等 |
| 基础卖点 | 是否上下水 | 水箱无需安装/上下水需安装         |
| 基础卖点 | 尺寸       | 尤其是上下水安装尺寸              |
| 产品性能 | 建图越障   | 建图时间/越障高度                 |
| 产品性能 | 清洁效果   | 拖布类型/滚刷类型/擦地方式        |
| 产品性能 | 电池续航   | 适用面积                          |
| 产品性能 | 特色功能   | 沿边/热水清洗/热风烘干/外扩       |

## 六、商品详情信息规范

### 6.1 整体规范要求

| 项目     | 规范要求                                                     |
| -------- | ------------------------------------------------------------ |
| 核心参数 | 只展示核心参数，减少冗余信息、重复信息                       |
| 页面长度 | 控制商详页面长度，限制在 6-8 屏（不含前置模块，如背书、服务、权益） |
| 色调     | 商详需要色调一致                                             |
| 系列对比 | 同系列产品的功能可以做横向对比                               |

### 6.2 结构化要求

> 第几屏以手机端为准。

| 页面位置  | 内容要求                                                     |
| --------- | ------------------------------------------------------------ |
| 前置模块  | 信任建立（任选其一）：品牌背书、采销背书、口碑背书           |
| 前置模块  | 服务权益（如有）：如送装一体                                 |

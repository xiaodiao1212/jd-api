## 一、整体规范综述（6 大点位）

围绕用户决策路径，系统化提升 **主图、标题、卖点、详情、视频、属性** 6 大点位信息质量，驱动流量转化提升。

| 点位         | 核心方向                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **主图**     | 首图分区透传；针对 4 类机型（经济/品质/旗舰/顶奢）分层视觉；整体「总-分」结构 | 建议性 |
| **标题**     | 「品牌 + 核心要素」结构，重要性降序排列，无冗余关键词        | 建议性 |
| **卖点**     | 技术参数 → 用户语言；聚焦 2–3 个核心痛点（洗得干净 / 高效除菌 / 洗烘奢护 等） | 建议性 |
| **图文详情** | 「黄金四段」结构（首屏 / 次屏 / 中段 3–7 屏 / 尾屏 8–10 屏） | 建议性 |
| **视频**     | 4 类机型差异化视觉与信息策略，机型与客群精准匹配             | 建议性 |
| **属性**     | 「准」且「全」；关键属性前置至参数楼层；必填属性是商品信息分核心跃升因子 | 要求性 |

### 1.1 用户决策树（决策层 / 认知层 / 验证层）

| 层级       | 用户目标               | 决策因子                               | 透传路径                                                     |
| ---------- | ---------------------- | -------------------------------------- | ------------------------------------------------------------ |
| **决策层** | 核心需求匹配，决策购买 | 品牌、类型、容量、系列、功能、价位     | 结构化透传 → 搜索卡片核心点位 → 主图首图、长标题、短标题、卖点 |
| **认知层** | 强化购买信心，激发购买 | 系列指南、功能、技术、能效、材质、服务 | 高效率透传 → 商品详情核心点位 → 主图前屏、主图视频、参数楼层、详情顶部 |
| **验证层** | 增强信任背书，打消顾虑 | 质检、授权、其他参数、用户证言         | 补充性透传 → 商品详情核心点位 → 主图后屏、详情中尾部、规格参数 |

## 二、主图规范

### 2.1 效果数据（OCR 原文）

- 商详转化率 ↑ **6.83%**

### 2.2 首图规范（含结构与布局）

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **结构**     | 品牌（必备）+ 商品主体（必备）+ 卖点（非必备）+ 售后（非必备）+ 价格（非必备） | 要求性 |
| **商品主体** | 所有营销信息不可遮挡商品                                     | 要求性 |
| **卖点**     | ≤ **3 个**核心卖点，必须大字                                 | 要求性 |
| **售后**     | 有特色售后则写（如「10年电机保修」「价保 30 天」「白条 12 期免息」）；常规售后（「7 天无理由」「正品保障」）无需写 | 建议性 |
| **价格**     | 必须大字                                                     | 要求性 |
| **布局**     | 建议左右结构：左为品牌/卖点/售后/价格区，右为商品主体区      | 建议性 |

### 2.3 4 类机型分层视觉策略

| 机型       | 价位区间     | 信息关键                                       | 视觉关键                                                     | 类型   |
| ---------- | ------------ | ---------------------------------------------- | ------------------------------------------------------------ | ------ |
| **经济型** | < 1200元     | 一眼看清商品外观/价促/售后，体现好用便宜有保障 | 直观，纯色/浅灰背景或简单家居，明亮干净                      | 建议性 |
| **品质型** | 1200–3000 元 | 护衣/除菌/静音/智能等特色功能，体现生活精致感  | 场景，温馨家居/自然环境，强调全嵌/零嵌融合                   | 建议性 |
| **旗舰型** | 3000–5000 元 | 最新技术/极致性能，体现颠覆感与科技感          | 科技，极简暗调或高级家居，高对比强光效，凸显金属光泽与屏幕炫彩 | 建议性 |
| **顶奢型** | > 5000 元    | 艺术品/身份象征/传递品牌美学/生活理念/顶尖工艺 | 品味，顶级家居，电影感色调或黑白摄影，留白，静谧高雅         | 建议性 |

### 2.4 主图整体结构规范（首图 / 第 2 张 / 第 3 张 / 第 4–8 张）

## 三、长标题规范

### 3.1 效果数据

- 商详转化率 ↑ **1.92%**

### 3.2 基本要求

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **字数**     | **90 字符**，**不含品牌名**                                  | 建议性 |
| **结构**     | 品牌 + 系列 + 类型 + 洗涤容量 + 趋势词/功能词（≤ 5）+ 型号   | 建议性 |
| **品牌**     | 若品牌同时具备中文与英文名称，需要同时写出；仅英文则只写英文；仅中文则只写中文 | 建议性 |
| **类型**     | 写明具体类型（滚筒单洗、滚筒洗烘一体、洗烘套装、内衣洗衣机、波轮洗衣机等） | 建议性 |
| **功能词**   | 易懂、可检索；不使用晦涩技术术语（示例：将「双动力科技」改为「快洗、防缠绕」；将「纳米水离子」改为「健康除菌」） | 建议性 |
| **趋势词**   | 多筒、分区洗、热泵、超薄、大筒径、大容量                     | 建议性 |
| **容量单位** | 统一使用 **「KG」**；不使用「公斤」；不使用小写「kg」        | 建议性 |
| **分隔符**   | 使用空格分隔；不使用特殊符号                                 | 建议性 |
| **关键词**   | 不要堆砌、错用关键词（示例：迷你洗衣机不要写「大容量」）     | 建议性 |

### 3.3 品牌写法示例

- **双语示例：** 海尔(Haier)、小天鹅(LittleSwan)、美的(Midea)、西门子（SIEMENS）、卡萨帝(Casarte)…
- **仅英文示例：** AEG、V-ZUG、ASKO、COLMO、LG…
- **仅中文示例：** 追觅…

### 3.4 优化案例

- **优化前：** 海尔 (Haier) 云溪 4.0Max 系列 583 大容量洗烘套装 12kg 直驱滚筒洗衣机+12kg 热泵烘干机 京东自营 583+583 国补
- **优化后：** 海尔 (Haier) 云溪 4.0 滚筒洗烘套装 12KG 大容量 全自动 热泵烘干 洗羽绒服 国家补贴 XQG120-BLEU583HU1

## 五、商品卖点规范

### 5.1 效果数据

- 搜索点击率 ↑ **0.73%**
- 商品信息分 ↑ 提升

### 5.2 基本要求

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **结构**     | 最少 2 个、最多 3 个（示例：深层洁净｜AI 智能投放｜银离子除菌） | 建议性 |
| **字数**     | 每个2–8 字符（汉字、英文字母、数字、符号及空格均计入）       | 建议性 |
| **通俗易懂** | 将技术参数翻译为用户语言（示例：不单写「银离子」，写「银离子除菌」） | 建议性 |
| **去重**     | 不要重复短标题、主图利益点中已出现的信息                     | 建议性 |
| **内容范围** | 写产品功能、材质、技术；不要使用评价；不要使用价格促销作卖点 | 要求性 |

### 5.3 可写卖点

- 洗净比、能效等级、特色功能、特色材质
- 特色服务（例如：「365 天只换不修」「12 年电机保修」）

### 5.4 禁写卖点

- 常规服务（例如：「京东自营」「送货上门」「7 天无理由退货」）
- 好评率/销量
- 价格/促销词
- 违禁词与夸大宣称

## 六、图文详情规范（黄金四段）

### 6.1 基础要求

| 项目         | 规范要求                                                   | 类型   |
| ------------ | ---------------------------------------------------------- | ------ |
| **篇幅**     | 不超过 **10 屏**（以 APP 端为标准），每屏 1 个完整主题     | 建议性 |
| **文字**     | 标题大字加粗，让用户一目了然；内容文案精炼，避免大篇幅文字 | 建议性 |
| **通俗易懂** | 场景化、数据化地将技术参数转化为用户理解的卖点             | 建议性 |
| **结构**     | 采用「黄金四段」结构                                       | 建议性 |

### 6.2 黄金四段（屏数 / 内容要求 / 示例）

| 屏数                | 内容要求                                                    | 类型   |
| ------------------- | ----------------------------------------------------------- | ------ |

| **次屏**            | 商品全景 + 核心卖点概览                                     | 建议性 |

## 七、商品视频规范

基于 4 类机型用户（经济/品质/旗舰/顶奢）的洗衣诉求与功能偏好，制定差异化视觉及信息策略，实现机型与客群精准匹配。

### 7.1 经济型（< 1200 元）

> **用户画像：** 解决刚需，参数为王，消除购买疑虑，用户最担心「洗不干净」和「容易坏」。

| 项目     | 规范要求                                                 | 类型   |
| -------- | -------------------------------------------------------- | ------ |
| **时长** | ≤ 60 秒（最长不超过 90 秒）                              | 建议性 |
| **卖点** | ≤ 10 个                                                  | 建议性 |
| **节奏** | 高速 ≤ 1.5 秒/镜                                         | 建议性 |
| **音乐** | 全程激昂的背景音乐 + 人声解说 + 操作演示，营造真实使用感 | 建议性 |
| **字幕** | 大字加粗，大部分用户无声环境看，确保能看懂               | 建议性 |
| **风格** | 高调明亮，色彩鲜艳，对比度高，文字卖点密集               | 建议性 |

### 7.2 品质型（1200–3000 元）

> **用户画像：** 生活美学，解决痛点（如伤衣、噪音），兼顾颜值，注重生活品质，有孩子或养宠物的家庭需求。

| 项目     | 规范要求                                         | 类型   |
| -------- | ------------------------------------------------ | ------ |
| **时长** | ≤ 60 秒（最长不超过 90 秒）                      | 建议性 |
| **卖点** | ≤ 10 个                                          | 建议性 |
| **节奏** | 中速 2–3 秒/镜，给用户反应和品味的时间           | 建议性 |
| **音乐** | 保留生活底噪（轻音乐、自然声音等）+ 人声解说     | 建议性 |
| **字幕** | 大字加粗，大部分用户无声环境看，确保能看懂       | 建议性 |
| **风格** | 柔和光影，暖色调，融入家居环境，开始注重材质质感 | 建议性 |

### 7.3 旗舰型（3000–5000 元）

> **用户画像：** 技术霸权，极致性能，身份认同，高收入人群，别墅/大平层用户，科技控，对价格不敏感，但对「黑科技」极度敏感。

| 项目     | 规范要求                                                     | 类型   |
| -------- | ------------------------------------------------------------ | ------ |
| **时长** | ≤ 60 秒（最长不超过 90 秒）                                  | 建议性 |
| **卖点** | ≤ 10 个                                                      | 建议性 |
| **节奏** | 缓慢有力，3–4 秒/镜，可加入升格慢镜头                        | 建议性 |
| **音乐** | 采用电影感宏大管弦乐或科技感电子乐，营造高端氛围，可无需人声解说 | 建议性 |
| **字幕** | 大字加粗，只写关键词，不写长句，给用户想象空间               | 建议性 |
| **风格** | 赛博朋克/科技蓝调，暗场环境光，突出金属拉丝、玻璃面板的冷峻质感，多用光影流动 | 建议性 |

### 7.4 顶奢型（> 5000 元）

> **用户画像：** 不谈参数，谈艺术、传承、服务与生活方式，用户拥有独立洗衣房，需要护理高级面料（真丝、羊绒、皮革）等。

| 项目     | 规范要求                                    | 类型   |
| -------- | ------------------------------------------- | ------ |
| **时长** | ≤ 60 秒（最长不超过 90 秒）                 | 建议性 |
| **卖点** | 可以没有                                    | 建议性 |
| **节奏** | 极慢，5 秒以上/镜，讲究呼吸感，甚至大量留白 | 建议性 |
| **音乐** | 极致的静，细微环境音，或者舒缓的古典钢琴曲  | 建议性 |
| **字幕** | 不要字幕或极简                              | 建议性 |
| **风格** | 光影柔和、简约                              | 建议性 |

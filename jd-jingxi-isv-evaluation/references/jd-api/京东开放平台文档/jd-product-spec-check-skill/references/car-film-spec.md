## 一、整体规范综述

商品信息围绕用户选购需求，通过优化产品主图、主图视频、标题、卖点、参数楼层&属性、品质标签和图文详情等 **8 项基础内容**，优化用户体验，提升转化率。

| 模块          | 核心方向                                                     | 类型   |
| ------------- | ------------------------------------------------------------ | ------ |
| 主图          | 采用模块化布局，将画面划分为 7 个模块，帮助用户在短时间内捕捉关键信息，提升点击意愿与信息吸收效率 | 建议性 |
| 主图视频      | 兼顾技术规格与内容结构，根据商品价格分层设计脚本逻辑         | 建议性 |
| 长标题        | 采用「模块化+顺序化」原则，将产品信息拆解为模块，避免信息重复堆砌 | 建议性 |
| 短标题        | 采用模块化结构，聚焦品牌、产品类型和核心属性，便于用户快速识别 | 建议性 |
| 卖点          | 避免技术术语，使用用户语言，采用直观、体验导向的表达         | 建议性 |
| 参数楼层&属性 | 将用户关注的参数信息从商详最下方属性模块上提至参数楼层；属性基于实际参数填写，使用标准单位，避免模糊表述 | 建议性 |
| 品质标签      | 在商品详情页上传并展示世界窗膜协会认证等证书，传达权威背书信息 | 建议性 |
| 图文详情      | 权威认证首屏抓眼球、参数表格中屏强说服、服务保障尾屏降低购买顾虑 | 建议性 |

## 四、长标题规范

商品标题为二段式结构，即「商品品牌」+「自定义文本框」。第一段「商品品牌」不计入标题总字符数，第二段「自定义文本框」计入标题总字符数。

自定义文本框建议结构：

```
【品类词】+【特征属性】+【适用信息】+【核心卖点】+【服务保障】
```

- 搜索点击率：↑+1.57%
- 短标题结构化呈现，精简重要信息。
- 字符范围：16-30 个字符（一个汉字等于 2 个字符，数字、符号、英文字母 1 个字符）。

## 六、卖点规范

### 6.1 总则

避免技术化和工业化的用语，使用用户理解的语言。

### 6.2 表达转化方向

| 专业表述     | 用户关心的表达     |
| ------------ | ------------------ |
| 多层复合结构 | 隔热更强、耐用持久 |
| 反射式隔热层 | 隔热降温、冷感舒适 |

### 6.3 分品类卖点方向

| 品类       | 卖点方向                                                     |
| ---------- | ------------------------------------------------------------ |
| 汽车玻璃膜 | 隔热降温、隐私保护、防爆安全、防紫外线/防晒、高清高透视野、信号无干扰 |
| 汽车改色膜 | 色彩表现、漆面保护与施工服务、材质与耐用性                   |
| 隐形车衣   | 划痕自修复、耐黄变与持久保护、增亮提光泽、附加实用功能（防水自洁/抗腐蚀保护） |

## 七、参数楼层与属性规范

### 7.1 总则

- 商详转化率：↑+9.5%
- 将用户关注的参数信息从商详最下方的属性模块上提至参数楼层。
- 每个属性基于产品实际参数填写，使用标准单位，避免模糊表述，确保数据准确、一致。

### 7.2 分品类参数与属性

| 品类       | 参数/属性类别 | 内容要求                                                     |
| ---------- | ------------- | ------------------------------------------------------------ |
| 汽车玻璃膜 | 核心参数      | 前挡太阳能总阻隔率（X.X%）、前挡透光率（≥70% 整数）、侧后挡透光率（X% 整数）、紫外线阻隔率（X%/100%）、侧后挡太阳能总阻隔率（X.X%） |
| 汽车玻璃膜 | 基础信息      | 材质（陶瓷膜/金属膜等）、质保期（X 年/终身）、适用位置（全车/侧挡等）、核心卖点（高隔热等） |
| 汽车改色膜 | 属性信息      | 颜色（电光金属灰等细分色号）、材质（PVC/TPU 等单选）、类型（珠光/磨砂等单选）、安装（包/不包） |
| 隐形车衣   | 核心参数      | 质保期（X 年/终身）、膜厚（X.Xmil）、产地（国产/进口单选）   |
| 隐形车衣   | 工艺材料      | 材质（TPU 等）、裁剪（手裁/机裁单选）、母粒品牌（路博润等全称） |
| 隐形车衣   | 服务          | 安装（包/不包单选）                                          |

### 7.3 属性填写待提升说明

| 品类       | 待提升说明                                                   |
| ---------- | ------------------------------------------------------------ |
| 汽车玻璃膜 | 核心卖点不需要标注适用位置，聚焦玻璃膜核心性能即可，如高透光、强隔热等 |
| 汽车改色膜 | 材质为 PET 时，颜色信息无需重复填写                          |
| 隐形车衣   | 母粒品牌应填写实际品牌                                       |

## 八、品质标签规范

- 商详转化率：↑+7.82%
- 为提升消费者对平台汽车贴膜类商品的品质信任度，帮助优质商品脱颖而出。
- 世界窗膜协会认证是行业公认的品质认证，建议上传对应证书，在商详页透传权威背书，给用户「安全心智」。

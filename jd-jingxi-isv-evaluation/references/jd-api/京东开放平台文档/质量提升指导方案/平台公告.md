## 一、业务背景

为提升ISV工具中商品发布与编辑的体验及信息质量，现发布以下商品发品与编辑对接规范，需涉及商品管理、商品供应链、ERP等调用商品发布接口的ISV完成相应功能优化。

## 二、对接规范

> 
> 商品发布场景方案： [https://open.jd.com/v2/#/doc/scene?listId=1100468](https://open.jd.com/v2/#/doc/scene?listId=1100468)
> 
> 商品类目乱挂、属性不一致、恶意铺品规则解读： [https://open.jd.com/v2/#/doc/begin-guide?listId=1101486](https://open.jd.com/v2/#/doc/begin-guide?listId=1101486)

## 4、素材标准及优化

- 为帮助服务商更有效产出高适配素材、助力商家获取更多公域流量，提升商品在京东搜索、推荐等公域场景的曝光与转化效果，平台特整理 **京东各品类”好素材“标准，明确高流量、高转化素材的设计规范与优质案例。请服务商以该标准** **【** [**商品好素材标准-跳转链接**](https://mtt.jd.com/index/collection-detail?collectionId=39051) **】为依据，优先产出符合平台流量偏好的素材，共同提升商家经营效果与生态服务质量。确保输出内容更贴合京东场域流量分发逻辑，助力商家提升商品曝光与成交转化。**
- 请各位服务商参考文档仔细了解素材标准规范。 [【直播】商品素材全准好-好素材标准交流](https://joyspace.jd.com/pages/BYdO5JcpkEN2vz2CB6Jy)
	- 请各位服务商尽快接入透传规则至自己的工具当中，通过各资源位形式透传好素材标准给商家。 [【直播】好素材标准ISV 透传商家要求](https://joyspace.jd.com/pages/SE096EOJkQypyKNctEy0)

**除以上内容需优化外，同时建议服务商组织内部运营、客服团队进行培训，确保能正确引导商家。**

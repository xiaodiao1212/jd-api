该场景文档主要用于对接京东开放平台咚咚客服机器人API，内容包括人工辅助、纯机器人客服应答模式场景下对应的流程、规范、前置服务开通和API对接步骤等

**适用业务：** 自营&POP

**适用对象：** 软件服务商

## 一、基础概念

## 1.1 名词解释

| **名词/概念** | **解释说明** |
| --- | --- |
| 客服账号 | 指用于登录咚咚客服系统的服务人员账户。每个客服账号对应一个具体的客服人员，用于接收和处理客户发起的会话请求、查看消息、发送回复等操作。 |
| 客服绩效 | 指衡量客服工作表现的数据指标集合，常包括接待量、响应时长、满意度、解决率等。通过绩效数据可以评估客服服务质量和工作效率。 |
| 咚咚通知 | 指由系统推送的业务类通知信息，通常用于提醒客服或管理者特定事件的发生，例如“有新访客接入”“会话超时未响应”等。 |
| 咚咚消息 | 指客服与客户在会话中发送和接收的消息内容，包括文本、图片、视频、文件等形式。这些消息构成了会话的具体沟通内容。 |
| 咚咚会话 | 指客户与客服之间在一定时间窗口内的完整沟通交互过程。一个会话通常包含多个咚咚消息，并可能由不同会话类型触发（如人工、机器人等）。 |
| 会话类型 | 表示会话的来源或处理方式，枚举值有：在线会话、留言会话、机器人会话。 |
| 聊天记录 | 指系统保存的完整会话消息历史，包括客户与机器人/人工客服的所有消息内容。用于追踪沟通过程、售后查询、质检分析等。 |
| 技能组 | 表示客服团队中根据专业能力、业务领域或处理类型划分的分组，例如“售前咨询组”“技术支持组”“VIP客户组”等。技能组通常用于智能分配会话，提高服务效率。 |
| 查询机器人编码 | 指查询某个机器人实例在系统中的唯一标识（对应服务市场的服务code，），用于接口调用时识别具体的机器人配置。通常用于获取机器人状态、策略或知识库信息。 |

## 二、业务规则

## 2.1 客服机器人接待业务介绍

本小节重点阐述开通客服机器人的前提条件和开通流程

### 2.1.1 客服机器人开通条件与流程

1. 开通对接机器人的开发者身份：软件服务商
2. 应用类型：客服机器人
3. 服务类目：客服关系管理-客服机器人
4. 入驻流程：请参考软件类服务入驻指南： [https://open.jd.com/v2/#/doc/guide?listId=1594](https://open.jd.com/v2/#/doc/guide?listId=1594)
5. 机器人接口包申请：请应用上线后联系条线运营进行配置，注明appkey及所做业务

### 2.1.2 客服机器人接待模式和要求

**人工辅助模式**

符合京东服务市场的经营类目要求

**纯机器人模式**

接入人工辅助2个月（服务露出售卖2个月，订购商家数>20）且无客诉情况出现后，可接入纯机模式。接入纯机模式前，请主动联系条线运营先行沟通

### 3.2.4 发送咚咚消息

本步骤使用的API： [POST sp-support/v0/dongdong-messages](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100512&apiName=postDongdongMessage&gwType=1)

发送京东客服消息接口，用于向用户发送客服消息。

**注意事项**

1. aspId、accessToken、source，消息发送凭证，咚咚场景化消息接入平台申请

### 3.2.5 咚咚异步发送消息结果

本步骤使用的MQ： [dongdong_isv_chat_message_push_result](https://open.jd.com/v2/#/doc/msgApi?apiCateId=91&apiId=318)

### 3.2.6 实时获取京东客服与客户的聊天记录

### 3.2.7 查询客服评价详情列表

本步骤使用的API： [GET sp-support/v0/dongdong-waiter-evaluations](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100432&apiName=listDongdongWaiterEvaluations&gwType=1)

客服评价列表接口，用于获取用户对客服的评价信息。

**注意事项**

1. 不支持查询3月前的数据；
2. 一次查询的时间范围不能超过7天；

### 3.2.8 机器人维度评价相关指标统计

查询客服机器人评价记录列表接口

**注意事项**

1. 不支持查询1年以前的数据；
2. 一次查询的时间范围不能超过7天；
3. 机器人ID：robotCode，对应服务市场的服务code

该场景文档主要用于对接京东开放平台咚咚客服绩效相关API，内容包括查询商家客服列表、查询商家专属客服、查询指定客服&指定时间段的咨询记录、查询指定客服&机器人的绩效表现

**适用业务：** 自营&POP

**适用对象：** 软件服务商

## 一、基础概念

## 1.1 名词解释

| **名词/概念** | **解释说明** |
| --- | --- |
| 客服账号 | 指用于登录咚咚客服系统的服务人员账户。每个客服账号对应一个具体的客服人员，用于接收和处理客户发起的会话请求、查看消息、发送回复等操作。 |
| 客服绩效 | 指衡量客服工作表现的数据指标集合，常包括接待量、响应时长、满意度、解决率等。通过绩效数据可以评估客服服务质量和工作效率。 |
| 咚咚通知 | 指由系统推送的业务类通知信息，通常用于提醒客服或管理者特定事件的发生，例如“有新访客接入”“会话超时未响应”等。 |
| 咚咚消息 | 指客服与客户在会话中发送和接收的消息内容，包括文本、图片、语音、文件等形式。这些消息构成了会话的具体沟通内容。 |
| 咚咚会话 | 指客户与客服之间在一定时间窗口内的完整沟通交互过程。一个会话通常包含多个咚咚消息，并可能由不同会话类型触发（如人工、机器人等）。 |
| 会话类型 | 表示会话的来源或处理方式，枚举值有：在线会话、留言会话、机器人会话 |
| 聊天记录 | 指系统保存的完整会话消息历史，包括客户与机器人/人工客服的所有消息内容。用于追踪沟通过程、售后查询、质检分析等。 |
| 技能组 | 表示客服团队中根据专业能力、业务领域或处理类型划分的分组，例如“售前咨询组”“技术支持组”“VIP客户组”等。技能组通常用于智能分配会话，提高服务效率。 |

## 二、业务规则

## 2.1 客服绩效定义

客服绩效是指对客服人员在会话处理过程中的业务表现进行量化评估，用于衡量服务效率、服务质量和工作负荷。绩效数据是企业客服运营优化、人员激励和培训改进的重要依据。

## 2.2 客服绩效核心指标

- **接待量**：客服在一定时间内处理的客户会话数量。
- **首次响应时长**：客服首次回复客户的平均耗时。
- **平均响应时长**：每条客户消息的平均响应时间。
- **会话处理时长**：一个完整会话从接入到结束的总耗时。
- **客户满意度**：客户对客服服务的主观评价（常通过满意度打分收集）。
- **会话解决率**：客服处理会话后，客户问题被成功解决的比例。
- **转接率**：客服将会话转接给其他客服或技能组的比例。

## 3.2 操作步骤

### 3.2.1 查询商家客服列表

本步骤使用的API： [GET sp-support/v0/dongdong-waiters](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100472&apiName=listDongdongWaiters&gwType=1)

查询商家下，客服列表信息，包括客服总量，每个客服的level（是否是主账号）

**注意事项**

1. 支持pop商家和品牌客服；

### 3.2.2 查询用户咨询记录

本步骤使用的API： [GET sp-support/v0/sessions](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100422&apiName=listDongdongSessions&gwType=1)

用于查询顾客咨询的会话列表，不包含聊天记录，如需获取聊天记录，需配合listChatLogs接口使用

**注意事项**

1. 可查询在线会话、留言会话 和 机器人会话；

### 3.2.3 查询客服绩效列表

本步骤使用的API： [GET sp-support/v0/dongdong-waiter-performance](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100420&apiName=listDongdongWaiterPerformance&gwType=1)

查询客服绩效接口，用于获取客服人员的绩效数据

**注意事项**

1. 数据是（T+1）的；
2. 不支持查询3月前数据；
3. 一次查询的时间范围不能超过7天；

### 3.2.3 查询聊天机器人绩效

本步骤使用的API： [GET sp-support/v0/chatbots/{robotCode}/performance](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100461&apiName=getChatbotPerformance&gwType=1)

用于获取聊天机器人绩效数据

**注意事项**

1. 一次查询的时间范围不能超过1个月；
2. 机器人ID：robotCode，对应服务市场的服务code

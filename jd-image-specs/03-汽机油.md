## 主图首图要求

【京东建议，转述】品牌在左上，服务在品牌下，利益/赠品在左侧，真实油瓶在右侧，活动条在底部；瓶身品牌、粘度和规格应清楚。可采用契合使用场景的背景，但不遮盖商品标签。

【执行规范】只保留本 SKU 有依据的卖点；布局中的认证、服务、促销属于条件模块。不得为填满版式而编造信息。首图文案、辅助卖点、参数与证据先写入任务单，再生成画面。

## 主图组要求

【京东建议/原文示例】采用与机油商品对应的 8 张完整图例：首图、定位/包装、适配、安装服务、技术、验真、白底、授权。总述中“第 7–9 张胎侧细节”等属于明显跨品类残留，不纳入机油要求。

【执行编排】默认 8 张独立主图；M01 为首图，其余为附图。若条件模块缺证，按通用门控删除或替换，并记录原因。

| 图号 | 内容与画面要求 |
|---|---|
| M01 | 商品首图｜瓶身、系列/粘度/容量、核心利益；服务与活动有条件展示。 |
| M02 | 定位与包装｜适用需求、包装版本；新旧包装对比只在确实并行时展示。 |
| M03 | 车辆与标准｜实际适配范围、API/ACEA 等规格及有据可查的车厂要求。 |
| M04 | 服务流程｜实际到店保养/安装流程；不含服务的商品改为购买说明。 |
| M05 | 技术利益｜清洁、润滑等实际卖点与依据，不凭特效表达量化效果。 |
| M06 | 验真方式｜真实瓶身识别点和官方查询流程，不伪造二维码。 |
| M07 | 白底商品｜完整实物外观、规格可读，数量对应销售组合。 |
| M08 | 真实授权/保障｜排版有效授权资产；缺失则用完整参数替换。 |

## 详情页要求

【来源说明】原文 10 屏图例包括首屏、参数适配、品牌、需求解决、正背面、系列推荐、验真、品牌历史、粘度知识、规格服务。单 SKU 任务中相关系列推荐为可选信息，不自动混入其他商品。

【执行编排】默认 10 个独立详情屏。每屏写一个主标题，用该屏对应的实物、场景、参数表或真实证据解释，不重复堆叠首图文案。

| 屏号 | 需要回答的内容 |
|---|---|
| D01 | 商品与主要利益 |
| D02 | 参数、标准和适配范围 |
| D03 | 品牌/系列依据 |
| D04 | 实际使用需求与性能解释 |
| D05 | 包装正面与背面 |
| D06 | 本 SKU 选择说明；跨系列对比仅在另有资料时采用 |
| D07 | 真实验真方法 |
| D08 | 品牌背景：只用可核实资料，可省略 |
| D09 | 粘度标识与选型说明 |
| D10 | 规格、销售清单与实际服务 |

## 生成前需要的商品资料

系列/型号；机油类型；SAE 粘度；API/ACEA/ILSAC 等实际等级；车厂正式批准或符合要求的准确表述；容量与瓶数；产地；包装版本；适配车辆/发动机；服务范围。

此外提供：清晰多角度实物图、包装/标签原图、可用品牌资产、说明书/参数依据、证据与服务条款，以及本批尺寸、张数、风格和是否制作活动版。

## 品类限制与验收重点

【执行规范】“满足要求”和“获得车厂批准”不能混写。不得复制轮胎花纹、胎侧或原例固定换油里程；不能推定所有车辆通用。油液颜色、油瓶盖、背标不能臆造；使用真实包装资料。

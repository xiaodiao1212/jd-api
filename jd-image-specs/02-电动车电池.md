## 主图首图要求

【京东建议，转述】模块化 L 形布局，品牌与型号清楚，核心卖点、营销标签、商品、信任/服务、底部优惠分区；产品完整不裁切。原文强调 3 个核心卖点及 4–5 个辅助营销标签，营销贴片占比小于 50%。不规定统一拍摄角度。化学体系、规格与销售数量必须醒目。

【执行规范】只保留本 SKU 有依据的卖点；布局中的认证、服务、促销属于条件模块。不得为填满版式而编造信息。首图文案、辅助卖点、参数与证据先写入任务单，再生成画面。

## 主图组要求

【京东建议/原文示例】总述：第 2 张利益，第 3–4 张服务，第 5–10 张量化属性。详细示例：第 2 张参数/核心卖点，第 3–6 张选型、购买及质保，第 7–10 张售后与使用；铅酸、锂电分别举例。下方按详细示例分组拆成 10 张，具体组内分配为执行编排。

【执行编排】默认 10 张独立主图；M01 为首图，其余为附图。若条件模块缺证，按通用门控删除或替换，并记录原因。

| 图号 | 内容与画面要求 |
|---|---|
| M01 | 购买首图｜化学体系、型号、额定电压/容量、数量与核心利益。 |
| M02 | 参数总览｜真实参数表与关键优势，单块和整组参数分开。 |
| M03 | 选型适配｜型号识别、车辆适配与尺寸接口，不用“通用所有车型”。 |
| M04 | 购买/安装流程｜按商家实际下单和安装方式排版。 |
| M05 | 以旧换新条件｜仅活动存在时展示旧电池匹配、回收要求；否则改为规格说明。 |
| M06 | 质保服务｜期限、范围、服务主体和条件。 |
| M07 | 售后规则｜故障处理或咨询流程。 |
| M08 | 使用说明｜依据本型号厂家说明，不复制其他型号步骤。 |
| M09 | 维护与充电｜采用真实说明书；不同化学体系分别处理。 |
| M10 | 来源与保障｜真实溯源/授权资料；无证明时省略或换为已有资料的补充说明。 |

## 详情页要求

【来源说明】总述覆盖第 1–3 屏吸引兴趣/流程、第 4–9 屏品牌和服务信任；详细示例仅列第 1–7 屏，铅酸与锂电的展示内容不同。以下 9 屏是执行补全，不声称原文有九张逐屏示例。

【执行编排】默认 9 个独立详情屏。每屏写一个主标题，用该屏对应的实物、场景、参数表或真实证据解释，不重复堆叠首图文案。

| 屏号 | 需要回答的内容 |
|---|---|
| D01 | 商品身份、规格和主要利益 |
| D02 | 核心优势与购买判断 |
| D03 | 兼容性、购买和安装方式 |
| D04 | 电芯/材料及结构：仅有真实资料才展示 |
| D05 | 性能参数及适用条件 |
| D06 | 实际质量证明与来源 |
| D07 | 使用与维护方法 |
| D08 | 质保、售后及换新条件 |
| D09 | 完整参数、清单和使用注意事项 |

## 生成前需要的商品资料

铅酸/锂电及具体体系；单块/整组数量；额定电压与容量；尺寸/重量；接口与极性；适用车辆；配套充电器；安装方式；回收活动；质保条款。

此外提供：清晰多角度实物图、包装/标签原图、可用品牌资产、说明书/参数依据、证据与服务条款，以及本批尺寸、张数、风格和是否制作活动版。

## 品类限制与验收重点

【执行规范】不推定铅酸可直接改装锂电，不虚构电芯品牌、BMS、透明外壳、续航或快充。涉及激活、接线、充电的图文必须引用本型号说明。无私改线路、过载等错误使用画面；不将“绝对安全”“永不故障”作为卖点。

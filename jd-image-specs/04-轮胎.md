## 主图首图要求

【京东建议，转述】品牌左上，服务在其下，性能/赠品在左，轮胎在右，活动条在底部。可以展示装在轮辋上的轮胎，但不能让用户误以为轮辋随商品出售；花纹与胎侧必须忠实。原文未指定统一旋转角度。

【执行规范】只保留本 SKU 有依据的卖点；布局中的认证、服务、促销属于条件模块。不得为填满版式而编造信息。首图文案、辅助卖点、参数与证据先写入任务单，再生成画面。

## 主图组要求

【京东建议/原文示例】10 张：首图；第 2–3 张定位/路况；第 4 张技术；第 5–6 张安装/保障；第 7–9 张白底多角度及细节；第 10 张授权。

【执行编排】默认 10 张独立主图；M01 为首图，其余为附图。若条件模块缺证，按通用门控删除或替换，并记录原因。

| 图号 | 内容与画面要求 |
|---|---|
| M01 | 商品首图｜品牌/花纹系列、规格和核心利益。 |
| M02 | 产品定位｜实际适用需求和服务。 |
| M03 | 使用路况｜场景结合胎面细节，季节与路况适配有依据。 |
| M04 | 技术说明｜原例为 4 个技术点；仅展示本 SKU 真实技术，不凑数。 |
| M05 | 购买安装流程｜预约、到店等按商家政策。 |
| M06 | 保障政策｜真实质保/退换/安装条件。 |
| M07 | 白底整体｜清晰完整轮胎外观。 |
| M08 | 白底胎面｜准确花纹与结构细节。 |
| M09 | 白底胎侧｜型号、尺寸等真实标记可辨。 |
| M10 | 授权保障｜真实授权材料；无材料以参数和清单替换。 |

## 详情页要求

【来源说明】原文 11 屏示例包含品牌/保障、安全技术、配方、排水、结构、新胎/磨损胎湿地制动、里程、舒适以及选购说明。示例依赖特定品牌技术和测试，不能要求所有轮胎逐项拥有同样性能。

【执行编排】默认 11 个独立详情屏。每屏写一个主标题，用该屏对应的实物、场景、参数表或真实证据解释，不重复堆叠首图文案。

| 屏号 | 需要回答的内容 |
|---|---|
| D01 | 商品定位与实际品牌依据 |
| D02 | 保障及存储相关说明 |
| D03 | 实际安全技术概览 |
| D04 | 配方或材料特点 |
| D05 | 排水/抓地等实际性能 |
| D06 | 结构或设计技术 |
| D07 | 真实测试表现及条件；无测试则展示已确认功能 |
| D08 | 不同使用状态的表现：仅有对应依据时采用 |
| D09 | 耐用性与使用建议，不编造里程 |
| D10 | 舒适、噪声或多角度细节 |
| D11 | 规格含义、适配与购买安装须知 |

## 生成前需要的商品资料

品牌/花纹系列；宽度/扁平比/轮辋直径；载重指数/速度级别；胎型、季节；防爆/自修补/静音棉等真实配置；数量；适配依据；安装及质保。

此外提供：清晰多角度实物图、包装/标签原图、可用品牌资产、说明书/参数依据、证据与服务条款，以及本批尺寸、张数、风格和是否制作活动版。

## 品类限制与验收重点

【执行规范】不得凭型号名推断防爆或静音棉。测试制动距离、噪声、里程必须有本型号/规格及条件，不复制原例“无限时间”等保障。结构、花纹和胎侧文字是商品身份，不允许美化改造。轮辋、汽车均是道具，除非销售清单明确包含。

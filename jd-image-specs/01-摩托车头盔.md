## 主图首图要求

【京东建议，转述】品牌在左上，认证在右上，核心卖点在左侧，商品或佩戴主体在右侧，价格/服务在底部；产品及佩戴展示统一左前 45°。原文总述为 4–5 个营销标签，细则为 3–5 个核心卖点；本批默认选 4 个不重复且有资料的卖点，避免把标签数当作必须堆满的任务。

【执行规范】只保留本 SKU 有依据的卖点；布局中的认证、服务、促销属于条件模块。不得为填满版式而编造信息。首图文案、辅助卖点、参数与证据先写入任务单，再生成画面。

## 主图组要求

【京东建议/原文示例】完整示例共 8 张，按外观与购买信息→佩戴→安全结构→镜片→内衬→通风→部件→骑行场景展开。

【执行编排】默认 8 张独立主图；M01 为首图，其余为附图。若条件模块缺证，按通用门控删除或替换，并记录原因。

| 图号 | 内容与画面要求 |
|---|---|
| M01 | 外观首图｜左前 45°；品牌/系列、核心卖点、真实认证；有效活动信息可选。 |
| M02 | 佩戴展示｜真实头盔比例与佩戴姿态；说明尺码或核心利益，不更换花色。 |
| M03 | 安全结构｜据资料展示外壳、缓冲层与内衬；标注实际材质。 |
| M04 | 镜片功能｜展示实际镜片结构、视野或日夜使用；单镜片不能画成双镜片。 |
| M05 | 内衬与舒适｜材料、拆洗方式、贴合细节；可拆洗仅在确有该功能时出现。 |
| M06 | 通风与风噪｜用真实风道位置解释气流；降噪数值需要测试依据。 |
| M07 | 结构细节｜展示扣具、镜片连接、通风口等真实部件；爆炸图需结构资料。 |
| M08 | 骑行场景｜与头盔定位相符的骑行环境、正确系扣，延续本 SKU 外观。 |

## 详情页要求

【来源说明】原文建议 10 屏：前段建立认知，中段建立信任并解释利益，后段补足功能与选择信息。示例包含规格/头围测量、内部构造、镜片、通风、气动、内衬和操作细节。

【执行编排】默认 10 个独立详情屏。每屏写一个主标题，用该屏对应的实物、场景、参数表或真实证据解释，不重复堆叠首图文案。

| 屏号 | 需要回答的内容 |
|---|---|
| D01 | 商品外观与主要价值 |
| D02 | 设计特点总览 |
| D03 | 规格尺码、头围测量与选择 |
| D04 | 内部构造与工艺 |
| D05 | 防护层次及舒适支撑 |
| D06 | 镜片结构与适用光线条件 |
| D07 | 通风通道与开关位置 |
| D08 | 气动设计与外观细节 |
| D09 | 内衬清洁及实际配置 |
| D10 | 操作细节与必要使用提示 |

## 生成前需要的商品资料

头盔类型；品牌/系列/型号/花色；尺码与头围范围；外壳、缓冲层、内衬材质；重量及测量口径；镜片数量/类型；扣具；可拆洗部件；认证及适用型号。

此外提供：清晰多角度实物图、包装/标签原图、可用品牌资产、说明书/参数依据、证据与服务条款，以及本批尺寸、张数、风格和是否制作活动版。

## 品类限制与验收重点

【执行规范】全盔、3/4 盔、半盔按真实类型选场景。赛道/碳纤维/复古/入门等定位不能自动带出某种材料或性能。3C、DOT、ECE 等只展示本 SKU 有效材料；不复制原例认证组合、KPA 技术、蓝牙配置或层数。

# 单 SKU 电商主图与详情页：通用执行规范

版本：v1.0｜识读日期：2026-09-09｜适用：用户提供的京东汽车用品类目文章。

## 1. 使用范围与证据等级

这套文件用于将京东图文运营建议转成单 SKU、单批次生图要求，覆盖静态主图和详情页。文中的 SKU 指一个确定的型号、规格、颜色与销售组合。

- **【京东建议】**：来自原文规范、文字说明或明确标注的示例结构。页面标注“官方建议”，不能等同于所有商家必须遵守的审核硬性规则。
- **【原文示例】**：某品牌商品的展示方法。品牌、证书、价格、期限、销量、性能数值及技术名称不能迁移给别的商品。
- **【执行规范】**：本次为生图任务制定的操作要求，包括单 SKU 一致性、事实门控、分镜拆分、文字制作和验收；不是京东新增政策。
- **【待补资料】**：缺少真实商品材料时不能生成的内容。不得用“行业常见值”填空。

各品类的“批次图序”均是执行编排：部分沿用原例顺序，部分在原文分组中具体拆分。推荐张数不是平台强制上传数量；删减、合并或换序时仍需覆盖本 SKU 的关键购买信息。

## 2. 主图首图的共用要求

【京东建议】产品清晰、无模糊失真；字体大小、粗细、颜色形成明确层级；配色协调品牌；突出核心商品与用户利益，减少信息拥挤。各类首图的产品位置、卖点数量、证书位置等以对应品类文件为准。

【执行规范】每张图先确定一个主要购买问题，再确定唯一主标题；标题、产品主体、证据或辅助说明分层排布。品牌与型号必须可辨，核心产品不能被营销贴片遮挡。不把详情页整屏缩成主图。

【执行规范】常规版与活动版分开。只有确认活动价格、有效期、适用规格、优惠条件后，才制作价格条、补贴、赠品及服务文案。无活动时将该区域用于规格或简洁留白，不虚构到手价。原例中的平台标、补贴标、排名及官方身份不自动取得使用资格。

## 3. 单 SKU 身份与事实门控

| 项目 | 执行要求 |
|---|---|
| 商品身份 | 锁定品牌、系列、型号、颜色、规格、版本、包装、数量；整批不得漂移。 |
| 外形结构 | 外壳、瓶型、花纹、接口、扣具、镜片、标识位置等以真实参考图为准；缺少侧面或背面时不能臆造细节。 |
| 组合关系 | 单件、套装、配件、赠品及场景道具明确区分；多个展示角度不表示包含多件。 |
| 性能数据 | 每个数值绑定本 SKU 的资料与测试条件。单位、比较对象、适用范围、日期保持一致。 |
| 证明材料 | Logo、证书、报告、授权书、二维码、标签用用户提供的真实资产；不得要求模型生成证明文件。 |
| 功能示意 | 有结构资料才画剖面/爆炸图；示意图标明“结构示意”或“效果示意”，不得冒充实拍或检测结果。 |
| 比较图 | 对比对象、角度、光线、剂量或测试条件需一致并有依据。AI 效果演绎不能作为真实试验前后照片。 |
| 服务承诺 | 安装、质保、退换、门店、运费、施工范围等必须对应商家实际政策，不沿用原例。 |
| 缺失处理 | 身份/外观/关键适配资料缺失，暂停依赖该资料的图片；非必要营销证据缺失，删去相应模块。对独立且资料齐全的图片可继续编排。 |

## 4. 详情页的共用执行方式

每屏解决一个问题，保持品牌色、字体、光线、产品比例和图标风格统一。先给商品价值与购买判断，再解释功能依据、参数适配、服务和使用条件；具体排序按品类。

详情屏可以采用产品大图、场景图、结构示意、参数表、操作流程、真实证据排版等不同形式。证书、说明书、参数表不适合交给模型自由绘制：生成可用底图，再用确定文本和真实资产排版。

仅有画面不能证明气味消除、灭菌、隔热率、耐磨里程、碰撞保护等效果；需要真实说明或测试依据。不能以光效、盾牌、火焰、冰霜等视觉符号替代性能证据。

## 5. 尺寸、张数与文字

本次识读材料没有提供一套可通用于十品类的静态图像像素、格式、文件大小及详情屏高限制，因此本文件不将 800×800、1:1 或某个字号写成京东强制要求。上传前按实际商家后台对应入口核对。

【执行规范】批次开始时填写主图宽高、详情宽度/分屏高度、格式和张数。若只做方案草稿，可暂按方形主图、竖向详情分屏设计，并明确标记“待按上传入口确认尺寸”；不能宣称已可直接上线。

源文中的商品长标题、短标题、搜索卖点字段以及“品质标签”“主推标签”属于商品信息或后台配置，和图内标题不是同一字段。不要把其字符规则、后台标签直接当成图内文案规则。

## 6. 生成与交付

1. 锁定 SKU 资料、真实参考图和可用证据，填写批次模板。
2. 输出逐图清单：图号、目的、构图、唯一文案、参数、证据、禁止内容；先消除事实空缺。
3. 按清单逐张生成独立图片。不得将整批主图拼为九宫格或联系表充当交付；单张内部的信息分区不受此限制。
4. 小字、数字、品牌标识、证书及复杂参数表优先在后期精确排版；图内文字应与确认稿逐字核对。
5. 交付独立图、对应文案/事实清单、版本及验收记录。建议命名：`SKU_ID_M01_v01`、`SKU_ID_D01_v01`；该命名是执行建议。

## 7. 验收清单

- [ ] 主图与详情页均覆盖；数量、顺序、尺寸符合本批任务单。
- [ ] 整批是同一型号、规格、颜色、销售数量与包装版本。
- [ ] 首图布局、品类核心字段、视角和卖点数量符合品类文件。
- [ ] 无错误结构、变形标签、假认证、乱码、未经确认的价格和承诺。
- [ ] 所有数字、适配范围、测试结论、证书和服务有资料对应。
- [ ] 场景使用方式符合真实产品说明；道具和附赠关系不会误导。
- [ ] 小屏浏览文字清楚，主次明确，产品没有被遮挡。
- [ ] 真实证据与 AI 示意区分明确；证据缺失项没有伪装成已经核验。
- [ ] 品类文档中“不得套用”的示例内容已逐项检查。
- [ ] 上线前已核对当前上传入口技术要求；本文件不是审核通过保证。

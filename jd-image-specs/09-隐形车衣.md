## 主图首图要求

【京东建议，转述】采用七模块：左上品牌，品牌下产品词与主卖点，其下 4–5 个勾选式辅助利益，主体为贴膜后的汽车且占较大面积；右侧纵向信任/服务标签，右下活动贴片，底部价格。主要展示施工后的外观效果；车型是展示载体，不属于销售商品。

【执行规范】只保留本 SKU 有依据的卖点；布局中的认证、服务、促销属于条件模块。不得为填满版式而编造信息。首图文案、辅助卖点、参数与证据先写入任务单，再生成画面。

## 主图组要求

【京东建议/原文示例】共用 10 张方向：第 1 张首图，第 2 张参数对比，第 3–4 张施工/质保/售后覆盖，第 5–10 张核心卖点和量化属性。具体逐张图例主要为玻璃膜；车衣/改色膜下方逐图分配为依原文分类重点编排的执行建议。

【执行编排】默认 10 张独立主图；M01 为首图，其余为附图。若条件模块缺证，按通用门控删除或替换，并记录原因。

| 图号 | 内容与画面要求 |
|---|---|
| M01 | 首图｜保持原车颜色，展示真实光泽/哑光效果；标明隐形车衣、系列及核心利益。 |
| M02 | 参数｜材质、膜厚及口径、产地、质保、施工范围。 |
| M03 | 施工服务｜裁切及施工流程，按商家实际方法。 |
| M04 | 保障范围｜安装与质保条款，不默认免费全国施工。 |
| M05 | 漆面保护｜有依据的防护示意，不能画成抵挡碰撞的铠甲。 |
| M06 | 划痕修复｜仅确有功能时说明可修复类型和触发条件。 |
| M07 | 外观光泽｜按实际透明/哑光效果展现，原车颜色一致。 |
| M08 | 疏水抗污｜依据真实功能素材，不凭水珠直接宣称自洁。 |
| M09 | 耐久性能｜耐黄变等数据需测试依据。 |
| M10 | 材质或收边细节｜采用真实施工/材料参考，不能捏造层结构。 |

## 详情页要求

【来源说明】共用 10 屏方向：第 1 屏真实权威依据与核心价值，第 2–4 屏品牌、下单/安装及服务网络，第 5–9 屏参数与分类核心利益，第 10 屏使用/质保。图例为玻璃膜；其他两类按原文明示的利益方向执行转译。

【执行编排】默认 10 个独立详情屏。每屏写一个主标题，用该屏对应的实物、场景、参数表或真实证据解释，不重复堆叠首图文案。

| 屏号 | 需要回答的内容 |
|---|---|
| D01 | 商品定位、漆面效果与实际依据 |
| D02 | 品牌/材料来源 |
| D03 | 施工流程及覆盖部位 |
| D04 | 服务网络与质保条件 |
| D05 | 材质、厚度、产地、裁切和清单 |
| D06 | 真实漆面保护功能 |
| D07 | 划痕修复条件：无此功能则替换 |
| D08 | 光泽、疏水或易清洁等已确认利益 |
| D09 | 实际耐久或质量证明 |
| D10 | 养护、清洁及质保限制 |

## 生成前需要的商品资料

材质；膜厚及是否含胶/涂层的测量口径；产地；母粒品牌（有资料才写）；光泽类型；裁切方式；施工覆盖；是否含安装；质保及修复条件。

此外提供：清晰多角度实物图、包装/标签原图、可用品牌资产、说明书/参数依据、证据与服务条款，以及本批尺寸、张数、风格和是否制作活动版。

## 品类限制与验收重点

【执行规范】不套用玻璃膜的透光、隔热、隐私指标；不得自动默认 TPU、进口、特定母粒、任意划痕自修复或永不黄变。透明车衣不应改变车色；厚度单位 mil 不得误写成 mm。局部套装不能画作全车均包含。

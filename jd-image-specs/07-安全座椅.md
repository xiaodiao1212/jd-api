## 主图首图要求

【京东建议，转述】柔和、低饱和、协调的配色，可用纯色背景或车内场景。品牌左上，产品主体在右；左侧明确适用年龄及 2–4 个核心功能卖点，优惠/赠品和价格位于左下；真实认证可在右侧纵向排布。边缘留安全空间，原文未给具体像素。

【执行规范】只保留本 SKU 有依据的卖点；布局中的认证、服务、促销属于条件模块。不得为填满版式而编造信息。首图文案、辅助卖点、参数与证据先写入任务单，再生成画面。

## 主图组要求

【京东建议/原文示例】10 张：首图；第 2–3 张服务优惠；第 4–5 张认证/报告；第 6–9 张功能细节；第 10 张白底。

【执行编排】默认 10 张独立主图；M01 为首图，其余为附图。若条件模块缺证，按通用门控删除或替换，并记录原因。

| 图号 | 内容与画面要求 |
|---|---|
| M01 | 首图｜适用年龄、主要利益及本 SKU 外观；年龄需与身高/体重限制相符。 |
| M02 | 服务权益｜实际安装支持、售后等。 |
| M03 | 活动或购买条件｜活动不存在时改为适配说明。 |
| M04 | 资质说明｜真实且对应本型号的认证材料。 |
| M05 | 真实测试依据｜测试机构/项目/结论准确；无材料不伪造评分。 |
| M06 | 安全结构｜实际防护设计与约束方式。 |
| M07 | 舒适细节｜真实面料、支撑和透气结构。 |
| M08 | 调节功能｜实际档位、角度、旋转或折叠功能。 |
| M09 | 安装操作｜接口、支撑腿、扣具等按本型号说明展示。 |
| M10 | 白底商品｜结构、配色、衬垫、扣具完整准确。 |

## 详情页要求

【来源说明】原文明确首屏不只放纯白底商品，应结合场景/核心卖点；采用明亮温馨、统一视觉。8 屏示例为价值、适配、认证、测试、材料、防护、差异化、操作。

【执行编排】默认 8 个独立详情屏。每屏写一个主标题，用该屏对应的实物、场景、参数表或真实证据解释，不重复堆叠首图文案。

| 屏号 | 需要回答的内容 |
|---|---|
| D01 | 商品价值与主要功能，结合场景或利益说明 |
| D02 | 尺寸及年龄/身高/体重适配 |
| D03 | 实际认证与适用范围 |
| D04 | 本型号真实测试及说明 |
| D05 | 骨架、缓冲及面料信息 |
| D06 | 实际防护结构 |
| D07 | 舒适或调节等差异化功能 |
| D08 | 安装、转向、扣具操作与使用须知 |

## 生成前需要的商品资料

型号/颜色；适用年龄、身高和体重；朝向及各模式限制；认证/测试材料；约束方式；ISOFIX/安全带等安装方式；支撑腿/上拉带；调节范围；尺寸；实际服务。

此外提供：清晰多角度实物图、包装/标签原图、可用品牌资产、说明书/参数依据、证据与服务条款，以及本批尺寸、张数、风格和是否制作活动版。

## 品类限制与验收重点

【执行规范】不自动加入 360° 旋转、全年龄、ISOFIX 或任意认证。区分认证、测试和评分的准确名称。儿童坐姿、肩带路径、扣具和安装方式按说明书，不展示行车时侧向乘坐。适用年龄不能代替身高、体重和模式限制。

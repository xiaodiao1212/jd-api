该场景文档主要用于对接京东开放平台咚咚客服质检相关API，内容包括查询会话列表、特定时间段的会话列表和聊天记录、指定商家&指定时间段&指定客户的聊天记录，用户留言记录等

**适用业务：** 自营&POP

**适用对象：** 软件服务商

## 一、基础概念

## 1.1 名词解释

| **名词/概念** | **解释说明** |
| --- | --- |
| 客服账号 | 指用于登录咚咚客服系统的服务人员账户。每个客服账号对应一个具体的客服人员，用于接收和处理客户发起的会话请求、查看消息、发送回复等操作。 |
| 客服绩效 | 指衡量客服工作表现的数据指标集合，常包括接待量、响应时长、满意度、解决率等。通过绩效数据可以评估客服服务质量和工作效率。 |
| 咚咚通知 | 指由系统推送的业务类通知信息，通常用于提醒客服或管理者特定事件的发生，例如“有新访客接入”“会话超时未响应”等。 |
| 咚咚消息 | 指客服与客户在会话中发送和接收的消息内容，包括文本、图片、语音、文件等形式。这些消息构成了会话的具体沟通内容。 |
| 咚咚会话 | 指客户与客服之间在一定时间窗口内的完整沟通交互过程。一个会话通常包含多个咚咚消息，并可能由不同会话类型触发（如人工、机器人等）。 |
| 会话类型 | 表示会话的来源或处理方式，枚举值有：在线会话、留言会话、机器人会话 |
| 聊天记录 | 指系统保存的完整会话消息历史，包括客户与机器人/人工客服的所有消息内容。用于追踪沟通过程、售后查询、质检分析等。 |
| 技能组 | 表示客服团队中根据专业能力、业务领域或处理类型划分的分组，例如“售前咨询组”“技术支持组”“VIP客户组”等。技能组通常用于智能分配会话，提高服务效率。 |
| 查询机器人编码 | 指查询某个机器人实例在系统中的唯一标识（对应服务市场的服务code，），用于接口调用时识别具体的机器人配置。通常用于获取机器人状态、策略或知识库信息。 |

## 二、业务规则

## 2.1 客服质检定义

客服质检是指对客服与客户之间的沟通内容进行系统化、规则化的审查和评估，以确保沟通合规、服务标准一致并持续优化客户体验。

## 2.2 客服质检规范

质检通常由系统质检（自动规则）+ 人工质检（抽样评审）组成，核心要素包括：

- **质检项**：如“是否自报工号”、“是否礼貌用语”、“是否回复完整”、“是否引导客户”等。
- **质检维度**：服务规范、表达技巧、解决能力、情绪管理等。
- **质检结果**：是否通过、评分等级、问题标签、扣分项等。
- **质检意见**：质检员对客服表现的评语和建议。

## 3.2 操作步骤

### 3.2.1 查询会话列表

本步骤使用的API： [GET sp-support/v0/sessions](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100422&apiName=listDongdongSessions&gwType=1)

用于查询顾客咨询的会话列表，不包含聊天记录，如需获取聊天记录，需配合listChatLogs接口使用

**注意事项**

1. 可查询在线会话、留言会话 和 机器人会话；

### 3.2.2 查询特定会话聊天记录

查询会话下的聊天记录，包含客服与顾客的对话信息，会话ID需要从listDongdongSessions获取

**注意事项**

1. 会话ID不能为空；

### 3.2.3 查询指定时间段聊天详情

本步骤使用的API： [GET sp-support/v0/dongdong-chat-details](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100412&apiName=listDongdongChatDetails&gwType=1)

用于获取咚咚会话详情，包含会话列表和聊天记录，少量数据场景下可通过该接口快速获取聊天信息

**注意事项**

1. 不支持查询3月前的数据；
2. 一次查询的时间范围不能超过7天；
3. 会话类型包含在线会话、留言会话、机器人会话；

### 3.2.4 查询用户留言记录

查询会话下的聊天记录，包含客服与顾客的对话信息，会话ID需要从listDongdongSessions获取

**注意事项**

1. 会话ID不能为空；

### 3.2.5 查询客服评价列表

本步骤使用的API： [GET sp-support/v0/dongdong-waiter-evaluations](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100432&apiName=listDongdongWaiterEvaluations&gwType=1)

客服评价列表接口，用于获取用户对客服的评价信息。

**注意事项**

1. 不支持查询3月前的数据；
2. 一次查询的时间范围不能超过7天；

### 3.2.6 查询机器人评价列表

本步骤使用的API： [GET sp-support/v0/chatbots/{robotCode}/evaluations](https://open.jd.com/v2/#/doc/api?apiCateId=100106&apiId=100426&apiName=listChatbotEvaluations&gwType=1)

查询客服机器人评价记录列表接口

**注意事项**

1. 不支持查询1年以前的数据；
2. 一次查询的时间范围不能超过7天；
3. 机器人ID：robotCode，对应服务市场的服务code

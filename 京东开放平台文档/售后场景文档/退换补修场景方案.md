退换补修，属于售后退款，是指用户在订单收到货以后，因商品质量问题、错发漏发、不想要了等原因，申请售后服务单，一般包含退货、换货、补发、维修、安装等多种售后类型。此场景的API解决方案，就是京东支持商家快速获取服务单，支持多种审核、收货、处理的能力。

**适用业务：** 第三方（POP）卖家模式、厂直供应商模式。

**适用对象：** 自研商家、软件服务商。

## 一、基础概念

| **名词** | **解释** |
| --- | --- |
| 退货 | 根据customerApplyInfo客户申请信息中， **customerExpect客户期望** **，一般为** **10: 退货** |
| 换货 | 根据customerApplyInfo客户申请信息中， **customerExpect客户期望** **，一般为** **20: 换货** |
| 补发商品 | 根据customerApplyInfo客户申请信息中， **customerExpect客户期望** **，一般为** **80: 补发新品** |
| 维修 | 根据customerApplyInfo客户申请信息中， **customerExpect客户期望** **，一般为30：维修，70:上门维修** |
| 已收货仅退款 | 根据customerApplyInfo客户申请信息中， **customerExpect客户期望** **，一般为11：已收货仅退款** |
| 协商 | 商家和消费者在售后审核过程中产生了分歧。为了给消费者更好的体验， **在审核拒绝的基础上，商家可以通过协商的方式进行服务单审核，协商场景可以分为协商拒绝、协商修改。** 审核后则通过im对话通知到消费者，消费者可选择同意或不同意。分场景来说：  **1、协商拒绝：** 商家和消费者协商关闭此服务单申请。消费者同意关闭，服务单取消；消费者不同意，可以申请京东介入，服务单完成，并且服务单标识会增加【京东介入】；  **2、协商修改：** 商家和消费者协商修改售后类型等。消费者同意，则服务单信息变更；消费者拒绝，则服务单会从「协商中」，回退到「待审核」状态； |
| 交易纠纷 | 在消费者无法与商家协商处理一致时，可申请交易纠纷，产生交易纠纷单，由京东介入进行处理，商家可进行举证由客服进行判责。 **此单据暂未开放。在商家审核为协商拒绝后，消费者不同意并发起京东介入时，服务单标识afsServiceFlagInfo会携带有京东介入jdDispute标识**，商家可通过京麦端-售后-交易纠纷，进行申诉、举证等动作。 |
| 闪电退款 | “闪电退款”是为了提高消费者的购物体验，可有效缩短消费者退货过程中等待退款到账时长的服务产品。客户在线提交退货申请，符合条件的退货申请在，商家审核通过后，商品返回京东前（部分订单需在取/收件成功后）即进入退款流程。如果已经触发闪电退款并且给客户完成退款后，可通过服务单标识 **afsServiceFlagInfo会携带有已闪退alreadySmartRefund**，如果商家收到货发现有问题，可以在京麦系统发起催收流程。 |
| 服务单标识 | **afsServiceFlagInfo**，通常用来识别服务单的各种场景，如命中7天无理由sevenDaysNoReason、京东介入jdDispute（后续开放）、已闪退alreadySmartRefund（后续开放）等。 |

## 2.3 闪电退款

### 2.3.1 闪电退款如何开通？

1、商家在同意开设店铺时，系统将自动为其开通闪电退款服务。

2、商品必须同时满足以下要求，方可支持“闪电退款”服务：

- 商品非虚拟、定制、服务产品等特殊商品；
- 商品已开通“7天无理由退货”服务；
- 售后申请时实付金额在3000元以内；
- 消费者无用户信誉风险；
- 消费者选择的寄回方式为“上门取件”，且京东物流已完成上门取件或消费者已填写真实物流单号（若使用京东上门取件服务会自动上传运单号，若自寄需消费者上传物流单号并经过校验。）

满足以上的条件的，商家受理消费者退货申请时可自动执行闪电退款。

注：针对部分特殊情况，闪电退款服务执行标准会根据实际调整，具体以实际系统执行为准。具体规则如下： [https://rule.jd.com/rule/ruleDetail.action?ruleId=616214789504503808&type=0&btype=1](https://rule.jd.com/rule/ruleDetail.action?ruleId=616214789504503808&type=0&btype=1)

### 2.3.3 业务规则补充

1. 闪电退款之后，服务单状态是【待收货】，退款状态是【退款完成】；
2. 闪电退款完成后，会先从商家钱包扣除，并且退款完成给消费者，商家后发起退款；

### 2.3.4 总结闪电退款的对接说明

1、服务单如果发生了闪电退款，会在服务单标识 **afsServiceFlagInfo会携带有已闪退alreadySmartRefund；**

2、对外开放只提供查询催收状态能力，发起催收、确认闪退等操作，仍在京麦端处理；

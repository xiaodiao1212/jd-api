鞋靴商品信息运营规范

## 一、整体规范综述

商品信息优化应紧密围绕用户选购决策路径，通过系统化提升**主图、视频、开箱测评/主图画廊、图文详情、标题、卖点、属性、尺码助手、安心品质、主推标签、规格图和系列品**十二个模块的信息质量，实现流量转化效率的最大化。

### 1.1 十二模块要点

| 模块                  | 核心要求                                                     | 类型   |
| --------------------- | ------------------------------------------------------------ | ------ |
| **主图规范**          | 信息逻辑精简聚焦，营销区域面积占比建议在 35% 以内；主图集建议包括整体呈现、材质与卖点、多角度细节、颜色及尺码建议四部分 | 建议性 |
| **主图视频**          | 建议时长不低于 15 秒；结构建议含快速识别产品、卖点集中展示、穿搭场景展示、强化信任引导购买；垂类含**产品展示类**与**卖点讲解类** | 建议性 |
| **开箱测评/主图画廊** | 作为主图静态图的补充，提供高颜值优质内容，增强决策信心       | 建议性 |
| **图文详情**          | 首屏抓注意力（海报与基础信息）；2–4 屏诠释尺码适配、品质认证与多角度细节；5–8 屏写材质工艺、穿着体验、场景实拍与服务保障 | 建议性 |
| **标题**              | 短标结构：【品牌】+【产品词】+【适用场景】/【功能卖点】/【材质特征】/【风格款式】长标结构：【品牌】+【性别】+【产品词】+【上市时间】+【适用人群】+【适用场景】+【功能/特色卖点】+【鞋面材质】+【鞋底材质】+【适用季节】+【颜色】+【尺码】 | 建议性 |
| **卖点**              | 将参数转化为可感知语言，突出鞋类材质优势、功能特色与技术理念，凸显品质感、舒适感与性价比 | 建议性 |
| **属性**              | 须真实、可验证，与标题、卖点逻辑一致；禁止矛盾、夸大或虚假描述 | 要求性 |
| **尺码助手**          | 精准推荐适配尺码，降低尺码原因退换，提高商详转化             | 建议性 |
| **安心品质**          | 上传检测报告（如耐磨、抗菌等），在详情页透传权威背书，占据「耐穿、舒适、安全」心智 | 建议性 |
| **主推标签**          | 配置主推标识，浏览下单时可见，提升爆品转化                   | 建议性 |
| **规格图**            | 展示商品细节，提升加购、降低退换                             | 建议性 |
| **系列品**            | 推荐高关联商品，促进跨品类连带销售                           | 建议性 |

## 二、主图规范

### 2.1 主图基础要求

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **视觉风格** | 贴片颜色须与背景色调贴合，柔和低饱和，避免高饱和强对比色块破坏质感，画面干净舒适 | 建议性 |
| **信息逻辑** | 精简聚焦，优先传递材质优势（如牛皮革、环保鞋底）、穿着舒适度（如透气、缓震）与用户价值，减少冗余促销话术 | 建议性 |
| **布局结构** | 营销区域面积占比建议在 **35% 以内**（画布均分 20 份，其中 7 份约 35%） | 建议性 |

### 2.2 主图集结构（帧序建议）

| 帧段            | 内容建议                                                 | 类型   |
| --------------- | -------------------------------------------------------- | ------ |
| **首图**        | 整体呈现：白底/场景/模特图展示鞋型；功能鞋可加强卖点标签 | 建议性 |
| **第 2～4 帧**  | 卖点与特写：材质触感与鞋底功能（防滑、缓震、耐磨等）     | 建议性 |
| **第 5～7 帧**  | 产品轮廓与多角度细节（正/侧/背/顶，车线、压印、内垫等）  | 建议性 |
| **第 8～10 帧** | 同款多色合集；尺码/脚型建议；功能鞋可补质检信息          | 建议性 |

### 2.3 营销信息布局示意（可读文案）

| 示意项                             | 说明               | 类型   |
| ---------------------------------- | ------------------ | ------ |
| 营销信息占比在 35% 以内 / 超过 35% | 单方图或单长图对比 | 建议性 |
| 营销信息集中在三处以内/分散在五处  | 布局分布示例       | 建议性 |

### 2.4 第 1～10 张主图分条要求

| 序号       | 类型         | 内容要求                                                     | 类型   |
| ---------- | ------------ | ------------------------------------------------------------ | ------ |
| 第 1 张    | 首图呈现     | 鞋子主体清晰、整体和谐；可选纯白底/场景/模特图；卖点文字不可满屏 | 建议性 |
| 第 2 张    | 核心卖点     | 集中讲卖点，特写形式统一、有视觉美感                         | 建议性 |
| 第 3 张    | 材质/触感    | 鞋面、内里、鞋垫；皮料/网布/绒面/织物等；可用模特上脚近景    | 建议性 |
| 第 4 张    | 鞋底功能     | 防滑、缓震、耐磨、软底、抓地等；宜鞋底近拍或与地面接触特写   | 建议性 |
| 第 5 张    | 产品轮廓     | 鞋头、鞋楦、整体廓形；尽量单图完整呈现，避免复杂拼图         | 建议性 |
| 第 6～7 张 | 多角度及细节 | 正/侧/背/顶；车线、品牌压印、内垫、鞋口、提拉等              | 建议性 |
| 第 8～9 张 | 尺码/脚型    | 脚长、脚宽、脚背高、偏码提醒；可有执行标准、质检、材质检测（下半区） | 建议性 |
| 第 10 张   | 同款多色合集 | 颜色、版本、搭配差异；可兼顾 SKU 引导                        | 建议性 |

## 三、主图视频

### 3.1 时长与分段（示例以约 20 秒计）

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **时长**     | 鞋靴类用户观看平均约 15 秒+；建议**不低于 15 秒**            | 建议性 |
| **0–3 秒**   | 快速识别：品牌 logo + 鞋款全貌，引导购买                     | 建议性 |
| **4–10 秒**  | 卖点集中：材质（真皮/飞织）、功能（缓震/防滑）、细节（走线、鞋垫、鞋底）；新技术可用动效讲原理 | 建议性 |
| **11–16 秒** | 穿搭场景：上脚效果、2–3 套穿搭切换、通勤/户外/居家           | 建议性 |
| **17–20 秒** | 信任与转化：耐磨/抗菌等认证，或明星代言、直播切片            | 建议性 |

### 3.2 优质垂类视频：产品展示类（品质材质式）

| 维度         | 说明                                       | 类型   |
| ------------ | ------------------------------------------ | ------ |
| **适用场景** | 新品首发、强调材质工艺、静动态展示为主     | 建议性 |
| **逻辑**     | 凸显美观性与材质质感，多场景多角度外观展示 | 建议性 |
| **结构**     | 整体展示 → 局部材质特写 → 局部功能细节特写 | 建议性 |

### 3.3 优质垂类视频：

| 维度         | 说明                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **适用场景** | 差异化卖点、真人出镜、特定人群                               | 建议性 |
| **逻辑**     | 通过真人（穿搭博主、素人用户、老年体验者等）试穿与讲解，传递核心卖点与穿着感受，建立信任 | 建议性 |
| **结构**     | 卖点引入 → 真人上脚展示 → 使用体验说明 → 推荐行动            | 建议性 |

## 六、标题规范

### 6.1 短标题

| 项目     | 要求                                                         | 类型   |
| -------- | ------------------------------------------------------------ | ------ |
| **字数** | **含品牌**，**16–30字符**（汉字计 2，数字/符号/英文计 1）    | 建议性 |
| **结构** | 【品牌】+【产品词】+【适用场景】/【功能卖点】/【材质特征】/【风格趋势】 | 建议性 |
| **组合** | 从适用场景、功能卖点、材质特征、风格款式中**精选 1–2 个关键词**，严禁堆砌 | 建议性 |

**可选词库（文档列举）：**

- 适用场景：居家、通勤、户外工地、跑步、沙滩、办公室  
- 功能卖点：防滑、静音、防穿刺、抗静电、保暖、透气、筒高（低/中/高帮）  
- 材质特征：EVA、真皮、网布、橡胶、帆布  
- 风格款式：厚底、高帮、低帮、复古、运动、商务  

**品类适配（文档示例）：**

- 拖鞋：侧重材质特征 + 适用场景，如「EVA 室内居家」  
- 功能鞋：侧重适用场景 + 功能卖点，如「工地防穿刺」  
- 休闲鞋：侧重材质特征 + 适用场景，如「网布夏季通勤」  
- 鞋类：侧重风格款式 + 功能卖点（如中筒复古等）  

### 6.2 长标题

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **字数**     | 「不含品牌，60 个字符以内」                                  | 建议性 |
| **通用结构** | 【品牌】+【性别】+【产品词】+【上市时间】+【适用人群】+【适用场景】+【功能/特色卖点】+【鞋面材质】+【鞋底材质】+【适用季节】+【颜色】+【尺码】 | 建议性 |

**不同品类侧重（文档示例）：**

- 拖鞋：侧重鞋根底形状（示例：洁丽雅男拖2026春季新款学生居家浴室洗澡防滑EVA平底鞋）
- 靴类：侧重筒高（示例：Dickies 男款马丁靴 2026 春季新款短筒学生春秋款增高加厚柔软大底）  
- 功能鞋：侧重附加功能（示例：蓝欧顿男士劳保鞋2026春季新款牛皮革高帮轻便透气防砸减震铁路地铁专用）
- 休闲鞋：侧重鞋面材质、鞋帮高度（示例：百丽（Belle）女士小白鞋2026春季新款学生头层牛皮春夏通勤休闲百搭低帮）

## 七、卖点规范

| 项目                 | 要求                                                         | 类型   |
| -------------------- | ------------------------------------------------------------ | ------ |
| **核心原则**         | 参数转化为可感知语言；突出材质优势、功能特色与技术理念；凸显品质感、舒适感、性价比 | 建议性 |
| **增加用户体感输出** | 围绕脚感、耐用、场景融合材质与穿着感受；例：头层牛皮→「透气不闷脚」；加宽版型 →「宽脚福音」；足弓科技→「足弓承托，久走不累」 | 建议性 |
| **材质与耐用性**     | 头层牛皮/羊皮、橡胶/牛筋底；手工缝线/重工雕花；耐磨抗造、一擦即净 | 建议性 |
| **功能防护**         | 防滑防水；防穿刺/防砸/防静电；透气干爽、保暖锁温、减震缓冲   | 建议性 |
| **舒适**             | 弹踩屎感、轻盈无重感、柔韧贴地感、硬挺支撑感、软底舒适、日行万步不累脚等 | 建议性 |
| **风格版型**         | 复古腔调；隐形增高、加宽跖围、足弓承托、流行元素             | 建议性 |
| **注意事项**         | 防穿刺、绝缘、抗菌等功能卖点须有工艺或检测报告；材质图标与实物一致，禁止夸大 | 要求性 |

## 八、属性规范

### 8.1 总则

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **填写原则** | 按实物准确、可验证填写；非必填但重要属性及其他属性应填尽填；与标题、卖点逻辑一致；禁止矛盾、夸大、虚假 | 要求性 |

### 8.2 填写示例

| 属性           | 要求                                                         | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **鞋面材质**   | 明确牛皮革/人造革/织物等，与检测报告一致                     | 要求性 |
| **鞋底材质**   | 明确橡胶/PU/EVA 等；非环保材质不得标「环保鞋底」             | 要求性 |
| **闭合方式**   | 明确是系带/魔术贴/拉链/一脚蹬等；勿用「便捷穿脱」类模糊词    | 要求性 |
| **鞋帮高度**   | 明确低帮/中帮/高帮；勿用「常规高度」                         | 要求性 |
| **鞋跟底形状** | 明确方跟/细跟/粗跟/坡跟/马蹄跟等，与标题卖点一致；勿用「异形跟」「特殊形状」 | 要求性 |

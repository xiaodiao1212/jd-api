# 坚果蜜饯行业 商品信息运营规范

> **来源：** 京东商品运营中心官方建议  **文档入口：**https://mtt.jd.com/serviceno/servicenoHomePage/378  **专题：**https://mtt.jd.com/index/collection-detail?collectionId=39051  **性质说明：** 规范为平台洞察提炼的转化优化参考，**并非强制性平台规则**（以商家后台及类目规则为准）。  **更新日期：** 2026 年 4 月 16 日 

------

## 一、整体规范综述

商品信息围绕用户选购需求，通过优化产品主图、主图视频、标题、卖点、属性、品质标签等 **10 项基础内容**，优化用户体验，提升转化率；其中「标题」在后文拆为长标题 / 短标题）。

### 1.1 十大模块要点总览

| 模块         | 核心要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **主图**     | **主图首张包含主图信息要素：**商品名、商品展示、规格、品牌、卖点和价促。前 5 张按「核心卖点→品质/场景→背书」递进；素材中心补充卖点图/场景图/白底图/透明图 | 建议性 |
| **主图视频** | 种草向/商品展示/工艺或产地介绍；总时长控制在 **40 秒以内**   | 建议性 |
| **长标题**   | 结构：品牌+品名+形容词+规格；规格用「（单件净含量*数量）或（总净含量+含数量）」标明克重 | 建议性 |
| **短标题**   | 结构同长标题方向，形容词控制在 **2～3 个词组**，精简表达     | 建议性 |
| **卖点**     | 相对标题更偏「趣味性、解说性」；优先选择长标题有而短标题塞不下的关键形容词；避免与短标题重复 | 建议性 |
| **属性**     | ① 与长短标题、卖点、**已选弹层**、主图等商详外露信息一致；② 提升用户高搜的通用属性覆盖率 | 建议性 |
| **尺码绑定** | 结构化命名：核心卖点+简短品名+（单件净含量*数量）或（总净含量+含数量）+包装形式；不同末级避免捆绑在同一 SPU 下) | 建议性 |
| **系列品**   | 同店内以「类别/规格/包装/口味/品质/成分/是否有壳有核/价促」为主题划分；经营多细分类目且垂类品牌店铺搭配组合 | 建议性 |
| **主推标签** | 完成主推配置后 APP 展示「主推」标识，利于加购转化            | 建议性 |
| **品质标签** | 以产地、工艺、配料或关键成分为抓手，承接更高质检             | 建议性 |

## 二、主图规范

### 2.1 核心总结（画面与品质）

| 维度         | 规范要求                                       | 类型   |
| ------------ | ---------------------------------------------- | ------ |
| **层级清晰** | 整体排版有序，层级在字号、颜色、粗细上区分清楚 | 建议性 |
| **色彩协调** | 背景色与主体、文字配色协调，符合品牌与品类气质 | 建议性 |
| **清晰度**   | 高分辨率、无模糊失真                           | 建议性 |

### 2.2 主图结构化（前五张分工）

首张主图要素：商品名、商品展示、规格、品牌、卖点。【建议性】

| 张序        | 内容重心                                                     | 类型   |
| ----------- | ------------------------------------------------------------ | ------ |
| **第 1 张** | **商品主题** + **核心卖点** + **价促**（产地/工艺/场景/口味/口感/健康成分/品质/包装形式等） | 建议性 |
| **第 2 张** | 围绕核心卖点强化补充（同上维度）                             | 建议性 |
| **第 3 张** | **人货场**：适用场景、适用人群                               | 建议性 |
| **第 4 张** | **品质**：颗粒大小、**种类介绍** + 原料进口与否              | 建议性 |
| **第 5 张** | 商品本身/ 品牌背书 / 网红零食推荐 / 特殊工艺等               | 建议性 |

**差异化补充：** 配料表 / 营养成分表——实物描述可采用简易表格或丰富成分呈现，提升专业感。【建议性】

**拉流量：** 在京麦素材中心补充场景图、透明图、白底图、卖点图，满足多场域展示（上传路径：`京麦 - 商品 - 素材管理 - 商品素材`）。【建议性】

### 2.3 首张主图模块化布局

| 区块                   | 位置/作用       | 规范要求                                                     | 类型   |
| ---------------------- | --------------- | ------------------------------------------------------------ | ------ |
| **品牌**               | 须体现          | 包含商品名、商品展示、规格、品牌、卖点等首图核心要素         | 建议性 |
| **核心卖点（含背书）** | 主视觉旁/信息区 | 与上列核心要素一致，可含认证类背书                           | 建议性 |
| **商品展示**           | 画面主体        | 建议组合「商品主体（强调包装样式）+ **单果展示**（强调品质）+ 场景（强调产地与食用场景）」 | 建议性 |
| **价促/ 商品名**       | 底部常用        | 撞色强化视觉冲击；可含到手价、限时补贴、赠品等（须合规）     | 建议性 |

### 2.4 优质主图结构化方向（四类）

以下为文档示意类的典型板式方向，可按品类与 SKU 择优组合：

| 类型                    | 画面与信息侧重点                                             | 类型   |
| ----------------------- | ------------------------------------------------------------ | ------ |
| **品质验证**            | 品牌名；老字号/口感/品质文案；多规格及颗粒展示（口味、颗粒尺寸、产地、国标口径等）；外观细节放大；店铺背书与促销 | 建议性 |
| **混合口味或礼盒装**    | 品牌名；高销量/人气/受众或地位类卖点；多口味混合特征；规格多人场景；价促气泡 | 建议性 |
| **代表性品牌（口碑）**  | 品牌名；认可度/品质背书；口碑补充；中华老字号、有机等证书露出；品质+口感+人数场景 | 建议性 |
| **本地特产 / 产地商品** | 品牌名；产区/地标/荣誉；正宗特产、原香原味、少添加等产地心智；品质+成分+健康标的 | 建议性 |

### 2.5 主图前五张示例（文档范例）

| 主图顺序   | 内容要求                                  | 示例方向（节选）                                             |
| ---------- | ----------------------------------------- | ------------------------------------------------------------ |
| 首图       | 主体 + 核心卖点 + 价促                    | 如「老树大颗粒｜开口率高…」「老字号传统工艺…」               |
| 第二张     | 核心卖点强化                              | 如原味烘烤、少许盐调味、果仁香气；或牧场奶源、原生态多样牧草 |
| 第三张     | 人货场搭配                                | 如孕妇级零食轻盐营养；或即食/泡水场景                        |
| 第四张     | 品质                                      | 多国果仁拼图；或营养元素对比可视化                           |
| 第五张     | 商品本身/品牌背书/网红零食推荐/特殊工艺等 | 如360度立体盐炒、三蒸三晒、0添加                             |
| 差异化补充 | 配料/成分/尺寸                            | 礼盒明细表；净含量与配料营养成分展开                         |

## 四、主图视频规范

### 4.1 拍摄与呈现建议

| 项目           | 规范要求                                                     | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **风格**       | 种草向 / 商品展示 / 工艺或产地介绍                           | 建议性 |
| **时长**       | 种草、商品展示建议 **15～30 秒**；工艺/产地介绍建议 **30～40 秒** | 建议性 |
| **画质**       | 高清、明亮、稳定                                             | 建议性 |
| **字幕与声音** | 建议配字幕（便于静音观看）；BGM 以轻松纯音乐为主，口播卖点更佳 | 建议性 |

### 4.2 视频结构

| 类型               | 结构要点                                                     | 类型   |
| ------------------ | ------------------------------------------------------------ | ------ |
| **种草向**         | 核心卖点（成分/易食等）+ 真人互动（剥开/撕开）+ 附加场景（泡酒/泡茶等）+ 工艺/功效 | 建议性 |
| **工艺或产地介绍** | 工艺/产地场景 + 原料与加工品呈现 + 附加场景 + 工艺/功效      | 建议性 |

### 4.3 视频类型与时长（文档表）

| 视频类型       | 内容要求                                        | 时长（建议） |
| -------------- | ----------------------------------------------- | ------------ |
| 种草向         | 核心卖点 + 真人互动 + 附加场景 + 工艺/功效      | 15～20 秒    |
| 商品展示       | 商品展示 + 卖点，无价格和口播                   | 20～30 秒    |
| 工艺或产地介绍 | 工艺/产地 + 原料与加工品 + 附加场景 + 工艺/功效 | 30～40 秒    |

## 五、长标题规范

### 5.1 字数与计数规则

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **长度**     | **长标题60个字符以内**（文档口径：1 英文/数字/符号=1 字符；**1 汉字=2 字符**） | 建议性 |
| **品牌占位** | 品牌由系统关联时可不占字符（以商家后台实际规则为准）         | 建议性 |
| **结构**     | 品牌 + 品名 + 形容词（产地/工艺/场景/口味/口感/健康/品质/包装形式）+ 规格 | 建议性 |
| **规格**     | 「（单件净含量*数量）或（总净含量+含数量）」，标明克重       | 建议性 |
| **合规**     | 避免误导性话术（如「买一赠一」「TOP1」等不当表述）           | 要求性 |

### 5.2 类目结构与示例

| 类目           | 推荐要素顺序                                                 | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **坚果炒货**   | 【品牌】+【产品词】+【规格】+【包装形式-强调礼盒】+【口味】+【产地】+【种类数-礼盒品】+【等级/品质】+【加工工艺】+【人群/场景】 | 建议性 |
| **蜜饯果干**   | 【品牌】+【产品词】+【规格】+【包装形式-强调礼盒】+【产地】+【成分】+【口味】+【产品特点】+【加工工艺】+【人群/场景】 | 建议性 |
| **奶制品零食** | 【品牌】+【产品词】+【规格】+【包装形式-强调礼盒】+【产地】+【成分】+【口味】+【人群/场景】+【特性】 | 建议性 |

**文档示例（节选）：**

- 坚果炒货：`楼兰蜜语 薄皮核桃500g*2袋 原味零添加新疆阿克苏原产地轻松开壳休闲零食`
- 蜜饯果干：`佳宝九制话梅150g/瓶广东李子咸甜开味传统入味话梅子蜜饯果干解馋`
- 奶制品零食：`朴珍 奶贝奶片500g/袋内蒙特产高钙无蔗糖益生元混合口味儿童休闲零食`

### 5.3 优秀案例思路

利用多余字符空间补充「坚果品种与数量」，避免堆砌；拆分复合配料降低歧义，讲清「纯坚果」特征。

- **优化前（示意）：**`[自营][京东超市] 沃隆 纯坚果每日坚果600g/24袋0添加混合坚果腰果核桃仁休闲零食礼盒`
- **优化后（示意）：**`[自营][京东超市] 沃隆 纯坚果每日坚果600g/24袋 礼盒0添加6种混合干果含腰果核桃仁零食`

## 八、属性规范

### 8.1 填写原则

| 项目           | 要求                                                         | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **一致性**     | 属性需与长短标题、卖点、已选弹层、主图等商详外露信息一致     | 要求性 |
| **覆盖率**     | 积极补充 4 种以上属性信息，商详会有额外楼层露出；通过口味、包装形式、类别、总净含量、产地等通用属性提升覆盖率 | 建议性 |
| **类目差异化** | 坚果炒货关注是否去壳；蜜饯果干关注是否有核、工艺；奶制品零食关注国产/进口、产地等 | 建议性 |

### 8.2 信息不一致（示例）

商详「特性：无核」与属性「是否有核：有核」互斥，易引发客诉与流失。【要求性】

## 九、系列品规范

### 9.1 平台规则摘要

通过为用户推荐高关联商品，来缩短跳转和决策路径，提升消费者的购物体验和商家的销售转化率。

| 项目         | 规则                                                     | 类型   |
| ------------ | -------------------------------------------------------- | ------ |
| **绑定范围** | 同店铺、同品牌、同三级类目可绑定（三级类目可跨类目绑定） | 规则性 |
| **展示数量** | 可展示 **2～6 个 SPU**                                   | 规则性 |
| **上限**     | 单店铺最大 **2000** 个系列品组                           | 规则性 |

### 9.2 运营建议

同店内，建议以经营多细分类目且垂类品牌店铺（如三只松鼠、沃隆等）作为

初次搭配测试建议；以【类别/规格/包装/口味/品质/成分/是否有壳有核/价促】为

主题划分。

| 建议方向        | 示例                                                   |
| --------------- | ------------------------------------------------------ |
| 类别            | 混合果干/坚果系列；碧根果系列                          |
| 规格            | 同三级类目不同规格（小包规/中包规/大包规系列）         |
| 包装            | 家庭量贩系列、出游便携系列、小包独立系列、送礼专享系列 |
| 口味            | 混合口味系列；奶油味系列                               |
| 品质            | 大果系列、2025 新鲜果粒                                |
| 成分系列        | 低 GI 系列、低热量系列、健康代餐系列                   |
| 是否有壳/有核等 | 无核系列、免剥系列                                     |
| 价促            | 高性价比系列                                           |

## 十、尺码绑定规范

### 10.1 规则与作用

| 项目       | 说明                                                         | 类型   |
| ---------- | ------------------------------------------------------------ | ------ |
| **一致化** | SKU 的末级类目、品牌、SPU 一致化属性等信息需保持一致         | 规则性 |

### 10.2 命名建议

**结构化命名：**`核心卖点 + 品名（简短美观品名为主） +（单件净含量*数量）或（总净含量+含「数量」）+ 包装形式（礼盒装需特别强调）`【建议性】

## 十一、主推标签与品质标签

### 11.1 主推标签

主推标签是对主推商品配置打标的工具；配置后在京东 APP 展示「主推」等标识，用户浏览商详时可直观看到主推商品标志，主要提升加购转化。【建议性】

### 11.2 品质标签（行业高标与展现）

| 方向         | 说明                                                         | 类型   |

## 主图视频（建议性）
- [ ] 风格为种草向 / 商品展示 / 工艺或产地介绍之一
- [ ] 时长（种草/商品展示 15～30s；工艺/产地介绍 30～40s）
- [ ] 高清、明亮、稳定；配字幕；BGM以轻松纯音乐为主
```

```

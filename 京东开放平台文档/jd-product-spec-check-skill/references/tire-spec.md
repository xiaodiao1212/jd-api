## 一、整体规范综述

商品信息围绕用户选购需求，通过优化**产品主图、主图视频、标题、卖点、参数楼层与属性、图文详情**等 7 项基础内容，优化用户体验，提升转化率。

| 模块               | 核心方向                                                     | 类型   |
| ------------------ | ------------------------------------------------------------ | ------ |
| **主图**           | 模块化布局（5 模块），短时间内传递关键信息，提升点击意愿与信息吸收效率 | 建议性 |
| **主图视频**       | 聚焦产品，高科技视觉呈现；围绕“节能、安全、静音、耐用”，用对比、模拟、展示等方式突出优势 | 建议性 |
| **长标题**         | 优先完整展示：轮胎类型、规格、系列、花纹、适配车型等关键信息，便于识别核心参数与适用车型 | 建议性 |
| **短标题**         | 突出「品牌」「规格」，产品词明确类型，可选花纹/车型/性能传递差异 | 建议性 |
| **卖点**           | 覆盖舒适、安全、性能等维度；可替换为时速或承重数据；**避免工业化术语**，降低认知成本 | 建议性 |
| **属性与参数楼层** | 关键参数从商详底部属性模块**上提至参数楼层**；属性值须严格规范、准确一致 | 建议性 |
| **图文详情**       | 将轮胎的技术参数转化为用户可理解的决策信息，利用从活动引流到知识科普的逻辑闭环，降低用户选择难度并建立信任 | 建议性 |

## 三、主图视频（建议方向）

### 3.1 核心原则

以用户为中心，动态视觉讲好轮胎故事，构建信任、高效转化；有限时长内精准传递价值、解决痛点。

### 3.2 详细要求

| 维度         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **基础规格** | 时长 15–60 秒；画面清晰稳定；整体比例与字幕大小适配移动端；字幕不挡主体 | 建议性 |
| **内容要求** | 开篇抓注意力；紧扣安全、舒适静音、耐磨耐用、性价比等核心需求 | 建议性 |
| **呈现规范** | 简洁醒目文字标注关键信息、核心卖点与技术参数；BGM 符合定位、不遮挡语音信息 | 建议性 |

### 3.3 内容展开维度（示例）

围绕「节能、安全、静音、耐用」四大核心优势展开：**卓越节能 / 湿地安全 / 静音舒适 / 持久耐用。**

从宏观宇宙冒险逐步聚焦到微观轮胎科技和实际应用：开篇点题/专业赛事背书/产品科技解析。

## 四、标题规范

### 4.1 长标题（商详）

| 项目               | 要求                                                         | 类型   |
| ------------------ | ------------------------------------------------------------ | ------ |
| **结构**           | **固定二段式**：第一段仅「商品品牌」（**不计入**总字符数），需与商品挂靠品牌一致；第二段为核心描述（**计入**总字符数，**≤60**） | 建议性 |
| **字符规则**       | 1 汉字/全角符号 = 2 字符；1 英文/半角/数字 = 1 字符          | 建议性 |
| **第二段固定排序** | `[轮胎类型]+[轮胎规格]+[产品系列]+[花纹性能]+[适配车型(1-5个)]+[服务承诺/核心卖点（剩余字符充足时补充）]` | 建议性 |
| **轮胎类型**       | 仅选 1 个：汽车轮胎 / 静音棉轮胎 / 防爆轮胎 / 自修补轮胎 / 雪地轮胎 | 建议性 |
| **多车型**         | 用 `/` 分隔                                                  | 建议性 |
| **字符超限处理**   | 若超过 60，优先删除服务承诺/非核心卖点，确保基础信息完整     | 建议性 |

### 4.2 短标题（搜索）

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **结构**     | `[品牌] + [产品词] + [轮胎规格] + (可选信息)`                | 建议性 |
| **可选信息** | 轮胎花纹 / 适用车型 / 花纹性能（三选一或组合，空格分隔）     | 建议性 |
| **字数**     | **8–15 个汉字**，且整体在 **30 字符内**；1 英文/数字/符号 = 1 字符 | 建议性 |
| **产品词**   | 择一：汽车轮胎、静音棉轮胎、防爆轮胎、自修补轮胎、雪地轮胎   | 建议性 |

## 五、卖点规范（通用卖点）

| 项目           | 要求                                                         | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **原则**       | 消费者语言，突出直观价值，避免工业化术语                     | 建议性 |
| **数量与字数** | 每品展示 **3 个**卖点，每个 **4–5 个字**；其中 **1 个**可换为具体最高时速或承重数据 | 建议性 |
| **忌用**       | 如「花纹块设计」「低滚动阻力」等专业术语；卖点之间不重复     | 建议性 |
| **维度**       | 覆盖舒适、安全、效率等不同维度                               | 建议性 |

**示例组合（原图）：**  

标准型：舒适驾乘 | 湿地稳行 | 节能省油  

高性能型：运动操控 | 强效抓地 | 最高 300km/h  

耐用型：耐磨缓震 | 静音舒适 | 承重 800KG

## 六、属性与参数楼层

### 6.1 总结

用户关注的轮胎关键参数从商详底部的属性模块**上提至「参数楼层」**；所有属性值填写须**严格遵循规范**，保证准确、一致。

### 6.2 参数项说明（原图列示）

| 参数                      | 说明                     | 示例                                     | 类型   |
| ------------------------- | ------------------------ | ---------------------------------------- | ------ |
| **轮胎规格**              | 物理尺寸与性能参数       | 205/55R16、215/55R17                     | 建议性 |
| **车辆类型**              | 适配的车辆类别           | 通用、轿车轮胎、商用车轮胎               | 建议性 |
| **速度级别**              | 可持续行驶的最高速度     | T（180km/h）/S（180km/h）/V （2400km/h） | 建议性 |
| **花纹性能**              | 胎面花纹特性             | 经济耐磨、雪地防滑、运动操控             | 建议性 |
| **轮胎类型**              | 功能分类                 | 常规标准轮胎、新能源轮胎、缺气保用轮胎等 | 建议性 |
| **Treadwear（耐磨指数）** | 耐磨量化指标，越高越耐磨 | 560、570                                 | 建议性 |

## 七、图文详情（建议方向）

### 7.1 整体要求

| 维度           | 说明                                                         | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **规格与车型** | 将技术参数转化为用户可理解、可操作的信息，并通过工具降低选择难度 | 建议性 |
| **差异化**     | 将抽象性能转化为直观、可比较的视觉信息，强化核心卖点         | 建议性 |
| **信任与服务** | 建立正品信任感，明确线下服务流程，提升转化信心               | 建议性 |

### 7.2 结构化要求（原图框架）

| 屏段           | 内容方向                                                     | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **第 1 屏**    | 补贴活动与产品荣誉等，吸引关注、促购买决策                   | 建议性 |
| **第 2 屏**    | 质保、储存、养护小贴士等                                     | 建议性 |
| **第 3–10 屏** | 底层技术拆解 → 硬核性能佐证 → 用户体验升级 → 直观产品展示    | 建议性 |
| **第 11 屏**   | 选购科普：规格确认、适配要求、更换规则与更换周期；规格标识各字符含义 | 建议性 |

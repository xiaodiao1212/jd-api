### char_counter.py 用法

```bash
# 单条标题计数
python3 scripts/char_counter.py "维达 超韧山茶花抽纸4层90抽20包"

# 带品类阈值校验
python3 scripts/char_counter.py -c tissue "你的标题"

# 短标题校验
python3 scripts/char_counter.py -c tire -s "你的短标题"

# 从文件批量
python3 scripts/char_counter.py -f titles.txt -c meat
```

## 注意事项

1. **登录态要求**：需要有效的京东采销工作台登录态才能访问商品详情
2. **规范更新**：平台规范可能更新，请以官方最新规范为准
3. **要求性 vs 建议性**：
   - 要求性规范：必须遵守，违反可能导致下架/降权
   - 建议性规范：推荐遵守，有助于提升转化
   - 优化性建议：可选优化，进一步提升效果
4. **批量处理**：批量校验建议每次不超过 50 个商品
5. **字符计数**：京东平台计数规则为汉字=2字符、英文/数字/符号=1字符，与 Python `len()` 不同
6. **品类差异**：不同品类的标题字数上限、卖点条数/字数、必填属性各不相同，以各品类 spec 为准

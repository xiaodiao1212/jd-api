# 熟肉制品 商品信息运营规范

> **来源：** 京东商品运营中心官方建议  **文档入口：**https://mtt.jd.com/serviceno/servicenoHomePage/378  **专题：**https://mtt.jd.com/index/collection-detail?collectionId=39051  **性质说明：** 规范为平台洞察提炼的转化优化参考，**并非强制性平台规则**（以商家后台及类目规则为准）。  **更新日期：** 2026 年 4 月 27 日 

------

## 一、整体规范综述

**围绕用户选购需求和决策关注点**，通过优化**商品主图、主图视频、长/短标题、卖点、属性、品质标签、尺码绑定、系列品、主推标签**等基础模块（文档口径为 **10 项**），优化用户体验，提升转化率。

### 1.1 十大模块要点总览

| 模块         | 核心要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **主图**     | **首张**含：商品名、商品展示、品牌、核心&营销卖点、价促。**前 5 张**：第 1 卖点图 + 第 2～3 产品明细（成分表&产品信息、细节特写、制作工艺）+ 第 4～5 补充（包装细节、搭配场景、烹饪方法、品牌资质、送礼场景）；素材中心补卖点图/场景图/白底图/透明图 | 建议性 |
| **主图视频** | 种草开箱、工艺展示、品质特写、场景/烹饪方法（烹饪镜头 **5～8 秒**，聚焦「简单易操作」）；组合拍摄；建议 **≤60 秒** | 建议性 |
| **长标题**   | 品牌+品名+形容词（产地/工艺/场景/口味/口感/健康成分/品质/包装）+规格；规格「（单件净含量×数量）或（总净含量+含数量）」标明克重 | 建议性 |
| **短标题**   | 品牌+品名+形容词+规格；字符 **不超过 30**                    | 建议性 |
| **卖点**     | 用户语言、通俗易懂；**优先选择长标题中存在**但短标题字数受限无法展示的关键形容词；避免与短标重复；方向含产地&特产、工艺、适用场景、口感风味、健康成分、品质特征、包装形式、食用方式 | 建议性 |
| **属性**     | 与长短标题、卖点、已选弹层、主图等外露一致；完善用户关注属性 | 建议性 |
| **系列品**   | 多细分类目+垂类品牌组合；主题可按类别/包装/口味/品质/成分/礼盒/适用场景来划分 | 建议性 |
| **尺码绑定** | 结构化命名：核心卖点+简短品名+口味+规格；避免不同末级类目捆绑同一 SPU | 建议性 |
| **主推标签** | 对 SPU 下主推荐 SKU 打标；APP 展示 **主推标识**              | 建议性 |
| **品质标签** | 产地（地理标志产品）、工艺（中华老字号）、配料/关键成分（高蛋白、高钙、0 脂、配料干净）等 | 建议性 |

## 二、主图规范

### 2.1 优化基础要求

| 维度     | 规范要求                                                     | 类型   |
| -------- | ------------------------------------------------------------ | ------ |
| **排版** | 规整有序，不同层级在字号、颜色、粗细上区分清晰；字体尽可能一致 | 建议性 |
| **配色** | 符合品牌形象与商品特性，协调统一                             | 建议性 |
| **画质** | 高分辨率、无模糊失真                                         | 建议性 |

### 2.2 首张主图核心要素

要素：**品牌、商品名、商品展示、核心卖点、规格、价促**。【建议性】

| 区块                 | 要求摘要                                                     | 类型   |
| -------------------- | ------------------------------------------------------------ | ------ |
| **品牌**             | 醒目字体与颜色；可含传达价值观的标语                         | 建议性 |
| **产品词及核心卖点** | 品名清晰；**1～3 个**核心差异化卖点                          | 建议性 |
| **商品展示**         | 商品主体（呈现形态）+ 细节（可视化味觉/风味）+ 场景（原料与食用场景） | 建议性 |
| **信任背书**         | 关键信任信息；善用对比增强信任                               | 建议性 |
| **价格促销**         | 底部采用撞色设计增强视觉吸引力；包含到手价、限时补贴、赠品等（须合规） | 建议性 |

### 2.3 主图结构化：前五张（建议方向）

| 张序        | 内容重心                                                     | 类型   |
| ----------- | ------------------------------------------------------------ | ------ |
| **第 1 张** | 商品主体 + 核心卖点 + 价促（产地/工艺/场景/口味/口感/健康成分/品质/包装形式） | 建议性 |
| **第 2 张** | 激发食欲：肉类特写，风味与口感可视化                         | 建议性 |
| **第 3 张** | 加深理解：配料表&产品信息图&产品成分表、制作过程、肉源产地   | 建议性 |
| **第 4 张** | 匹配需求：包装细节展示、多场景展示、多种烹饪方法/食用方式展示、品牌资质 | 建议性 |
| **第 5 张** | 品牌资质与信任：品牌介绍、资质认证、质检报告等               | 建议性 |

**丰富素材图类型：** 除前五张外，在京麦素材中心补充：白底图、透明图、场景图、卖点图（上传路径：`京麦 - 商品 - 素材管理 - 商品素材`）。【建议性】

### 2.4 首张主图模块化布局（建议）

模块化网格含品牌名、卖点、场景、商品主体、商品细节、价促信息/商品名。【建议性】

| 区块                   | 规范摘要                                                     | 类型   |
| ---------------------- | ------------------------------------------------------------ | ------ |
| **品牌**               | 品牌名称 + LOGO；醒目字体与颜色                              | 建议性 |
| **核心卖点（含认证）** | 品牌下方、商品左侧；资质认证可排列一行                       | 建议性 |
| **产品展示**           | 商品主体（强调包装样式） + 实物展示（肉质、纹理等）+ 场景（如原产地） | 建议性 |
| **价促/商品名**        | 底部撞色；包含到手价、限时补贴、赠品等                       | 建议性 |

### 2.5 首张主图四类驱动方向（文档示意）

#### 【感官驱动】

烹饪类或即食类：**展示商品外包装**，右下角展示**烹饪后/食用时**状态，增强食欲。（文档含午餐肉修改前后与点评示例。）【建议性】

#### 【成分驱动】

健康与高品质商品：**更大字号**突出原料（优质肉源、高肉含量、低淀粉等）。（文档含牛肉脆片等示例。）【建议性】

#### 【信任驱动】

有品牌传承：突出「中华老字号」等权威标识。（文档含腊味、腊鸭腿示例。）【建议性】

#### 【真实感驱动】

礼盒/礼包商品：**外包装与内置内容**同显，数量视觉化，所见即所得。（文档含鸡肉大礼包、肉类零食礼盒示例。）【建议性】

### 2.6 主图结构化：前五张示例（文档表）

| 主图顺序   | 内容要求                       | 示例方向（文档节选）                                         |
| ---------- | ------------------------------ | ------------------------------------------------------------ |
| **首图**   | 品牌、商品主体、核心卖点、价促 | 黑猪午餐肉（肉含量、大肉块、无添加、淀粉含量等）；牛腱（原切、草饲、配方干净、低脂高蛋白等） |
| **第二张** | 成分表、产品信息图             | 风干牛脆片产地配料与营养成分表；高蛋白牛健肉营养成分表       |
| **第三张** | 细节特写、制作工艺             | 和牛雪花纹理；香肠切面与工艺参数                             |
| **第四张** | 包装细节、搭配场景、烹饪方法   | 火腿礼盒；多场景轻食指引                                     |
| **第五张** | 品牌资质、送礼场景、售后/质检  | 检测报告页；品牌传承与产地叙事                               |
| **礼盒装** | 展示礼包内置清单               | 多口味网格清单；烤鸭礼盒配料与开盒实拍                       |

## 四、主图视频规范

### 4.1 通用建议

| 项目                | 规范要求                                                  | 类型   |
| ------------------- | --------------------------------------------------------- | ------ |
| **方向**            | 种草开箱、工艺展示、品质特写、场景/烹饪方法               | 建议性 |
| **画面**            | 清晰、明亮，与产品实际一致                                | 建议性 |
| **字幕与声音**      | 配字幕（无声观看）；BGM 轻松纯音乐；可口播卖点            | 建议性 |
| **时长与节奏**      | 前 **5 秒**抓住注意力；组合拍摄；建议 **均控制在 60s 内** | 建议性 |
| **再烹饪/加工镜头** | 简洁、「简单易操作」；**5～8 秒**；不喧宾夺主             | 建议性 |

### 4.2 视频类型与结构化示例（文档表）

| 视频类型           | 说明要点                                                     | 类型   |
| ------------------ | ------------------------------------------------------------ | ------ |
| **种草开箱**       | 第一视角开箱；外包装、内袋与分量；卖点口播与试吃             | 建议性 |
| **工艺/品牌**      | 标准化生产流程；工序特写；车间卫生合规；关联口感与锁鲜       | 建议性 |
| **品质特写**       | 肉质纹理色泽；按压/撕扯/切片体现口感；健康与高肉含量字幕     | 建议性 |
| **场景化烹饪方法** | 多种食用场景与简易食用/烹饪步骤；即食便捷 vs 蒸炒涮焖成品展示 | 建议性 |

## 五、长标题规范

### 5.1 字数与优化

| 项目           | 要求                                                         | 类型   |
| -------------- | ------------------------------------------------------------ | ------ |
| **长度**       | **60 个字符以内**（1 英文/数字/符号=1；**1 中文=2**）；品牌前缀不计入字符数 | 建议性 |
| **优化**       | 利用多余空间补充核心卖点、差异点、常搜通用品类词/热点词      | 建议性 |
| **结构**       | 品牌+品名+形容词+规格；规格「（单件净含量×数量）或（总净含量+含数量）」标明克重 | 建议性 |
| **形容词维度** | 产地/工艺/场景/口味/口感/健康成分/品质/包装形式              | 建议性 |
| **合规**       | 规避营销词不良引导（买一送一、TOP1、企业团购等）             | 要求性 |

### 5.2 形容词优先级顺序建议

文档小节：**「形容词优先级顺序建议」** — 按细分类目差异化：【建议性】

| 细分类目     | 优先级顺序（文档）                                           | 用户关注点摘要                                   |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------ |
| **肉类零食** | 口味 > 口感 > 健康成分 > 场景 > 工艺 > 品质 > 包装 > 产地    | 好不好吃、健康、是否独立包装                     |
| **熟食腊味** | 产地 > 工艺 > 口味 > 品质 > 食用方式 > 场景 > 包装 > 健康成分 | 地域心智、传统工艺/正宗性、家宴/下酒/年货送礼    |
| **罐头食品** | 品质 > 健康成分 > 场景 > 口味 > 工艺 > 包装 > 口感 > 产地    | 用料、肉含量、无添加；火锅、露营、囤货；易开罐等 |
| **方便食品** | 品质等级 > 健康成分 > 口味 > 场景 > 口感 > 包装 > 工艺 > 产地 | 无淀粉、优级、高肉含量、低脂；独立袋装、整箱量贩 |

文档中含各类目示例长标题（京东京造风干牛肉、周家口酱牛肉、上海梅林鸡胸肉原味午餐肉、双汇王中王轻盐特级火腿肠等），可作为句式参考。

### 5.3 优化对比（文档示意）

文档给出风干牛肉优化前后对比：强化「高蛋白、低脂、健身解馋」等可感知卖点。【建议性】

## 六、短标题规范

| 项目         | 要求                                             | 类型   |
| ------------ | ------------------------------------------------ | ------ |
| **结构**     | 品牌+品名+形容词+规格                            | 建议性 |
| **形容词**   | 从 **8 大类**中选 **2～3 类**词组                | 建议性 |
| **字数**     | **16～30 个字符**（计数规则同长标题：中文=2）    | 建议性 |
| **品牌展示** | 关注品牌占用字符；优先级「中文名称 > 英文缩写」  | 建议性 |
| **合规**     | 规避营销词不良引导（买一送一、TOP1、企业团购等） | 要求性 |

文档「优化方向示例」含补充规格、补充品牌、补充卖点等表格。【建议性】

## 七、卖点规范

### 7.1 选题与表达

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **错位补充** | **优先选择长标题中存在**、因短标题限制无法展示的关键形容词；避免与短标题重复 | 建议性 |
| **语言风格** | 相较工业化表述，用用户语言，通俗易懂、快速辅助决策           | 建议性 |
| **方向**     | 产地&特产、工艺、适用场景、口感风味、健康成分、品质特征、包装形式、食用方式；结合商品选 **2～3 个**方向 | 建议性 |

### 7.2 平台规则（文档）

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **数量**     | **建议维护 3 个卖点**                                        | 建议性 |
| **每条字数** | **2～8 个字符**（中文、数字、符号、英文均按 **1 个字符**计） | 建议性 |

### 7.3 示例方向（文档卡片）

产地特色、工艺、适用场景、口感风味、成分、品质特征、包装形式、食用方式 —— 各配有商品示意与卖点短语示例（东北红肠、先卤后烤、出游解馋、口感紧实、0 添加防腐剂、中华老字号等）。【建议性】

## 八、属性规范

### 8.1 信息丰富度

完善用户关注属性有助于流量。【建议性】

| 细分类目     | 文档建议补充                         |
| ------------ | ------------------------------------ |
| **肉类零食** | 补充保质期、加工工艺、口味、包装形式 |
| **熟食腊味** | 加工工艺、产地                       |
| **罐头食品** | 国产/进口、烹饪建议                  |

### 8.2 额外加成与一致性

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **额外加成** | 积极填写 **4 条及以上**属性，商详可获额外信息外露            | 建议性 |
| **填写规范** | 属性须与长/短标题、卖点、已选弹层、主图等外露**保持一致**，避免客诉与用户流失 | 要求性 |

**反例：** 标题写「牛肉丁」，属性类目选「牛肉片」。【要求性】

文档含搜索列表属性外露与商详参数楼层示意。【建议性】

## 九、系列品规范

### 9.1 平台规则摘要

| 项目         | 规则                                                     | 类型   |
| ------------ | -------------------------------------------------------- | ------ |
| **绑定范围** | 同店铺、同品牌、同三级类目可绑定（三级类目可跨类目绑定） | 规则性 |
| **展示数量** | **2～6 个 SPU**                                          | 规则性 |
| **上限**     | 单店铺最大 **2000** 个系列品组                           | 规则性 |

### 9.2 运营建议

同店内以多细分类目+垂直品牌组合；主题可按 **类别/包装/风味口味/品质成分/场景** 等划分（文档含低脂鸡肉、年货礼盒、轻盐健康、无淀粉、健身控卡等示例方向）。【建议性】

------

## 十、尺码绑定（SKU）规范

### 10.1 规则与作用

| 项目       | 说明                                             | 类型   |
| ---------- | ------------------------------------------------ | ------ |
| **一致化** | SKU 的末级类目、品牌、SPU 一致化属性等需保持一致 | 规则性 |
| **作用**   | 共用权重与评价；减少无效对比与跳失；提升运营效率 | 建议性 |

### 10.2 命名建议

**结构：**`核心卖点 + 品名（简短类目名为主）+ 口味 + 规格（「单件净含量×数量」或「总净含量」；礼盒装须强调）`【建议性】

文档对比「优秀示例」（以口感、成分为核心前缀）与「待提升示例」（缺少口味与卖点）。【建议性】

------

## 十一、主推标签

为 SPU 下主推荐 SKU 打标；配置后 APP 展示 **「主推标识」**，缩短决策、提升加购转化。【建议性】

文档含 SKU 列表、宫格选款、商详 SKU 区等展示样式示意。【建议性】

------

## 十二、品质标签

对有资质认证的商品打标；成功后在搜索与商详展示。**安心品质为京东特有品质楼层**，同品竞对未必有特殊露出。【建议性】

**建议：** 产地（地理标志产品）、工艺（中华老字号）、配料/关键成分（高蛋白、高钙、0 脂、配料干净）。【建议性】

### 12.1 标签要求（节选）

| 标签名                   | 标签要求（摘要）                                             |
| ------------------------ | ------------------------------------------------------------ |

# 清洁纸品 商品信息运营规范

> **来源：** 京东商品运营中心官方建议  **文档链接：**[京东商品运营中心](https://mtt.jd.com/serviceno/servicenoHomePage/378) · [专题：商品信息促转化](https://mtt.jd.com/index/collection-detail?collectionId=39051)  **最后更新：** 2026 年 4 月 28 日  **提取方式：** OCR 识别原图内容  **说明：** 「官方建议」为平台经验归纳，供商家参考，**非**强制性平台规则。下文「要求性/建议性」依原图表述与项目既有规格文档惯例归纳，自检时须与平台强制规则区分。

## 一、整体规范综述（十大模块）

清洁纸品商品信息优化围绕用户快速识别规格、功能与品质保障的决策路径，通过主图、主图视频、长/短标题、卖点、参数楼层与属性、系列品、尺码绑定、主推标签、一诺千金等模块提升信息质量。

| 模块              | 核心方向                                                     | 类型   |
| ----------------- | ------------------------------------------------------------ | ------ |
| **主图**          | 首张主图采用模块化布局，将画面划分为品牌、核心卖点、其他营销卖点、产品展示、核心规格、促销活动临时贴片和价格促销等模块 | 建议性 |
| **主图视频**      | 拍摄风格以实物展示与产品实际使用为主；种草/商品展示、实际使用或实验对比均建议 5–10 秒 | 建议性 |
| **长标题**        | 结构化：品牌 + 类别/类型 + 产品词 + 核心规格 + 适用场景/范围 + 核心功能功效/卖点 + 资质；60 字符以内 | 建议性 |
| **短标题**        | 结构化：品牌 + 核心功能功效/卖点 + 产品词 + 核心规格；16–30 字符 | 建议性 |
| **卖点**          | 偏向用户语言，避免技术化和工业化用语，严禁夸大或虚假宣传功效信息 | 要求性 |
| **参数楼层&属性** | 将用户关注的参数信息从商详最下方的属性模块上提至参数楼层；属性需要与长短标题、卖点、已选弹层、主图等外露信息一致；增加用户高搜的通用属性覆盖率（如原料成分、是否压花、是否独立包装、功能） | 要求性 |
| **尺码绑定**      | SKU 末级类目、品牌、SPU 一致化属性保持一致；规格名称结构化且排序有逻辑 | 建议性 |
| **系列品**        | 同店内建议以经营多戏份类目且垂类品牌店铺作搭配推荐；以类别/系列/联名/原料成分/包装形式/尺寸等主题划分 | 建议性 |
| **主推标签**      | 配置后 APP 显示「主推」标识，提升加购转化                    | 建议性 |
| **一诺千金**      | 京东超市联合生活用纸品牌推出的品质保障活动，承诺抽数符合国家标准，配置后展示「品质保真」标签 | 建议性 |

## 二、主图规范

### 2.1 效果数据（原文）

- 商详转化率 **+10.18%**；商详提袋率 **+3.31%** ↑

### 2.2 主图基础要求

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **文字排版** | 整体文字排版规整有序，不同层级信息在字体大小、颜色、粗细等方面需明显区分 | 建议性 |
| **色彩搭配** | 色彩搭配符合品牌形象与产品特点，保证色调协调统一             | 建议性 |
| **图片质量** | 图片需保证高分辨率、无模糊失真，提升整体宣传效果与用户体验   | 建议性 |

### 2.3 首张主图核心要求

| 模块                 | 规范要求                                                     | 类型   |
| -------------------- | ------------------------------------------------------------ | ------ |
| **品牌**             | 以醒目字体与颜色展示品牌名称及传达核心价值的标语，强化品牌辨识度 | 建议性 |
| **核心卖点**         | 体现产品最关键的卖点，让用户快速知晓                         | 建议性 |
| **其他营销卖点**     | 在产品展示层左侧，竖版排列呈现具体卖点，解决用户痛点、满足需求 | 建议性 |
| **产品展示**         | 清晰美观展示清洁纸品，凸显产品本身                           | 建议性 |
| **核心规格**         | 明确展示层数、抽数/卷数、包数、克重等核心规格                | 建议性 |
| **促销活动临时贴片** | 传达活动主题和时间                                           | 建议性 |
| **价格促销**         | 处于图片底部，用撞色设计展示促销信息                         | 建议性 |

### 2.4 主图 2-5 张（建议方向）

| 序号      | 内容要求          | 说明                                                         | 类型   |
| --------- | ----------------- | ------------------------------------------------------------ | ------ |
| 第 2 张   | 优惠活动/新旧包装 | 随机发货建议放前面；展示商品或品牌福利                       | 建议性 |
| 第 3-5 张 | 核心/营销卖点     | 以用户能看懂的语言展示核心卖点，最好有量化数据，如有效除菌 99.9% | 建议性 |

### 2.5 完整主图示例要点

| 主图顺序      | 内容要求                                                     | 类型   |
| ------------- | ------------------------------------------------------------ | ------ |

| **第 2 张**   | 优惠信息图，随机发货建议放前面，展示商品/品牌福利            | 建议性 |
| **第 3-5 张** | 核心卖点或功能功效、资质证明；使用用户语言展示亲肤可湿水、湿水不易破、干擦不易掉屑、空气柔层、原生木浆等信息 | 建议性 |

## 四、长标题规范

### 4.1 效果数据

- 商详转化率 **+0.61%** ↑

### 4.2 基本要求

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **标题结构** | 商品标题为二段式结构，即「商品品牌」+「自定义文本框」        | 建议性 |
| **品牌字段** | 第一段「商品品牌」不计入标题总字符数；品牌需与商品挂靠品牌保持一致 | 建议性 |
| **字数**     | 60 个字符以内；1 个汉字/全角符号 = 2 字符，1 个英文字母/半角符号/数字 = 1 字符 | 建议性 |
| **结构建议** | 品牌 + 类别/类型 + 产品词 + 核心规格 + 适用场景/范围 + 核心功能功效/卖点 + 资质 | 建议性 |

### 4.3 类目结构

| 类目                         | 内容建议（粗体为必填，非粗体为非必填）                       | 类型   |
| ---------------------------- | ------------------------------------------------------------ | ------ |
| 抽纸/卷纸/手帕纸             | **【品牌】**+【类别/类型】+**【产品词】+【核心规格】（层数******单包规格******包数）**+【适用场景/范围】+**【核心功能功效/卖点】**+【资质】 | 建议性 |
| 湿巾/湿厕纸/洗脸巾           | **【品牌】**+【类别/类型】+**【产品词】+【核心规格】（单包规格\*包数）**+【适用场景/范围】+**【核心功能功效/卖点】**+【资质】 | 建议性 |
| 厨房纸巾/一次性清洁/护理纸品 | **【品牌】**+【类别/类型】+**【产品词】+【核心规格】（单包规格\*包数/卷数）**+【适用场景/范围】+**【核心功能功效/卖点】**+【资质】 | 建议性 |

### 4.4 优化方向示例

| 优化前                                                       | 优化后                                                       | 变更                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 维达（Vinda）山茶花B5精华湿厕纸80片*6包双重精华保湿加大加厚湿纸巾厕纸 | 维达 湿厕纸**80片\*6包XL码**山茶花B5双重精华保湿加大加厚**可冲散** | 将规格信息提前，卖点信息后移。加入用户高关注卖点，如「可冲散」。 |
| 维达（Vinda）湿厕纸 家庭装60片*6包 多巴胺湿厕纸纯水湿纸巾厕纸湿巾新旧随机 | 维达 **纯水**湿厕纸60片*6包通用湿纸巾 **家庭装可冲散**日常清洁无香型 | 在产品词前添加类别/类型信息。添加适用场景/范围：家庭装加入用户高关注卖点，如「可冲散」。 |

## 六、通用卖点规范

### 6.1 基本要求

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **语言风格** | 避免技术化和工业化用语，使用用户理解的语言                   | 建议性 |
| **合规要求** | 严禁夸大或虚假宣传功效信息                                   | 要求性 |
| **转化方向** | 将「加厚」等工业表述转化为「湿水不易破」「湿水不烂絮」等用户关心表达 | 建议性 |

### 6.2 示例词

| 方向     | 示例                             | 类型   |
| -------- | -------------------------------- | ------ |
| **韧性** | 柔韧不掉屑、湿水不易破、强韧耐用 | 建议性 |
| **亲肤** | 柔软亲肤、亲肤无刺激             | 建议性 |
| **功能** | 吸水强、抑菌、无荧光剂           | 建议性 |

## 七、属性与参数楼层规范

### 7.1 基本要求

| 项目         | 要求                                                         | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| **一致性**   | 属性需要与长短标题、卖点、已选弹层、主图等商详外露信息保持一致，避免客诉和用户流失 | 要求性 |
| **覆盖率**   | 增加用户高搜的通用属性覆盖率                                 | 建议性 |
| **参数楼层** | 将用户关注的参数信息从商详最下方属性模块上提至参数楼层，提升决策与转化效率 | 建议性 |

### 7.2 重点属性

| 属性名   | 说明           | 示例值             | 类型   |
| -------- | -------------- | ------------------ | ------ |
| 品牌     | 商品品牌       | 维达/洁柔/心相印   | 要求性 |
| 原料成分 | 纸品原料       | 原生木浆           | 建议性 |
| 类别     | 产品类型       | 抽取式/卷纸/湿厕纸 | 建议性 |
| 包装形式 | 包装类型       | 箱装/独立包装      | 建议性 |
| 适用场景 | 使用场景       | 家用/日常清洁      | 建议性 |
| 是否压花 | 是否含压花工艺 | 无印花/立体压花    | 建议性 |
| 功能     | 核心功能       | 可湿水/可冲散/抑菌 | 建议性 |

### 7.3 信息不一致反面案例

- 标题或标签写「立体压花」，属性填写「非压花」。
- 外露规格、已选规格与标题核心规格不一致。

## 八、尺码绑定规范（SKU 规格命名）

### 8.1 绑定规则

- SKU 的末级类目、品牌、SPU 一致化属性等信息需要保持一致。【要求性】
- SKU规格名称建议结构化展示且注意SKU的展示顺序需有一定逻辑性，便于用户易选易购【建议性】

### 8.2 命名结构

| 类目     | 命名结构（粗体为必填，非粗体为非必填）                       | 类型   |
| -------- | ------------------------------------------------------------ | ------ |
| 抽纸     | 产品简称/卖点 + **层数 + 单包抽数\******包数*** *+ 尺寸（选填M码或长**宽 mm） | 建议性 |
| 卷纸     | 产品简称/卖点 + **层数 + 单卷克重/节数\*卷数** + 功能/材质   | 建议性 |
| 厨房纸巾 | 产品简称/卖点 + **层数 + 单包规格\******包数（单卷规格******卷数）**+ 功能/材质 | 建议性 |
| 湿厕纸   | 产品简称/卖点 + **单包片数\*包数** + 香型 + **包装形式**     | 建议性 |
| 湿巾     | 产品简称/卖点 + **单包片数\*包数** + 香型+ 卖点/功能         | 建议性 |
| 手帕纸   | 产品简称/卖点 + **层数 + 单包张数\*包数** + 香型 + 尺寸      | 建议性 |
| 洗脸巾   | 产品简称/卖点 + 材质/纹路 + **规格**                         | 建议性 |

### 8.3 排序建议

相同系列放在一起宣传；先按层数升序或降序，层数相同按单包抽数排序，单包抽数相同按包数排序。【建议性】

## 十、主推标签规范

### 10.1 效果数据

- 商详转化率 **+2.87%** ↑

### 10.2 说明

主推标签是对主推商品配置打标的工具，商家完成配置后，在京东 APP 上会有对应的「主推」标识，用户在浏览商品详情时，能直观看到主推商品标志，提升商品的加购转化。【建议性】

## 十一、一诺千金规范

### 11.1 效果数据

- 商详转化率 **+0.05%**；搜索点击率 **+0.05%** ↑

### 11.2 说明

「一诺千金」是京东超市联合生活用纸品牌推出的品质保障活动，承诺商品抽数符合国家标准。消费者购买带有「抽数保真」标识的商品后，若发现数量不符合国家标准，收到商品 7 个工作日内提交相关证据，京东在规定时间内若核实无误，消费者可获得 1000 元超市卡。【建议性】

### 11.3 展示要求

| 项目               | 要求                                                         | 类型   |
| ------------------ | ------------------------------------------------------------ | ------ |
| **卖点楼层露出**   | 搜索列表中可展示「抽数保真 假一赔千」等标签                  | 建议性 |
| **专属 Logo 露出** | 主图或列表图可展示「一诺千金」「京东抽纸」「抽数严守国家标准」等专属标识 | 建议性 |

## 十二、校验清单（运营自检）

```
## 主图（建议性）
- [ ] 文字排版层级清晰，色彩协调，高分辨率无模糊
- [ ] 首图采用模块化布局（品牌/核心卖点/营销卖点/产品展示/核心规格/促销）
- [ ] 核心规格清晰展示层数、抽数/卷数、包数、克重等
- [ ] 第 2 张展示优惠活动或新旧包装说明
- [ ] 第 3-5 张覆盖核心卖点、功能功效或资质证明

## 主图视频（建议性）
- [ ] 视频 5–10 秒，高清稳定
- [ ] 内容为实物展示、实际使用或实验对比
- [ ] 搭配字幕，BGM 轻松，可搭配口播

## 长标题（建议性）
```

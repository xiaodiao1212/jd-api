# 家电类目主图设计规范

> **来源：** 京东商品运营中心官方建议  **原文标题：** 大促卖货：跳出贴片扎堆困境，掌握高效设计解法——家电类目  **参考入口：**[京东商品运营中心](https://mtt.jd.com/serviceno/servicenoHomePage/378)（专题《商品信息促转化》）  **发布时间：** 2025-10-13  **适用范围：** 家电类目主图及大促贴片类素材  **文档性质：** 专题材料为「官方建议」，**非强制性平台规则**；落地以平台 / 后台最新规则为准。

------

## 一、整体规范综述

家电大促主图常见问题是「贴片大战」导致信息过载、视觉疲劳，反而降低信息传递效率。规范从 **信息梳理、布局排版、色彩应用** 三个设计维度拆解，目标是在传递活动与卖点的同时，控制认知负荷、理顺阅读节奏。

| 目标           | 核心做法                                         | 类型   |
| -------------- | ------------------------------------------------ | ------ |
| 降低认知负荷   | 维度分类、控制信息量上限、区分主次               | 建议性 |
| 提升阅读效率   | 顺应自然动线（左→右、上→下），区隔信息块         | 建议性 |
| 强化氛围与识别 | 主色与商品/活动调性一致，控制色相数量            | 建议性 |
| 贴片理性使用   | 不以「大而艳」为默认；复杂背景时可用贴片换可读性 | 建议性 |

## 二、主图信息整理

### 2.1 信息分类（内容相近做归堆）

按用户决策链路将主图信息归为 **三大类**，与「决策依据 / 购买动力 / 行动及时性」对应：

| 维度             | 用户心智（原文概括） | 典型内容                                  | 类型   |
| ---------------- | -------------------- | ----------------------------------------- | ------ |
| **商品卖点**     | 产品牛               | 功能、材质、技术、差异化资质等            | 建议性 |
| **活动利益点**   | 价格划算             | 满减、折扣、赠品、套餐、服务权益等        | 建议性 |
| **限时叠加利益** | 立即下单             | 限时券、叠券、倒计时、前 N 名等强时效信息 | 建议性 |

**实操要求（原文）：** 同类信息聚拢呈现，避免全图平铺混杂。

| 项目     | 规范要求                                               | 类型   |
| -------- | ------------------------------------------------------ | ------ |
| 分类展示 | 卖点、活动价、限时利益分区明确（可用色块/留白/分割线） | 建议性 |
| 价格区   | 到手价、补贴口径与活动区可分离，避免与卖点句挤在同层   | 建议性 |

### 2.2 信息筛选（控制上限，强化重点）

| 项目         | 规范要求                                                     | 类型   |
| ------------ | ------------------------------------------------------------ | ------ |
| 核心信息条数 | 核心信息建议控制在 **5 项**以内；辅助信息不超过 **4 项**     | 建议性 |
| 核心文字字号 | 核心文字尺寸建议 **≥30px**（可按画布等比缩放）               | 建议性 |
| 权重排序     | 优先「差异化卖点」(人无我有)；再结合搜索/点击等 **大盘行为数据** 前置高关注信息 | 建议性 |

### 2.3 信息表达（降低阅读难度）

| 手法               | 规范要求                                                  | 类型   |
| ------------------ | --------------------------------------------------------- | ------ |
| 荣誉/背书          | 长句荣誉可 **符号化**（勋章、盾牌等），减少文字占位       | 建议性 |
| 服务、口碑、排行榜 | 质保、价保、物流、好评、排行等可用 **统一规格图标**       | 建议性 |
| 利益点             | 红包、赠品、券、晒单返等宜 **分层、图标化**，避免单行堆叠 | 建议性 |

## 三、布局与视觉动线

| 项目     | 规范要求                                                     | 类型   |
| -------- | ------------------------------------------------------------ | ------ |
| 阅读顺序 | 顺应 **从左到右、从上到下** 的习惯排列信息优先级             | 建议性 |
| 熟悉样式 | 利益条、腰带等用户已熟悉的样式可沿用，降低学习成本           | 建议性 |
| 区隔手段 | 用 **留白、分割线** 分隔模块，保证规整可扫读                 | 建议性 |
| 动线目标 | 避免多点争夺视线；典型动线：**卖点区 → 利益/权益区 → 价格区（常置底部）** | 建议性 |

------

## 四、色彩应用

| 项目     | 规范要求                                                     | 类型   |
| -------- | ------------------------------------------------------------ | ------ |
| 调性匹配 | 母婴常用柔和的暖色调；家电常用 科技感的冷色调；大促氛围可适当提高饱和，但需与品类调性协调 | 建议性 |
| 颜色数量 | 主打 **2 个主色 + 黑白色**承载文字与线；避免 **超过 3 个主色** 造成杂乱 | 建议性 |
| 主色来源 | **场景图取色**（家电类的金属灰，母婴类的柔粉色）；或 **品类联想色** | 建议性 |
| 辅色     | 可从场景 **次要色** 取辅色增强一体感                         | 建议性 |
| 信息强调 | 对关键句使用 **高亮色** 做次强调，避免满屏艳色块             | 建议性 |

## 五、贴片尺度与背景处理

### 5.1 实验结论（原文）

| 结论               | 说明                                                         | 类型   |
| ------------------ | ------------------------------------------------------------ | ------ |
| 非「大而艳即正义」 | 同品实验中，**低饱和清晰版 / 小贴片突出产品版** 相对高饱和大贴片均有显著提升案例 | 建议性 |
| 决定因素           | **信息是否被准确接收**、是否支持决策，优于单纯贴片面积与饱和度 | 建议性 |

**重要边界：** 文中「↑133%」「↑283%」等为 **个案实验** 相对原图在商详提袋率或成交转化率的变化，**不得**宣传为全体商家/全 SKU 承诺效果。

### 5.2 复杂背景

| 场景               | 规范要求                                                 | 类型   |
| ------------------ | -------------------------------------------------------- | ------ |
| 背景花、字贴图不清 | 可使用 **半透明底色/贴片** 提升可读性                    | 建议性 |
| 原则               | 从 **信息有效性** 选择是否加贴片，而非一律取消或一律铺满 | 建议性 |

## 六、反面模式与优化方向（主图困境）

| 反面现象                 | 优化方向                         | 类型   |
| ------------------------ | -------------------------------- | ------ |
| 贴片密度过高、多色块无序 | 减项、分类、统一色彩层级         | 建议性 |
| 促销与卖点同屏无主次     | 拆区排列，核心卖点大字或顶栏少量 | 建议性 |
| 与场景色调冲突           | 从场景取主色/降饱和利益色        | 建议性 |

## 七、执行自检清单（建议性）

```
## 主图信息整理（建议性）
- [ ] 信息可归入「卖点 / 活动利益 / 限时利益」三类且分区清楚
- [ ] 核心条数未明显多于「约 5+4」参考，应合并或上图标
- [ ] 动线单一清晰，价格在固定预期区域（多为底部）
- [ ] 主色未超过约 3 个色相堆叠，应收紧为 2 主色 + 黑白
- [ ] 背景与字可读，复杂背景应使用轻量衬底
- [ ] 权益/荣誉图标合规，无绝对化或虚假背书
```

## 类目主图问题

## 一、激活味觉联想，放大产品吸引力

### 1-A 微距呈现食物质感，促发视觉通感

**核心手法：**

| 手法          | 说明                                 |

## 三、降低促销识别难度，让划算一眼可见

在信息爆炸的流式浏览中，大段的文字很容易让用户失去耐心，从而漏看关键信息。在关键利益点的表达上，我们要做到更直观、更可视化的呈现。

### 3-A 促销机制可视化

#### 1. 量贩阵列式排布

针对周期性复购的囤货场景，我们要考虑解决总价高带来的支付犹豫，因而在主图上需要重点突出：量大、单价低的感知。

| 手法               | 说明                                                         |
| ------------------ | ------------------------------------------------------------ |
| **阵列式展示商品** | 堆叠套装商品，在画面布局占比中尽可能饱满，在不阅读其他信息的前提上就让人有第一眼感知：多 |
| **强化数量记忆**   | 将"20袋"、"30天装"、"整箱"等规格词放大，进一步强化到手多的感受 |
| **体现单价低**     | 通过展示单个商品的到手价，强调划算便宜                       |

**案例：法优乐酸奶**

| 对比     | 文案内容                                                     |
| -------- | ------------------------------------------------------------ |
| 😐 优化前 | Pom'Potes 法优乐，进口儿童酸奶销量NO.1，进口常温酸奶，原味*6、草莓*6、蓝莓*4、桃子*4（少量产品散放展示） |

### 3-B 信息秩序清晰化

### 3-C 用色彩构建高效阅读

利用色彩反差来提升信息可读性。特别对于关键利益点，考虑使用更高的反差比，让它从"被用户搜索"变为"主动吸引用户注意"。

**案例：秋田满满 尝鲜礼盒**

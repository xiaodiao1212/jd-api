## 一、整体规范综述

为提升用户前台购物浏览体验，帮助用户清晰明了地选购心仪商品，现将厨具品类下的餐具、茶具套装商品主图进行规范说明，该品类商品主图须遵循以下规范：

### 主图核心要求

| 模块            | 核心要求                                   | 类型   |
| --------------- | ------------------------------------------ | ------ |
| **主图数量**    | 建议主图数量最多上传 5 张                  | 建议性 |
| **第 1 张主图** | 应为场景图                                 | 要求性 |
| **第 2 张主图** | 套装整体展示图，需与下方详细示例一致       | 要求性 |
| **第 3 张主图** | 实物图；如有礼盒，需一起出镜实拍，不可渲染 | 要求性 |
| **第 4 张主图** | 商品细节图                                 | 要求性 |
| **第 5 张主图** | 卖点图                                     | 要求性 |

## 二、主图规范

### 2.1 主图 1-5 张结构化要求

| 序号        | 内容要求       | 说明                                      | 类型   |
| ----------- | -------------- | ----------------------------------------- | ------ |
| **第 1 张** | 场景图         | 展示商品使用场景                          | 要求性 |
| **第 2 张** | 套装整体展示图 | 展示整套餐具 / 茶具，需与下方详细示例一致 | 要求性 |
| **第 3 张** | 实物图         | 如有礼盒，需一起出镜实拍，不可渲染        | 要求性 |
| **第 4 张** | 商品细节图     | 展示商品细节                              | 要求性 |
| **第 5 张** | 卖点图         | 展示商品核心卖点                          | 要求性 |

### 2.2 第 2 张主图内容规范

为保证消费者可以快速了解套装商品，在第 2 张主图中，建议展示以下内容：

| 模块             | 规范要求                                                     | 类型   |
| ---------------- | ------------------------------------------------------------ | ------ |
| **套装名称**     | 需要说明套装的名称和规格，帮助消费者掌握核心属性与卖点，快速判断产品是否符合需求 | 要求性 |
| **套装整体图片** | 完整呈现套装内的所有单品，让消费者一眼看清款式搭配与数量构成，快速获得整体印象 | 要求性 |
| **套装内容介绍** | 逐一列出套装中每件单品的名称、规格和数量，并可同时标注赠品及包装配置 | 要求性 |
| **套装适用场景** | 说明商品的使用限制；当商品适用场景较广泛时，可增加此项做为亮点 | 建议性 |

## 三、校验清单

### 3.1 上架前自检清单

```
## 主图检查（建议性）
- [ ] 主图数量不超过 5 张

## 主图检查（要求性）
- [ ] 第 1 张为场景图
- [ ] 第 2 张为套装整体展示图，需与下方详细示例一致
- [ ] 第 3 张为实物图；如有礼盒，需一起出镜实拍，不可渲染
- [ ] 第 4 张为商品细节图
- [ ] 第 5 张为卖点图
- [ ] 第 2 张包含套装名称
- [ ] 第 2 张完整呈现套装整体图片
- [ ] 第 2 张逐一列出套装中每件单品的名称、规格和数量

## 主图检查（建议性）
- [ ] 套装名称包含系列名称、件数、适合群体、使用场景、包装形式等信息
- [ ] 套装整体图片完整集中摆放，未只呈现局部
- [ ] 套装内容通过图片清晰呈现商品本体、赠品及包装
- [ ] 适用场景通过文案或图标合理展示
```

### 3.2 常见问题

| 问题                   | 原因                                  | 解决方案                              |
| ---------------------- | ------------------------------------- | ------------------------------------- |
| 消费者无法判断套装构成 | 第 2 张未完整展示单品名称、规格、数量 | 在第 2 张逐一列出套装内容并与图片对应 |
| 礼盒信息引发误解       | 礼盒未与实物一起出镜或存在虚设        | 礼盒随第 3 张实物图一起实拍展示       |
| 套装数量不清           | 只使用氛围图或局部图                  | 使用整套餐具 / 茶具集中摆放图片       |

{ 整体规范综述 } INTRODUCTION

整体规范综述：商品信息围绕用户选购需求，通过优化产品主图、标题、卖点、系列品提升流量转化效率

● 主图：结构化，核心决策信息聚焦于首屏主图位置，从而提升选购效率
● 标题：结构化，长标题用于精准呈现商品核心信息，表述简明、准确且详尽，既可实现精准检索召回，也有助于构建买家信任度；短标题聚焦提炼商品核心卖点，仅用于前端用户展示，通过清晰直观的核心信息，助力用户快速做出购买决策
● 卖点：差异化，针对不同价格区间消费者所关注的核心信息，精准匹配对应产品卖点，助力用户高效完成购买决策
● 系列品工具（不同spu绑定）：标准化，制定不同品类绑定规则，模糊信息标准化、简单清晰可识别
● 规格图：简洁化，减少多余价促切片，保留场景图和关键卖点

01 { 主图：结构化 } PRODUCT MAIN IMAGE

产品主图（第一张）：
突出高端、品质和品牌调性，头图（第1帧）突出核心卖点
保持现有策略，保持简洁，减少贴片数量，确保产品清晰、完整展示

结构化展示：
【主图视频】提高主图视频覆盖及质量，包含品宣视频、产品介绍视频、采销推荐视频，需要突出产品功能、场景适用性
【第1张：产品主图】核心展现产品外观，露出核心卖点/体验点。第一张主图确保产品完整清晰，不允许任何遮挡，底部可放价格、权益、服务等。可选：个性化、高端背景主题，根据产品特性配置相应风格
【第2张：尺寸】突出产品核心参数、产品清单等
【第3张：服务/权益】如送装一体、购机权益等
【第4张：卖点总览】一张图展示商品核心卖点/功能点，不超过8个
【第5-10张：卖点展开】用户语言阐释具体的卖点、功能

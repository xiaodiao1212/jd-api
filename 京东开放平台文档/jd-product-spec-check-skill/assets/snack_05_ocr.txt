03 { 长标题 } SPECIFICATION

效果数据：
商详转化率+0.6%
商详提袋率+1.66% ↑

建议：
字数：长标题限60个字符（英文字母、数字或符号各占1个字；每个汉字各占2个字；品牌前缀不计入长标题字符数）。
标题结构化：品牌+品名+形容词（产地/工艺/场景/口味/口感/健康原料/品质/包装形态）+规格。
规格表达：（单件净含量*数量）或（总净含量+数量），标明克数。
注意：避免不良营销话术（例如「买一送一」「TOP1」一类）〔措辞以原图为准〕〔字迹不清〕

结构化公式及示例：
饼干：【品牌】+【品名】+【核心风味/原料】+【品质/工艺描述】+【场景/属性】+【规格/包装】+【适用场景】
示例：碧翠园 燕麦谷物棒坚果味酥脆高蛋白烘焙盒装20g*25支代餐饱腹

膨化食品：【品牌】+【品名】+【口味/风味】+【口感/形态】+【规格/包装】+【趣味/场景】
示例：热烈 爆米花奶油非油炸微波炉酥脆袋装100g*10袋休闲伴侣〔字迹不清〕

优秀案例：
策略：在长标题冗余字符空间中补充核心卖点词，拉高差异与类目常用搜索词的覆盖。
优化前：[京东自营标][京东超市标]〔品牌马赛克〕零食大礼包636g 馍片雪饼馍丁办公室零食
优化后：[京东自营标][京东超市标]〔品牌马赛克〕零食大礼包 多口味 混合装〔字迹不清〕 馍片雪饼馍丁 办公室 解馋零食 636g

04 { 短标题 } SPECIFICATION

效果数据：搜索点击率 ↑

总结：
短标题结构化：品牌+品名+形容词+规格。
精简表达：形容词从上述8大类（产地/工艺/场景/口味/口感/健康原料/品质/包装形态）中择2-3类组合。
字数：16-30个字符（英文字母、数字或符号各占1个字；每个汉字各占2个字；需特别注意品牌所占字符）。
展示优先级：中文名优于英文名缩写。
注意：避免不良营销话术〔同长标题提示〕〔字迹不清〕

策略：增补口味类型「四口味」；规格「208g」；包装属性「礼盒装」。

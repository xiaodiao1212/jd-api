07 { 系列品 } SPECIFICATION

规则：
同店铺、同品牌、同三级类目可绑定（三级类目可以跨类目绑定）。可展示2-6个SPU；单店铺内最大绑定2000个系列品组。

说明：
通过为用户推荐高关联商品，来缩短跳转和决策路径，提升消费者的购物体验和商家的销售转化率。

建议：
同店内，本次建议以经营多细分类目且垂类品牌店铺（如乐事、亿滋等）作为初次搭配测试建议；以【规格/包装/口味/成分/系列】为主题划分。

表：建议方向｜示例｜前端

规格｜同三级类目不同规格（小包规/中包规/大包规系列）｜〔手机端「选择系列」弹层示意：大包规系列、中包规、规格内容与价格〕〔字迹不清〕

包装｜家庭量贩系列、出游便携系列、小包独立系列、送礼专享系列｜〔前端示意图〕〔字迹不清〕

口味｜混合口味系列；黑松露风味系列｜〔字迹不清〕

成分系列｜低GI系列、低热量系列、健康代餐系列｜〔字迹不清〕

08 { 尺码绑定 } SIZE BINDING

规则：
SKU的末级类目、品牌、SPU一致化属性等信息需要保持一致。

说明：
共用权重、评价等，避免用户在相似商品间反复对比、减少跳失；便于流量集中；减少重复操作，提升运营效率。

建议：
结构化命名：核心卖点+品名（简短类目名为主）+（单件净含量*数量）或（总净含量+含数量）+包装形式（礼盒装需特别强调）。

优秀案例：
右侧示意可见字：

②卖点+简短品名（或类目名）+总净含量+包装规格+包装形式〔字迹不清〕

{ 整体规范综述 } INTRODUCTION

整体规范综述：围绕用户决策路径，系统化提升主图、标题、卖点、详情、视频、属性6大点位信息质量，驱动流量转化提升。

用户决策树

决策层
核心需求匹配，决策购买
决策因子：
品牌：用户认知/偏好品牌
类型：用户家庭环境和洗衣习惯
容量：用户家庭人口
系列：用户认知/偏好系列
功能：用户洗衣核心需求
价位：用户预算区间
结构化透传 → 搜索卡片核心点位 → 主图首图、长标题、短标题、卖点

认知层
强化购买信心，激发购买
决策因子：
系列矩阵：全方位向用户展示核心参数
功能：场景化解决用户洗衣痛点
技术：通俗化向用户讲解技术优势
能效：向用户传递节能省钱
材质：向用户传递质量保障
服务：向用户传递送装及售后无忧
高效率沟通 → 商品详情核心点位 → 主图视频、主图详情、参数楼层、详情顶部

验证层
增强信任背书，打消顾虑
决策因子：
质检：向用户传递质量安全
授权：向用户传递正品保障
其他参数：用户关注的其他信息
用户证言：〔字迹不清〕
补充性透传 → 商品详情核心点位 → 主图后屏、详情中尾部、规格参数

主图
主图首张：搜索结果页与商详首屏双场景同步展示，信息精炼、分区透传，针对4类机型（经济/品质/旗舰/顶奢）采用分层视觉策略，实现精准引流
主图整体：采用“总-分”结构，信息按重要性降序排列，系统性提升用户信息获取效率

标题
采用“品牌+核心要素”结构，信息按重要性降序排列，确保层级清晰、无冗余关键词，让用户一眼抓取关键信息，实现高效引流

卖点
将技术参数转化为用户语言，聚焦“洗得干净”、“高效除菌”、“洗烘奢护”等2-3个核心痛点，一句话直击要害，实现价值精准透传

图文详情
采用“黄金四段”结构，以结构性信息快速促转化：
首屏：核心参数概览 + 店内系列商品引流
次屏：商品全景 + 核心卖点概览
中段(3-7屏)：场景化详解卖点，按重要性降序排列
尾屏(8-10屏)：信任补充（安装/售后/尺寸/质检）

视频
基于4类机型用户（经济/品质/旗舰/顶奢）的洗衣诉求与功能偏好，制定差异化视觉及信息策略，实现机型与客群精准匹配

属性
在确保“准”且“全”的基础上，将影响用户决策的关键属性前置至“参数楼层”突出展示。同时，必填属性将作为商品信息分的核心跃升因子，助力提升商品曝光

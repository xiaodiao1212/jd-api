02 { 标题：结构化 }

短标题：
字数：16-30个字符
结构：品牌+（主推卖点/系列名）+品类 + 适用人数 + 容量
例如：美的纯钛0涂层电饭煲4-5人5L

长标题：商详转化率+2.57%↑
字符数：90个字符
结构：品牌词+品类词+系列词（如有）+ 核心卖点 + 颜色 + 容量 + 适用人数 + 型号
趋势词：钛内胆、瓷内胆、316L不锈钢内胆、IH加热等（建议结合当前消费者关注的特性运营，如近期消费者关注健康、无化学有害物质析出，健康材质的内胆）
注：工艺合规+材质安全的 316L不锈钢内胆、钛内胆，可以加注“母婴级”关键词
例如：松下（Panasonic）【重磅新品】饭光光Ultra钛电饭煲家用0涂层纯钛内胆IH电饭锅4-5人316L不锈钢3.8升SR-HXET152-W

03 { 系列品绑定：标准化 }

同一SPU下的SKU绑定原则遵循：
同模具的支持绑定，不同模具需分开（如：同款不同色/不同配件/产品某个配件升级）可以进行绑定；具体规则如下：
1. 有出厂系列的优先按出厂系列划分，如：【松下饭光光系列】【苏泊尔旋焰釜系列】
2. 如上层都不满足，鉴于大部分电饭煲是按内胆材质和加热方式来规划产品线的，所以可结合内胆材质和加热方式来绑定；如：基础款入口电饭煲可以作为【基础款高性价比系列】、功能升级作为【升级款IH加热系列】或【升级款0涂层系列】
3. 同模具的商品可做绑定：从外形和功能上看，产品没有差别，只有颜色或容量的区别

以上3层规则中，需遵循 同一SPU下按容量从小到大排序 且容量放到最前面

更新日期：2024年4月21日

{ 整体规范综述 } INTRODUCTION

商品信息优化运营能围绕用户意向决策路径，通过系统化提升主图、标题、卖点、属性&参数楼层、安心品质、主推标签、SPU尺码概览、商品使用指南八大模块的信息质量，实现流量转化效率的最大化。

● 主图：
全图第一视觉区分明确的功能区域，确保信息层级清晰，构建流畅的视觉动线，引导用户快速获取核心信息，降低认知成本。当营销标题且较多，整体营销面积太大，需优化展示样式。无太多赠品时，首张主图可介绍商品主要营销活动和成分/功效模型；

● 标题：
结构遵循“品牌+核心要素”的固定结构，内容需突出系列、产地词、规格、成分特点、营销词。确保信息层级清晰且前后一致，快速抓取用户核心关注点；

● 卖点：
跨主要成分信息、认证信息、冲调方式、健康引导、使用感受、奶源地、包装形式（独立包装）等信息进行展示，并能将用户关心的功能以精准的语言进行描述，严禁夸大或虚假宣传诱导消费；

● 属性&参数楼层：
属性信息维护需准确且全面，透传搜索、筛选面板等各后台领域应用场景。通过将用户关注的属性在参数楼层展示，提升用户决策效率，并减少因信息不清晰导致的用户咨询与退货，提升客服效率与商品转化率；

● 安心品质：
上传高钙、低脂、DHA糖等权威认证报告图赏，通过在商品详情页安心品质楼层展示著作权证明书，给用户“安全心智”，建立消费者品质信任感，提升购买信心；

● 主推标签：
用户在浏览商品详情或加购物车时，能直观看到主推商品标签，助力提升商品的加购转化。

● SPU尺码概览：
SKU规格名称建议按照规范并且注重SKU的展示顺序具有一定逻辑性，便于用户挑选选购；

● 商品使用指南：
结合用户高频咨询问题、配置商品使用说明书，助力售前转化，降低售后咨询，提升用户服务体验。

01 { 主图规范 } SPECIFICATION

● 效果数据：
方图-商详转化+5.48%；长图-商详转化+12.99% ↑

● 主图基础要求：
整体文字排版框架有序，不同层级信息在字体大小、颜色、粗细等方面清晰层级区分，背景色与物品主体及文字信息色彩搭配需协调。图片需保证高分辨率、无模糊失真，提升整体宣传效果与用户体验；

● 主图首图模块化布局方案：
● 品牌Logo：置于左上角，保持清晰可见；
● 产品展示：商品正面展示图片，背景可选纯色或商品场景相适应结合的框架；
● 卖点提炼：一句话精准概括商品主要营销点，并搭配2-4个核心卖点，语言精炼、直击痛点；
● 赠品贴片：左下侧层级，清晰整洁尽量能描述，突出赠品丰富的同时让用户可直观看到赠品信息；
● 促销贴片：下方展示单件到手价及活动信息，便于用户进行价格对比及了解营销时效。

● 主图2-5张（长建议）：
● 第2张：赠品较多时补充更多福利，通过营销攻略/享好礼等字幕做指引；赠品较少时，可增加引导文案，介绍后续使用该商品对用户带来的好处。
● 第3-5张：详细描述核心成分或作用（用户语义），展示产品升级、专利技术或生产线迭代等。

首图式为重要，需重点设计。抓住用户浏览的黄金5秒，调整贴片布局，增强商品成分及核心卖点信息。

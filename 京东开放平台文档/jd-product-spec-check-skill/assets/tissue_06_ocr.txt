06 { 参数楼层&属性 } SPECIFICATION

填写规范：
- 属性需要与长短标题、卖点、已选弹层、主图等商详外露信息保持一致，避免引起客诉和不必要用户流失；
- 增加用户高搜的通用属性覆盖率（如原料成分、是否压花、是否独立包装、功能、适用场景）。

参数楼层：
将用户关注的参数信息从商详最下方的属性模块上提至参数楼层，提升用户决策与转化效率。

信息不一致（左图示例-清风有芯卷纸）：
- 价格区：¥47.9 到手价（划线¥59.9）
- 标题：[自营] 京东超市 清风有芯卷纸 厚柔 4层110克*30卷 卫生纸 纸巾整箱 厕纸 卷筒纸
- 标签：7天价保、复购补贴、原生木浆、立体压花
- 属性列表中与标签矛盾项示例：是否压花 — 非压花（与“立体压花”外露不一致）

前台效果（右图示例-洁柔抽纸）：
- 价格区：¥51.9，买3件¥38.85/件
- 标题：[自营] 京东超市 洁柔抽纸 粉Face3层150抽*24包 S码干湿两用 柔韧卫生纸 整箱纸巾
- 参数楼层横向标签示例：原生木浆（原料成分）、抽取式（类别）、箱装（包装）、家用（适用场景）、无印花（是否压花）

07 { 尺码绑定 } SIZE BINDING

规则：
SKU的末级类目、品牌、SPU一致化属性等信息需要保持一致。

说明：
共用权重、评价等，避免用户在相似商品间反复对比、减少跳失；便于流量集中；减少重复操作，提升运营效率。

建议：
SKU规格名称建议结构化展示且注意SKU的展示顺序具有一定逻辑性，便于用户易选易购。

优秀案例（规格列表）：
3层120抽*72包 【加量囤货装】
3层120抽*36包 【热门箱装】
3层120抽*24包 【店铺爆款】主推
3层120抽*20包 【整箱装】
3层120抽*12包 【商超同款】
3层120抽*8包 【经典体验装】
3层120抽*6包 【热门提装】
3层120抽*3包 【单提尝鲜装】

SPU命名结构化（灰色字体选填）：
抽纸：产品简称/卖点+层数+单包抽数*包数+尺寸（洗脸巾码或长度*宽mm）
卷纸：产品简称/卖点+层数+单卷克重/节数*卷数+功能/材质
厨房纸巾：产品简称/卖点+层数+单包规格*包数（单卷规格*卷数）+功能/材质
湿厕纸：产品简称/卖点+单包片数*包数+功能+包装形式
湿巾：产品简称/卖点+单包片数*包数+功能+包装形式
手帕纸：产品简称/卖点+层数+单包张数*包数+香型+尺寸（标准、迷你、加长）
洗脸巾：产品简称/卖点+（码数/单张克重）/纹路（珍珠纹/平纹/网纹）*规格（单包抽数/节数*包数）

排序建议：相同系列的放在一起宣传，先按照层数的升序或者降序，层数相同，按照单包抽数的升序或者降序，单包抽数相同按照包数的升序或者降序。

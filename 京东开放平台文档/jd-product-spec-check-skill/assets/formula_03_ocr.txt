04 { 通用卖点 } SPECIFICATION

● 效果数据： 搜索点击率+0.76pp ↗

● 数量及字数范围：
每个SKU可维护3个卖点，且每个卖点需满足4-16个字符（1个汉字/全角（中文）符号=2个字符，1个英文字母/半角（英文）符号/数字=1个字符）；

● 核心规则：
将参数转化为消费者可感知的语言，突出商品特点，注意不要夸大或虚假宣传；

● 填写建议：
将包装特点&送礼属性（小包装方便携带）、认证信息（欧盟认证）、健康引导（三重防护力）、使用感受（清淡口感）、奶源地（新西兰奶源）、科学配方（添加乳铁蛋白）、送礼属性（送爸妈健康）等维度进行用户语义转述，突出商品特点的可理解性，并与长/短标题做差异化信息表述。

05 { 属性&参数楼层 } SPECIFICATION

● 效果数据： 参数楼层商详转化+3.87~6.45%，不同类目有差异 ↗

● 填写规范：
提升属性填写准确率及挂靠率，需要与长/短标题、卖点、已选弹层、主图等信息保持一致，既可以提升用户搜索及筛选面板精准性，同时可避免引起客诉和不必要用户流失。

● 参数楼层：
将用户关注的参数信息从商详最下方的属性模块上提至参数楼层，同时自营商品支持外露生产日期，共同提升用户决策效率。

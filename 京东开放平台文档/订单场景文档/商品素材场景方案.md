本文为开发者讲解图片/视频上传管理及与商品的绑定接入流程，包含文本/图片/视频素材上传应用。包含商品发布流程所必须的素材（对应京麦-商品发布页），和在发品后为获取更多曝光机会优化商品素材（对应京麦-商品素材中心，发品非必填）在相关公域展示的素材信息，经维护后的素材将会在搜索、推荐、频道页等流量场有机会曝光，同时商品素材也是商品信息健康分的重要优化项。

**适用对象：** 自研商家；软件服务商

## 一、基础概念

## 1.1 图片/视频空间

> 商家后台路径： [京麦-商品-图片/视频空间](https://imgzone.shop.jd.com/)

图片空间是商家后台的统一图片管理中心，会存储商家在各渠道场景应用的图片，并支持商家对图片进行上传、删除、引用等管理操作，通俗来说，图片空间就是商家管理自己店铺内图片的“大仓库”。

视频空间除与图片相同进行视频文件的基础管理外，还兼容了视频标签、与商品绑定管理功能。

## 1.2 商品素材中心

> 商家后台路径： [京麦-商品-商品素材](https://shop.jd.com/jdm/ware/material/materialCenter/materialScene)

商品素材中心是支持商家维护优质规范素材的主要系统，图片素材包含：搜索推荐图、透明图、白底图、场景图、卖点图，文本素材包含商品卖点，维护后的素材将会在首页、搜索、推荐、商详、各频道场、大促会场、排行榜、广告等诸多流量场进行展示或应用，同时商品素材也是商品信息健康分的重要优化项，因此维护素材后将提升商品流量获取能力与转化效率。

这些素材与发品时必传的主图不同，需先发布商品后，进行商品与素材的绑定（白底图在京麦发品编辑页为选填）。

## 1.5 定时更换主图

> 商家后台路径： [京麦-商品-商品管理-更多批量工具-批量定时修改主图](https://ware-material-jdm.jd.com/mainImageChange/changeRecord)

传统指定时间更换商品主图能力，是开发者自行设定定时任务在指定时间，通过商品编辑修改商品SPU/SKU主图实现，大促期间因大量商品集中换图，易出现任务延迟执行、图片更新不及时情况。

为解决此类问题，平台统一提供定时更换主图能力，用户通过开发者提供的软件提前录入期望更换的时间、素材图等信息，平台在指定时间段执行该商品的“主图”更换任务，实现几乎无延迟的换图效果。

需注意，新“定时主图”并不会更换商品上的主图信息，而是在指定时间以“素材绑定”能力，将素材图片绑定指定skuID。故该素材图仅在特定渠道展示，并不会如主图一样被所有应用场景使用。

## 1.7名词解释

**1\. 商品&素材绑定**

因不同素材最终会在消费者端以商品维度进行展示，故需建立商品与素材之间的关系，根据素材类型不同的绑定规则，决定了商品与素材之间的数量对应关系。

**2\. 视频来源：**

- 商家视频：POP商家及自营供应商在京麦-视频空间上传的视频（开放平台API上传同理），其中采销视频项目-红马甲计划，内容由采销&商家按平台要求共创，视频制作完成后由商家上传详情规则查阅 [《红马甲计划白皮书》](https://joyspace.jd.com/pages/heynMyU0EdcuDzUj0Gnk)
- 达人视频：在 [京东创作服务平台](https://dr.jd.com/) 由个人达人、企业帐号、商家帐号上传的视频
- 采销视频：由京东采销发布的视频，且配置了相关商品范围，被命中的商家才可见

**3\. 视频ID：** 本场景涉及2类视频ID，通用视频ID（jdVideoId）：获取上传视频地址时生成，用于上传、保存、查询视频及标签关系等环节使用，商家视频ID（VideoId）：由京麦在保存视频信息时生成，代表该视频已存至商家视频空间，后续用于商家主图视频素材绑定

**4****. 首图：** 商品主图排在第1位顺序的图片，消费者访问商详页，未侧滑操作时看到的商品图片

**5****. 批量更换主图：** 本文中提供的“批量更换主图”能力中，可一次性定时绑定商品主图多张图的功能

## 二、业务规则

## 2.1 图片/视频空间

**1\. 权限：支持供应商/店铺2种身份**

- 供应商身份：以供应商维度查询/管理供应商简码下所有素材，可以跨店
- 店铺身份：以店铺维度查询/管理商家ID下所有素材，POP模式仅有店铺身份，自营使用店铺身份需使用供应商角色的店铺主帐号才可进行全部操作，否则可能导致无权限

若自营账号“供应商”身份中无主图视频权限，需联系京东采销经理为账号开通主图视频权限，可将开通流程 [供应商主图视频权限开通流程](https://joyspace.jd.com/pages/pP63e5YRzW2Ux9pLPePk) 发给采销经理参考（注：每个群/部门权限名称不同，但大致位置相同，可参考链接找对应的权限开通）。

**2\. 关于容量：**

- 图片：单商家默认容量（企业店）50GB/（个人店）10GB，可付费扩容 [图片空间存储扩容订购](https://fw.jd.com/main/detail/FW_GOODS-807002?rdct=true) （有效期1年）

**4\. 空间上传限制规则基础要求：** 更详细介绍可查看 [【商家版】图片/视频空间使用文档](https://joyspace.jd.com/pages/87Tp4Ibro96L1kmYWjjr)

## 2.2 商品主图管理

1\. 商品主图在商品发布/编辑时，可选取图片空间已上传的图片作为主图提交，审核通过后消费者可见。

2\. 基础规则详见表格说明，可自定义图片顺序，每组SKU/SKU主图中可选其中1张作为规格图。

- 商品模式审核流程差异，POP商品机器自动审核通过后生效，自营商品会有额外人工审核，以最终审核结果为准

## 2.3 定时更换主图

支持2种换图模式，定时更换“首图”与定时“批量更换整套图”，本文中主要说明新升级的“批量更换整套图”，更换“首图”详见此文档 [【技术升级】商品定时主图（首张图）能力接入文档](https://joyspace.jd.com/pages/tw6Gy2sfmFIOOW7As21q)

**1\. 换图任务&图片类型：** 可单独更换sku方图或sku长图，也支持长/方图同时批量更换，但当前已有其中一种生效中换图任务的商品不可重复绑定换图任务，故不能分别创建长/方图换图。

当前暂不支持更换“搜索推荐图”（仅时尚等部分开通了搜索推荐图的类目有此素材类型）

**2.活动配置规则：**

图片数量：同sku绑定长/方图最少各1张，每类型最多10张，同一个任务中长/方图数量可以不一致

相同sku间隔时间：5分钟≤间隔时间≤180天

**3.定时图&原图展示规则：**

当绑定的该张定时图顺序有原sku主图时，则为替换逻辑，生效期间该顺序的原图不再展示

当绑定的该张定时图顺序无原sku主图时，则为补充逻辑，生效期间与其它顺序原图合并展示。如定时图指定位置与原图有空位，则会自动补充至最后一张原图之后的最小顺位。

（如：原图顺序 1+2+3，定时图指定顺序1+8，则最终展示为定时图1+原图2、3+定时图4，即：替换1张+补充1张并自动调整位置至4）

**4.区域投放：** 开启“区域设置”后，定时换图仅对该区域消费者定向可见，该投放任务仅能更换方图不可更换长图，开启后可选省/市/区县投放，同任务下地区不可重复

**5.活动状态：** 处理失败，审核中，审核通过，审核驳回，结束成功，结束失败（审核通过且到达生效时间的即为“生效中”，建议开发者自行识别展示该状态便于用户操作）

## 2.4 商品素材图片绑定

**1\. 提交规则：** 与主图不同， 素材图需通过与已发布商品绑定的方式提交（搜索推荐图除外），且审核通过后消费者可见，对应 [京麦-商品-商品素材](https://shop.jd.com/jdm/ware/material/materialCenter/materialScene) 提供的设置能力。

**2\. 素材图通用要求：** 无牛皮癣、主体完整不变形、清晰不偏色、尽量铺满画布（除透明图）、单主体（套装除外），卖点图允许展示文字信息。

②分片上传：文件大于5GB时需分片上传，参考 [京东云-对象存储-分片上传](https://docs.jdcloud.com/cn/object-storage-service/multipart-upload-s3) 通过3个步骤：a.初始化一个分片上传任务（InitiateMultipartUpload）→b.逐个或并行上传分片（UploadPart）→c.完成分片上传（CompleteMultipartUpload）或取消分片上传(AbortMultipartUpload)

分片上传完整示例：

```javascript
// 初始化分片上传
String bucket_name = "<your bucketname>";
String file_path = "<your loacl file>";
String key = Paths.get(file_path).getFileName().toString();
File file = new File(file_path);
long contentLength = file.length();
long partSize = 5 * 1024 * 1024; // 设置每个分片大小为5MB.
        
try {                
// 创建对象的Etag列表，并取回每个分片的Etag。
    List<PartETag> partETags = new ArrayList<PartETag>();
// 初始化分片上传
    InitiateMultipartUploadRequest initRequest = new InitiateMultipartUploadRequest(bucket_name, key);
    InitiateMultipartUploadResult initResponse = s3.initiateMultipartUpload(initRequest);

// 上传分片
    long filePosition = 0;
    for (int i = 1; filePosition < contentLength; i++) {
        partSize = Math.min(partSize, (contentLength - filePosition));
        UploadPartRequest uploadRequest = new UploadPartRequest()
            .withBucketName(bucket_name)
            .withKey(key)
            .withUploadId(initResponse.getUploadId())
            .withPartNumber(i)
            .withFileOffset(filePosition)
            .withFile(file)
            .withPartSize(partSize);
// 上传分片并将返回的Etag加入列表中
        UploadPartResult uploadResult = s3.uploadPart(uploadRequest);
        partETags.add(uploadResult.getPartETag());
        filePosition += partSize;
    }

// 完成分片上传
    CompleteMultipartUploadRequest compRequest = new CompleteMultipartUploadRequest(bucket_name, key,
    initResponse.getUploadId(), partETags);
    s3.completeMultipartUpload(compRequest);
}
catch(AmazonServiceException e) {
    e.printStackTrace();
}
catch(SdkClientException e) {
    e.printStackTrace();
}
```

## 五、常见问题

## 5.1 图片/视频空间相关

**1\. 空间容量不足怎么办？**

1）付费扩容，订购有效期一年 [图片空间扩容订购](https://fw.jd.com/main/detail/FW_GOODS-807002?p=fw&t=searchbutton)， [视频空间扩容订购](https://fw.jd.com/main/detail/FW_GOODS-801002?p=fw&t=searchbutton)。

2）删除历史废弃图片（查询接口未被引用的图片）未绑定的废弃视频以释放空间容量。需特别注意！强制删除“已引用”的图片，会导致前台商品无图可展示，并直接影响商品转化，请谨慎操作！

**2\. 为什么不能新建文件夹？**

图片空间总文件夹个数不限，但同级分类下只能建立200个文件夹。若核实某分类下文件夹个数已达到200，但仍需上传新的文件夹，建议①删除旧文件夹再传新的，②将新文件夹传到其中一个旧文件夹下，平台后续会考虑调整该限制，感谢理解。
